    스크립트 편집기 열기 – 첫 코드 실행까지 5분 완성¶

    2차시 | Part 1: 앱스 스크립트 첫걸음 – 시작하기 전에 알아야 할 것들

    🎯 이 장에서 배우는 것¶

    • 구글 스프레드시트에서 앱스 스크립트 편집기를 열 수 있다
    • 셀에 값을 자동 입력하는 첫 번째 스크립트를 작성·실행할 수 있다
    • 권한 승인 팝업을 이해하고 당황하지 않고 완료할 수 있다

    📚 핵심 개념¶

    개념 1: 앱스 스크립트 편집기¶

    1. 비유로 시작: "편집기는 스프레드시트 뒤에 숨겨진 작업 지시서 작성 공간입니다. 엑셀의 VBA 편집기(Alt+F11)를 떠올리면 딱 맞습니다."
    2. 정확한 정의: 구글이 제공하는 웹 기반 코드 작성 환경으로, 스프레드시트에 연결(Container-bound)되어 시트 데이터를 직접 읽고 쓸 수 있습니다.
    3. 예시로 확인: 메뉴에서 확장 프로그램 → Apps Script를 클릭하면 새 탭에 편집기가 열립니다. 별도 설치가 전혀 필요 없습니다.

    개념 2: 함수(function)¶

    1. 비유로 시작: "함수는 자판기 버튼 하나라고 생각하세요. 버튼을 누르면 정해진 동작이 순서대로 실행됩니다."
    2. 정확한 정의: function 이름() { ... } 형태로 작성하며, 중괄호 {} 안에 실행할 명령을 순서대로 넣습니다.
    3. 예시로 확인: function sayHello() { ... } → ▶ 실행 버튼을 누르면 sayHello 함수 안의 명령이 위에서 아래로 차례대로 동작합니다.

    개념 3: 권한 승인(Authorization)¶

    1. 비유로 시작: "처음 설치한 앱이 '카메라 접근을 허용하시겠습니까?' 묻는 것과 같습니다. 내 스프레드시트 데이터에 스크립트가 접근해도 되는지 구글이 확인하는 절차입니다."
    2. 정확한 정의: 스크립트가 스프레드시트·드라이브 등 구글 서비스에 접근할 때, 최초 1회 사용자 동의를 요구하는 OAuth 2.0 기반 보안 절차입니다.
    3. 예시로 확인: "이 앱은 확인되지 않았습니다"라는 무서운 경고가 뜨지만, 본인이 직접 작성한 코드이므로 고급 → (프로젝트 이름)(으)로 이동을 눌러 안전하게 승인할 수 있습니다.

    🔨 따라하기¶

    Step 1: 스프레드시트 만들기¶

    1. Google 스프레드시트에 접속합니다.
    2. 빈 스프레드시트 를 클릭해 새 문서를 만듭니다.
    3. 파일 이름을 "앱스스크립트 연습장" 으로 바꿔주세요.

    실무 TIP: 연습용 시트는 반드시 별도로 만드세요. 실제 업무 파일에서 실험하다 데이터가 바뀌면 되돌리기 어렵습니다.

    Step 2: 편집기 열기¶

    1. 상단 메뉴에서 확장 프로그램 을 클릭합니다.
    2. 드롭다운에서 Apps Script 를 클릭합니다.
    3. 새 탭에 편집기가 열리고, function myFunction() { } 이라는 기본 코드가 보입니다.
    flowchart LR A["스프레드시트 열기"] --> B["확장 프로그램 클릭"] B --> C["Apps Script 클릭"] C --> D["편집기 새 탭 열림 🎉"]

    Step 3: 첫 번째 코드 작성¶

    기본 코드를 전부 지우고, 아래 코드를 복사해서 붙여넣기 하세요.

    function sayHello() {
  // 현재 연결된 스프레드시트를 가져온다
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  // A1 셀에 인사말을 입력한다
  sheet.getRange("A1").setValue("안녕하세요! 첫 스크립트 성공 🎉");
}

    코드 한 줄씩 뜯어보기

    • SpreadsheetApp.getActiveSpreadsheet() → 지금 연결된 스프레드시트 파일을 가져옵니다
    • .getActiveSheet() → 현재 활성화된 시트(탭)를 가져옵니다
    • .getRange("A1") → A1 셀을 선택합니다
    • .setValue("...") → 선택한 셀에 값을 넣습니다

    실무 TIP: getRange에는 "B3", "C10" 등 어떤 셀 주소든 넣을 수 있습니다. 엑셀에서 셀을 클릭하는 것과 같다고 생각하세요.

    Step 4: 코드 실행하기¶

    1. 편집기 상단 툴바에서 함수 선택 드롭다운이 sayHello 로 되어 있는지 확인합니다.
    2. ▶ 실행 버튼을 클릭합니다.
    3. 처음 실행하면 "승인 필요" 팝업이 나타납니다 → Step 5로 이동!

    Step 5: 권한 승인 완료하기 ⚡¶

    이 단계에서 많은 분이 멈춥니다. 겁먹지 마세요! 순서대로 따라하면 됩니다.

    flowchart TD A["'승인 필요' 팝업"] --> B["권한 검토 클릭"] B --> C["구글 계정 선택"] C --> D["'이 앱은 확인되지 않았습니다' 경고"] D --> E["왼쪽 하단 '고급' 클릭"] E --> F["'앱스스크립트 연습장(으)로 이동' 클릭"] F --> G["'허용' 클릭 ✅"]

    상세 순서:

    1. "승인 필요" 팝업 → 권한 검토 클릭
    2. 본인 구글 계정 선택
    3. "이 앱은 확인되지 않았습니다" 경고 화면 → 왼쪽 하단 고급 클릭
    4. "앱스스크립트 연습장(으)로 이동" 링크 클릭
    5. 권한 목록 확인 후 허용 클릭

    주의사항: "확인되지 않았습니다"는 구글 심사를 받지 않았다는 의미일 뿐, 위험하다는 뜻이 아닙니다. 본인이 직접 작성한 코드이므로 안전합니다. 단, 모르는 사람이 공유한 스크립트는 반드시 코드를 확인한 뒤 승인하세요.

    Step 6: 결과 확인¶

    1. 스프레드시트 탭으로 돌아갑니다.
    2. A1 셀에 "안녕하세요! 첫 스크립트 성공 🎉"이 입력되어 있으면 성공입니다!

    실행 결과: 

    A1 셀 → 안녕하세요! 첫 스크립트 성공 🎉

    📝 실전 코드: 오늘 날짜 + 회사명 자동 입력¶

    위에서 배운 원리를 바로 확장해 봅시다. 출근 후 매일 작성하는 업무일지 시트에 오늘 날짜와 회사명을 자동으로 채우는 스크립트입니다.

    function fillDailyInfo() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  // A1에 오늘 날짜 입력
  var today = new Date();
  sheet.getRange("A1").setValue(today);

  // B1에 회사명 입력 (본인 회사명으로 바꾸세요)
  sheet.getRange("B1").setValue("(주)우리회사");

  // A1 셀을 날짜 형식으로 표시
  sheet.getRange("A1").setNumberFormat("yyyy-MM-dd");
}

    실행 결과: 

    A1 셀 → 2025-01-15  (실행한 당일 날짜)
B1 셀 → (주)우리회사

    실무 TIP: new Date()는 스크립트가 실행되는 그 순간의 날짜와 시간을 가져옵니다. 매일 아침 이 함수를 실행하면 항상 당일 날짜가 입력됩니다. 나중에 배울 트리거를 설정하면 버튼 없이 자동 실행도 가능합니다.

    ⚠️ 주의할 점¶

    1. 편집기와 시트는 다른 탭입니다

    코드를 수정한 뒤 시트 탭에서 결과를 확인할 때, 편집기 탭에서 ▶ 실행을 누른 후 시트 탭으로 이동해야 합니다. 시트에서 아무리 새로고침해도 코드가 자동 실행되지는 않습니다.

    2. 코드를 수정하면 반드시 저장(Ctrl+S) 후 실행하세요

    저장하지 않고 실행하면 이전 버전의 코드가 돌아갑니다. 편집기 제목 옆에 주황색 점(●)이 보이면 아직 저장되지 않은 상태입니다.

    ✅ 점검하기¶

    1. 스프레드시트에서 앱스 스크립트 편집기를 여는 경로는?

    정답 확인 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭하면 새 탭에 편집기가 열립니다.

    2. 처음 스크립트를 실행할 때 "이 앱은 확인되지 않았습니다" 경고가 뜨면 어떻게 해야 하나요?

    정답 확인 왼쪽 하단 **고급** → **"(프로젝트 이름)(으)로 이동"** → **허용** 순서로 클릭합니다. 본인이 직접 작성한 코드이므로 안전하게 승인할 수 있습니다.

    3. A5 셀에 "완료"라는 텍스트를 입력하는 코드를 작성해 보세요.

    정답 확인 
    function markDone() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.getRange("A5").setValue("완료");
}
    핵심은 `getRange("A1")`을 `getRange("A5")`로 바꾸는 것입니다. 셀 주소만 변경하면 어떤 셀이든 값을 넣을 수 있습니다.
