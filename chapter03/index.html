    Chapter 03: 스프레드시트 읽기·쓰기 – 코드로 시트 데이터 다루기¶

    🎯 이 장에서 배우는 것¶

    • getRange()로 원하는 셀과 범위를 지정할 수 있다
    • getValue() / getValues()로 시트 데이터를 코드로 읽어올 수 있다
    • setValue() / setValues()로 시트에 데이터를 쓸 수 있다
    • 템플릿 코드의 '← 여기만 바꾸세요' 부분을 수정하여 자신의 시트에 적용할 수 있다

    💡 왜 이걸 배우나요?¶

    매달 반복하는 일이 있습니다. 시트에서 데이터를 복사해서, 다른 시트에 붙여넣고, 빈 칸을 찾아 기본값을 채우고… 손으로 하면 10분, 데이터가 1,000행이면 1시간입니다.

    코드로 시트를 읽고 쓸 수 있으면 이 모든 작업이 버튼 한 번으로 끝납니다.

    이번 장은 앱스 스크립트에서 가장 자주 쓰는 4가지 메서드만 집중적으로 익힙니다. 이 네 가지만 알면 스프레드시트 자동화의 80%를 해결할 수 있습니다.

    🏗️ 비유: 스프레드시트가 큰 창고라면, getRange는 "3번 선반 2번 칸"처럼 위치를 지정하는 것이고, getValue는 그 칸에서 물건을 꺼내는 것, setValue는 물건을 넣는 것입니다. 이번 장에서는 이 창고 출입법을 마스터합니다.

    📚 핵심 개념¶

    개념 1: getRange() — "어디를 볼 건지" 지정하기¶

    비유: 도서관에서 책을 찾을 때, 먼저 "3층 A구역 선반 5"라고 위치를 특정하죠? getRange()는 시트에서 어떤 셀(또는 셀 범위)을 다룰지 주소를 지정하는 메서드입니다.

    정확한 정의: getRange()는 Sheet 객체에서 특정 셀 또는 셀 범위를 가리키는 Range 객체를 반환합니다.

    두 가지 지정 방식이 있습니다.

    ① A1 표기법 — 평소 시트에서 쓰는 방식 그대로

    // "A1" 셀 하나
sheet.getRange("A1");

// "A1부터 C10까지" 범위
sheet.getRange("A1:C10");

    ② 행·열 번호 방식 — 숫자로 지정 (반복 처리에 유리)

    // getRange(시작행, 시작열, 행수, 열수)
sheet.getRange(1, 1);          // 1행 1열 = A1
sheet.getRange(1, 1, 10, 3);   // 1행1열부터 10행×3열 = A1:C10

    💡 실무 TIP: 고정된 범위는 A1 표기법이 읽기 쉽고, 행·열이 변하는 반복문 안에서는 숫자 방식이 편합니다.

    개념 2: getValue() / getValues() — 데이터 "읽기"¶

    비유: 주소를 지정했으니(getRange), 이제 그 위치에서 내용물을 꺼내 봅니다.

    getValue() — 셀 하나의 값을 가져옵니다.

    var name = sheet.getRange("A2").getValue();
Logger.log(name); // 예: "김민수"

    getValues() — 범위 전체의 값을 2차원 배열로 가져옵니다.

    var data = sheet.getRange("A2:C4").getValues();
// 결과: [["김민수", 1, "A반"], ["이지은", 2, "B반"], ["박준호", 3, "A반"]]
    flowchart LR A["시트 범위<br/>A2:C4"] -->|"getValues()"| B["2차원 배열"] B --> C["data[0][0] → 김민수"] B --> D["data[0][1] → 1"] B --> E["data[1][0] → 이지은"]

    ⚠️ 주의사항: getValues()의 결과는 0부터 시작하는 배열입니다. 시트의 2행이 배열에서는 data[0]입니다. 헷갈리기 쉬우니 꼭 기억하세요!

    개념 3: setValue() / setValues() — 데이터 "쓰기"¶

    비유: 이번엔 반대로, 창고 선반에 물건을 올려놓는 동작입니다.

    setValue() — 셀 하나에 값을 씁니다.

    sheet.getRange("D2").setValue("출석");

    setValues() — 범위 전체에 2차원 배열을 한꺼번에 씁니다.

    var results = [["합격"], ["불합격"], ["합격"]];
sheet.getRange("D2:D4").setValues(results);

    💡 실무 TIP: 1,000행 데이터를 처리할 때, setValue()를 1,000번 반복하면 수십 초 걸립니다. setValues()로 한 번에 쓰면 1~2초면 끝납니다. 대량 데이터는 반드시 setValues()를 사용하세요!

    개념 4: 시트 접근 — getActiveSpreadsheet()와 getSheetByName()¶

    코드의 첫 두 줄은 거의 항상 같은 패턴입니다.

    var ss = SpreadsheetApp.getActiveSpreadsheet();  // 현재 열린 스프레드시트
var sheet = ss.getSheetByName("학생명단");          // "학생명단" 시트 선택

    비유: 건물(스프레드시트)에 들어가서 → 특정 방(시트)의 문을 여는 것입니다.

    flowchart TD A["SpreadsheetApp"] -->|"getActiveSpreadsheet()"| B["스프레드시트 파일"] B -->|"getSheetByName('학생명단')"| C["학생명단 시트"] C -->|"getRange('A1')"| D["A1 셀"] D -->|"getValue()"| E["셀 값 읽기"] D -->|"setValue('hello')"| F["셀 값 쓰기"]

    🎯 핵심 포인트 요약 - getRange → 위치 지정 - getValue / getValues → 읽기 (하나 / 여러 개) - setValue / setValues → 쓰기 (하나 / 여러 개) - getSheetByName → 어떤 시트를 다룰지 선택

    🔨 따라하기¶

    📋 실습 준비: 샘플 시트 만들기¶

    실습을 위해 아래와 같은 데이터를 준비합니다.

    시트 이름: 학생명단

    • A1: 이름 / B1: 번호 / C1: 반 / D1: 비고
    • A2: 김민수 / B2: 1 / C2: A반
    • A3: 이지은 / B3: 2 / C3: B반
    • A4: 박준호 / B4: 3 / C4: A반
    • A5: 최서연 / B5: 4 / C5: B반
    • A6: 정하늘 / B6: 5 / C6: A반
    • D2~D6은 비워두세요 (뒤에서 채울 예정)

    💡 직접 입력하거나, 기존에 데이터가 있는 시트를 사용해도 됩니다. 시트 이름과 범위만 코드에서 맞춰 바꿔주면 됩니다.

    Step 1: 셀 하나 읽어오기¶

    🎯 목표: A2 셀의 이름을 코드로 읽어서 로그에 출력하기

    1. 구글 스프레드시트에서 확장 프로그램 > Apps Script 를 클릭합니다.
    2. 기존 코드를 모두 지우고 아래 코드를 붙여넣습니다.
    function readOneCell() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("학생명단");  // ← 여기만 바꾸세요 (시트 이름)

  var name = sheet.getRange("A2").getValue(); // ← 여기만 바꾸세요 (셀 주소)

  Logger.log("읽어온 값: " + name);
}
    1. 저장(Ctrl+S) → 함수 선택 드롭다운에서 readOneCell 선택 → ▶ 실행 클릭
    2. 권한 승인 팝업이 뜨면 승인합니다.
    3. 실행 로그 또는 보기 > 로그에서 결과를 확인합니다.
    읽어온 값: 김민수

    ✅ "김민수"가 보이면 성공입니다! 셀 주소를 B3으로 바꿔서 다시 실행해보세요. 숫자 3이 나오나요?

    Step 2: 여러 셀 한꺼번에 읽어오기¶

    🎯 목표: A2:C6 전체 데이터를 한 번에 읽어서 로그에 출력하기

    function readMultipleCells() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("학생명단");  // ← 여기만 바꾸세요

  var data = sheet.getRange("A2:C6").getValues(); // ← 여기만 바꾸세요 (범위)

  for (var i = 0; i < data.length; i++) {
    Logger.log(data[i][0] + " / " + data[i][1] + "번 / " + data[i][2]);
  }
}

    실행 결과:

    김민수 / 1번 / A반
이지은 / 2번 / B반
박준호 / 3번 / A반
최서연 / 4번 / B반
정하늘 / 5번 / A반

    💡 실무 TIP: data[i][0]은 i번째 행의 1번째 열(이름), data[i][2]는 3번째 열(반)입니다. 배열 인덱스는 항상 0부터 시작한다는 점, 잊지 마세요!

    Step 3: 셀에 값 쓰기 — 빈 셀에 기본값 채우기¶

    🎯 목표: D열(비고)이 비어있는 셀에 "확인필요"를 자동으로 채우기

    function fillEmptyCells() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("학생명단");    // ← 여기만 바꾸세요

  var range = sheet.getRange("D2:D6");          // ← 여기만 바꾸세요 (채울 범위)
  var values = range.getValues();

  for (var i = 0; i < values.length; i++) {
    if (values[i][0] === "") {                  // 빈 셀이면
      values[i][0] = "확인필요";                 // ← 여기만 바꾸세요 (기본값)
    }
  }

  range.setValues(values);  // 한 번에 쓰기!
  Logger.log("빈 셀 채우기 완료!");
}

    실행 후 시트의 D열을 확인해보세요. 비어있던 셀이 모두 "확인필요"로 채워져 있을 것입니다.

    💡 실무 TIP: 읽어온 배열을 수정한 뒤 setValues()로 같은 범위에 다시 쓰는 패턴은 실무에서 가장 많이 쓰는 패턴입니다. 꼭 익혀두세요!

    Step 4: 실전 사례 — 반별 학생 수 세기¶

    🎯 목표: 코드로 A반, B반 학생이 각각 몇 명인지 세기

    function countByClass() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("학생명단");    // ← 여기만 바꾸세요

  var data = sheet.getRange("C2:C6").getValues(); // ← 여기만 바꾸세요 (반 열)

  var count = {};  // 빈 객체: 반 이름별로 숫자를 저장할 공간

  for (var i = 0; i < data.length; i++) {
    var className = data[i][0];
    if (count[className]) {
      count[className]++;         // 이미 있으면 1 증가
    } else {
      count[className] = 1;       // 처음 나오면 1로 시작
    }
  }

  // 결과 출력
  for (var key in count) {
    Logger.log(key + ": " + count[key] + "명");
  }
}

    실행 결과:

    A반: 3명
B반: 2명

    Step 5: 실전 사례 — 특정 열 데이터를 다른 시트에 복사하기¶

    🎯 목표: "학생명단" 시트의 이름(A열)을 "이름목록" 시트에 복사하기

    먼저 스프레드시트에서 새 시트를 하나 추가하고 이름을 이름목록으로 바꿔주세요.

    function copyColumnToAnotherSheet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();

  // 원본 시트에서 데이터 읽기
  var sourceSheet = ss.getSheetByName("학생명단");  // ← 여기만 바꾸세요
  var names = sourceSheet.getRange("A1:A6").getValues();

  // 대상 시트에 데이터 쓰기
  var targetSheet = ss.getSheetByName("이름목록");   // ← 여기만 바꾸세요
  targetSheet.getRange(1, 1, names.length, 1).setValues(names);

  Logger.log(names.length + "개 행을 복사했습니다!");
}

    실행 후 "이름목록" 시트를 확인하면 이름 데이터가 복사되어 있습니다.

    💡 코드 해설: getRange(1, 1, names.length, 1)에서 names.length를 사용했기 때문에, 원본 데이터가 늘어나도 코드 수정 없이 자동으로 맞춰집니다. 이런 동적 범위 지정이 실무에서 핵심입니다.

    Step 6: 마무리 — getLastRow()로 데이터 끝 자동 감지¶

    지금까지는 범위를 A2:C6처럼 직접 지정했습니다. 하지만 실무에서는 데이터가 매일 늘어납니다. 마지막 행을 자동으로 찾는 방법을 알아봅시다.

    function readAllDataDynamic() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("학생명단");  // ← 여기만 바꾸세요

  var lastRow = sheet.getLastRow();            // 데이터가 있는 마지막 행 번호
  Logger.log("마지막 행: " + lastRow);

  // 2행부터 마지막행까지 동적으로 읽기 (헤더 제외)
  var data = sheet.getRange(2, 1, lastRow - 1, 3).getValues();

  Logger.log("총 " + data.length + "명의 데이터를 읽었습니다.");
  for (var i = 0; i < data.length; i++) {
    Logger.log(data[i][0] + " (" + data[i][2] + ")");
  }
}

    🎯 핵심 포인트: getLastRow()를 사용하면 데이터가 100행이든 10,000행이든 코드를 수정할 필요가 없습니다. 실무 코드에서는 항상 이 방법을 사용하세요!

    📝 전체 코드¶

    이번 장에서 배운 핵심 패턴을 하나의 함수로 정리했습니다. 실무에서 템플릿처럼 복사해서 사용하세요.

    /**
 * 스프레드시트 읽기·쓰기 통합 템플릿
 * '← 여기만 바꾸세요' 표시 부분을 자신의 시트에 맞게 수정하세요
 */
function spreadsheetReadWriteTemplate() {
  // ===== 1. 시트 연결 =====
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("학생명단");    // ← 여기만 바꾸세요 (시트 이름)

  // ===== 2. 데이터 읽기 (동적 범위) =====
  var lastRow = sheet.getLastRow();
  var data = sheet.getRange(2, 1, lastRow - 1, 4).getValues(); 
  // ↑ 2행부터, 1열부터, (lastRow-1)행만큼, 4열 — ← 여기만 바꾸세요

  Logger.log("총 " + data.length + "행 읽음");

  // ===== 3. 데이터 가공 =====
  for (var i = 0; i < data.length; i++) {
    // data[i][0] = 이름, data[i][1] = 번호, data[i][2] = 반, data[i][3] = 비고

    if (data[i][3] === "") {           // 비고(D열)가 비어있으면
      data[i][3] = "확인필요";          // ← 여기만 바꾸세요 (기본값)
    }
  }

  // ===== 4. 데이터 쓰기 (한 번에!) =====
  sheet.getRange(2, 1, data.length, 4).setValues(data);
  // ↑ 읽어온 범위와 동일하게 다시 쓰기

  Logger.log("처리 완료!");
}

    ⚠️ 자주 하는 실수¶

    실수 1: 시트 이름 오타¶

    // ❌ 이름이 틀리면 null이 반환되어 에러 발생!
var sheet = ss.getSheetByName("학생 명단");  // 공백 하나 차이!

// ✅ 시트 탭에 보이는 이름을 정확히 복사하세요
var sheet = ss.getSheetByName("학생명단");

    에러 메시지 Cannot call method "getRange" of null이 보이면 99% 시트 이름이 틀린 것입니다.

    실수 2: setValues()에 넘기는 배열 크기 불일치¶

    // ❌ 3행 범위에 2행 데이터를 넣으면 에러!
sheet.getRange("D2:D4").setValues([["합격"], ["불합격"]]);

// ✅ 범위와 배열 크기를 정확히 맞추세요
sheet.getRange("D2:D3").setValues([["합격"], ["불합격"]]);

    해결법: getRange(시작행, 시작열, 배열.length, 배열[0].length)처럼 배열 크기에 맞춰 범위를 동적으로 지정하면 실수를 방지할 수 있습니다.

    실수 3: getValue와 getValues를 혼동¶

    // ❌ 범위인데 getValue를 쓰면 첫 번째 셀만 가져옴
var data = sheet.getRange("A1:C10").getValue();  // A1 값만 나옴!

// ✅ 범위는 반드시 getValues (복수형!)
var data = sheet.getRange("A1:C10").getValues();

    🎯 기억법: 셀 하나 → getValue (단수) / 여러 개 → getValues (복수, s가 붙음!)

    실수 4: 배열 인덱스를 1부터 시작¶

    // ❌ 시트의 2행이니까 data[2]? → 틀림!
var firstName = data[2][0];  // 실제로는 3번째 행의 값

// ✅ 배열은 0부터! 시트 2행 = data[0]
var firstName = data[0][0];  // 첫 번째 데이터 행

    ✅ 스스로 점검하기¶

    아래 항목을 하나씩 체크해보세요. 모두 체크할 수 있다면 이번 장을 완료한 것입니다!

    • getRange("A1") 과 getRange(1, 1)이 같은 셀을 가리킨다는 것을 안다
    • getValue()는 값 하나, getValues()는 2차원 배열을 반환한다는 것을 안다
    • 빈 셀을 찾아 기본값을 채우는 코드를 작성할 수 있다
    • setValues()를 쓸 때 범위와 배열 크기를 맞춰야 한다는 것을 안다
    • getLastRow()로 데이터의 마지막 행을 자동 감지할 수 있다
    • 템플릿 코드의 '← 여기만 바꾸세요' 부분을 자신의 시트에 맞게 수정할 수 있다
