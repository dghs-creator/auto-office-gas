    학부모 개별 알림 ① – 학생별 맞춤 이메일 발송¶

    Part 3: 알림·소통 자동화 – 필요한 사람에게 정확히 전달하기 | 11차시

    🎯 이 장에서 배우는 것¶

    • 스프레드시트의 학생·학부모 정보를 읽어 개별 맞춤 이메일을 자동 발송할 수 있다
    • 이메일 본문에 학생 이름, 성적, 출결 등 개별 데이터를 자동 삽입할 수 있다
    • 발송 완료 여부를 시트에 자동 기록하는 로직을 구현할 수 있다
    • 테스트 발송과 오류 점검을 통해 안전하게 대량 메일을 운영할 수 있다

    💡 왜 이걸 배우나요?¶

    CASE STUDY: D 선생님의 중간고사 후 일주일

    담임 D 선생님은 중간고사가 끝나면 30명 학부모에게 개별 성적 안내 메일을 보냅니다. "○○ 어머님, ○○ 학생의 국어 성적은 85점이고…" 한 통 작성에 5분, 30통이면 2시간 30분. 게다가 이름을 바꿔 넣다가 '김민준 어머님'에게 '이서연 학생' 성적을 보낸 사고까지 경험했습니다.

    이 문제는 학교만의 일이 아닙니다.

    • 영업팀: 고객사 50곳에 각기 다른 견적 요약 발송
    • HR팀: 부서별 연차 현황을 각 팀장에게 개별 안내
    • 교육기관: 수강생 출결·성적을 보호자에게 통보

    핵심은 같습니다. "같은 구조, 다른 내용"의 이메일을 여러 명에게 보내는 것. 이 작업을 Apps Script 10줄 남짓으로 자동화하면, 30명이든 300명이든 1분 안에 정확하게 발송할 수 있습니다.

    📚 핵심 개념¶

    개념 1: 메일 머지(Mail Merge) 패턴¶

    비유: 편지지 틀(템플릿)에 이름 도장만 바꿔 찍는 것. 편지 내용은 같고, 받는 사람 정보만 다릅니다.

    정의: 하나의 이메일 템플릿에 {학생이름}, {국어점수} 같은 플레이스홀더(자리표시자)를 넣어두고, 스프레드시트 각 행의 데이터로 치환하여 개별 이메일을 생성하는 패턴입니다.

    예시: 템플릿 본문이 다음과 같을 때—

    {학부모명} 학부모님, 안녕하세요.
{학생이름} 학생의 중간고사 국어 성적은 {국어}점입니다.

    1행 데이터가 김영수, 김민준, 85이면 → 김영수 학부모님… 김민준 학생… 85점으로 완성됩니다.

    개념 2: GmailApp.sendEmail() 메서드¶

    비유: 우체국 창구입니다. "받는 사람 주소, 제목, 내용"을 건네면 우체국이 알아서 배달합니다.

    정의: Google Apps Script에서 Gmail을 통해 이메일을 보내는 내장 함수입니다.

    GmailApp.sendEmail(받는사람이메일, 제목, 본문);
    • 받는사람이메일: 문자열 (예: "parent@example.com")
    • 제목: 문자열
    • 본문: 일반 텍스트 또는 htmlBody 옵션으로 HTML 가능

    실무 TIP 💡 HTML 본문을 사용하면 굵은 글씨, 색상 강조, 표 삽입이 가능합니다. 네 번째 인자에 {htmlBody: htmlString}을 전달하면 됩니다.

    개념 3: 시트 데이터 순회(Loop) 구조¶

    비유: 출석부를 위에서 아래로 한 줄씩 읽으며 이름을 부르는 것과 같습니다.

    정의: getDataRange().getValues()로 시트 전체 데이터를 2차원 배열로 가져온 뒤, for 반복문으로 각 행(=학생 1명)을 처리합니다.

    flowchart LR A["시트 데이터 읽기<br/>getValues()"] --> B["행 반복<br/>for loop"] B --> C["템플릿 치환<br/>replace()"] C --> D["이메일 발송<br/>sendEmail()"] D --> E["발송 로그 기록<br/>setValue()"] E --> B

    개념 4: 발송 로그 자동 기록¶

    비유: 택배 송장번호를 찍어두는 것. "언제, 누구에게 보냈는지" 기록이 없으면 이중 발송이나 누락이 생깁니다.

    정의: 이메일 발송 직후 해당 행의 특정 열(예: G열)에 "발송완료" 텍스트와 타임스탬프를 기록합니다. 다음 실행 시 이 값을 확인하여 중복 발송을 방지합니다.

    주의사항 ⚠️ 발송 로그 없이 스크립트를 여러 번 실행하면 같은 학부모에게 동일 메일이 반복 전송됩니다. 반드시 로그 확인 로직을 포함하세요.

    🔨 따라하기¶

    준비: 스프레드시트 데이터 세팅¶

    새 Google 스프레드시트를 만들고, 시트 이름을 학생정보로 변경합니다. 아래 구조로 데이터를 입력하세요.

    열 구성 (1행 = 헤더) - A열: 학생이름 - B열: 학부모명 - C열: 이메일 - D열: 국어 - E열: 수학 - F열: 영어 - G열: 발송상태

    샘플 데이터 (2~4행) - 김민준 / 김영수 / test1@gmail.com / 85 / 92 / 78 / (비워둠) - 이서연 / 이정희 / test2@gmail.com / 91 / 76 / 88 / (비워둠) - 박지호 / 박수진 / test3@gmail.com / 72 / 85 / 90 / (비워둠)

    실무 TIP 💡 테스트 단계에서는 C열의 이메일을 모두 본인 이메일로 입력하세요. 실제 학부모에게 테스트 메일이 발송되는 사고를 방지합니다.

    Step 1: Apps Script 편집기 열기¶

    1. 스프레드시트 상단 메뉴 → 확장 프로그램 → Apps Script 클릭
    2. 기본 생성된 myFunction 코드를 모두 삭제
    3. 아래 Step 2부터의 코드를 입력할 준비 완료

    Step 2: 이메일 템플릿 정의하기¶

    먼저 이메일의 "틀"을 만듭니다. 플레이스홀더로 {학부모명}, {학생이름} 등을 사용합니다.

    function sendParentEmails() {
  // ① 이메일 제목 템플릿
  var subjectTemplate = "[중간고사] {학생이름} 학생 성적 안내";

  // ② 이메일 본문 템플릿
  var bodyTemplate = 
    "{학부모명} 학부모님, 안녕하세요.\n\n" +
    "담임교사 ○○○입니다.\n" +
    "{학생이름} 학생의 중간고사 성적을 안내드립니다.\n\n" +
    "• 국어: {국어}점\n" +
    "• 수학: {수학}점\n" +
    "• 영어: {영어}점\n\n" +
    "궁금하신 점은 언제든 연락주세요.\n" +
    "감사합니다.";

    핵심 포인트: {중괄호} 안의 텍스트가 시트 헤더와 정확히 일치할 필요는 없지만, 코드에서 치환할 때 철자가 정확히 같아야 합니다.

    Step 3: 시트 데이터 읽기¶

      // ③ 시트 데이터 가져오기
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("학생정보");
  var data = sheet.getDataRange().getValues();  // 2차원 배열
  var header = data[0];  // 1행(헤더)

  // 발송 건수 카운터
  var sentCount = 0;

    getValues()가 반환하는 구조를 그림으로 이해하면:

    flowchart TD A["data[0] = 헤더행<br/>[학생이름, 학부모명, 이메일, 국어, 수학, 영어, 발송상태]"] B["data[1] = 1번 학생<br/>[김민준, 김영수, test1@..., 85, 92, 78, ]"] C["data[2] = 2번 학생<br/>[이서연, 이정희, test2@..., 91, 76, 88, ]"] A --> B --> C

    Step 4: 행 반복 + 템플릿 치환 + 발송¶

      // ④ 2행(인덱스 1)부터 마지막 행까지 반복
  for (var i = 1; i < data.length; i++) {
    var row = data[i];

    var 학생이름 = row[0];
    var 학부모명 = row[1];
    var 이메일   = row[2];
    var 국어     = row[3];
    var 수학     = row[4];
    var 영어     = row[5];
    var 발송상태 = row[6];

    // ⑤ 이미 발송된 행은 건너뛰기 (중복 방지)
    if (발송상태 === "발송완료") {
      continue;
    }

    // ⑥ 이메일 주소가 비어있으면 건너뛰기
    if (!이메일 || 이메일.toString().trim() === "") {
      continue;
    }

    // ⑦ 템플릿 치환
    var subject = subjectTemplate
      .replace("{학생이름}", 학생이름);

    var body = bodyTemplate
      .replace("{학부모명}", 학부모명)
      .replace("{학생이름}", 학생이름)
      .replace("{국어}", 국어)
      .replace("{수학}", 수학)
      .replace("{영어}", 영어);

    // ⑧ 이메일 발송
    GmailApp.sendEmail(이메일, subject, body);
    sentCount++;

    주의사항 ⚠️ replace()는 첫 번째로 매칭되는 것만 치환합니다. 같은 플레이스홀더가 본문에 2번 이상 나오면 replaceAll()을 사용하거나, 정규식 replace(/\{학생이름\}/g, 학생이름)을 쓰세요.

    Step 5: 발송 로그 기록¶

        // ⑨ G열(7번째 열)에 발송 완료 기록
    sheet.getRange(i + 1, 7).setValue("발송완료");

    // ⑩ H열(8번째 열)에 발송 시각 기록
    sheet.getRange(i + 1, 8).setValue(new Date());
  }

  // ⑪ 완료 알림
  SpreadsheetApp.getUi().alert(sentCount + "건의 이메일을 발송했습니다.");
}

    i + 1을 쓰는 이유: 배열 인덱스는 0부터 시작하지만 시트 행 번호는 1부터 시작하므로 1을 더해야 실제 행과 맞습니다.

    Step 6: 테스트 발송 및 확인¶

    1. C열 이메일을 모두 본인 주소로 변경
    2. Apps Script 편집기에서 sendParentEmails 선택 → ▶ 실행
    3. 첫 실행 시 권한 승인 팝업 → "고급" → "○○(안전하지 않음)으로 이동" → "허용"
    4. Gmail 받은편지함 확인 → 3통의 맞춤 메일 수신 확인
    5. 스프레드시트 G열에 "발송완료", H열에 타임스탬프 확인
    6. 다시 실행 → 이미 발송완료 표시가 있으므로 0건 발송 확인 (중복 방지 검증)

    실무 TIP 💡 Gmail은 하루 발송 한도가 있습니다. 일반 Google 계정은 100통/일, Google Workspace 계정은 1,500통/일입니다. 대량 발송 시 한도를 미리 확인하세요.

    📝 전체 코드¶

    function sendParentEmails() {
  // === 설정 영역 ===
  var SHEET_NAME = "학생정보";
  var STATUS_COL = 7;   // G열: 발송상태
  var TIME_COL = 8;     // H열: 발송시각

  var subjectTemplate = "[중간고사] {학생이름} 학생 성적 안내";

  var bodyTemplate = 
    "{학부모명} 학부모님, 안녕하세요.\n\n" +
    "담임교사 ○○○입니다.\n" +
    "{학생이름} 학생의 중간고사 성적을 안내드립니다.\n\n" +
    "• 국어: {국어}점\n" +
    "• 수학: {수학}점\n" +
    "• 영어: {영어}점\n\n" +
    "궁금하신 점은 언제든 연락주세요.\n" +
    "감사합니다.";

  // === 데이터 읽기 ===
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);
  var data = sheet.getDataRange().getValues();
  var sentCount = 0;
  var errorRows = [];

  // === 행 반복 처리 ===
  for (var i = 1; i < data.length; i++) {
    var row = data[i];
    var 학생이름 = row[0];
    var 학부모명 = row[1];
    var 이메일   = row[2];
    var 국어     = row[3];
    var 수학     = row[4];
    var 영어     = row[5];
    var 발송상태 = row[6];

    // 중복 발송 방지
    if (발송상태 === "발송완료") continue;

    // 이메일 누락 체크
    if (!이메일 || 이메일.toString().trim() === "") continue;

    try {
      // 템플릿 치환
      var subject = subjectTemplate.replace("{학생이름}", 학생이름);
      var body = bodyTemplate
        .replace("{학부모명}", 학부모명)
        .replace("{학생이름}", 학생이름)
        .replace("{국어}", 국어)
        .replace("{수학}", 수학)
        .replace("{영어}", 영어);

      // 발송
      GmailApp.sendEmail(이메일, subject, body);

      // 로그 기록
      sheet.getRange(i + 1, STATUS_COL).setValue("발송완료");
      sheet.getRange(i + 1, TIME_COL).setValue(new Date());
      sentCount++;

    } catch (e) {
      // 에러 발생 시 상태 기록
      sheet.getRange(i + 1, STATUS_COL).setValue("오류: " + e.message);
      errorRows.push(i + 1);
    }
  }

  // === 결과 알림 ===
  var message = sentCount + "건 발송 완료.";
  if (errorRows.length > 0) {
    message += "\n오류 발생 행: " + errorRows.join(", ");
  }
  SpreadsheetApp.getUi().alert(message);
}

    실무 TIP 💡 위 코드에는 try-catch 블록이 추가되어 있습니다. 이메일 주소 형식 오류 등으로 한 건이 실패해도 나머지는 계속 발송되며, 오류가 발생한 행 번호를 알려줍니다.

    ⚠️ 자주 하는 실수¶

    실수 1: 테스트 없이 바로 실제 발송 🚨¶

    증상: 템플릿에 오타가 있는 채로 30명에게 발송 → "김민준 어머님… {수학}점" 같은 메일이 전달됨

    해결: 반드시 C열을 본인 이메일로 바꿔서 테스트한 뒤, 확인 후 실제 이메일로 교체하세요. 테스트 후에는 G열 발송상태를 지우고 다시 실행합니다.

    실수 2: 시트 이름 불일치¶

    증상: TypeError: Cannot call method 'getDataRange' of null

    원인: getSheetByName("학생정보")인데 실제 시트 이름이 "학생 정보"(띄어쓰기) 또는 "Sheet1"인 경우

    해결: 시트 탭 이름과 코드의 문자열이 완전히 동일한지 확인. 공백, 대소문자 주의.

    실수 3: 발송상태 열을 지우고 재실행 → 중복 발송¶

    증상: 같은 학부모에게 동일 메일 2~3통 수신

    원인: G열 "발송완료" 값을 지운 뒤 스크립트 재실행

    해결: 재발송이 의도된 경우에만 상태값을 삭제하세요. 실수 방지를 위해 코드 첫 줄에 확인 다이얼로그를 추가하는 것도 좋습니다.

    var ui = SpreadsheetApp.getUi();
var response = ui.alert("정말 이메일을 발송하시겠습니까?", ui.ButtonSet.YES_NO);
if (response !== ui.Button.YES) return;

    실수 4: Gmail 일일 발송 한도 초과¶

    증상: Service invoked too many times for one day: email 오류

    해결: 일반 계정 100통, Workspace 1,500통 한도를 초과하지 않도록 분할 발송하세요. 발송 로그가 있으므로 다음 날 이어서 실행하면 미발송 건만 처리됩니다.

    ✅ 스스로 점검하기¶

    아래 항목을 모두 체크할 수 있다면 이 차시를 완료한 것입니다.

    • 스프레드시트에 학생/학부모 정보를 올바른 구조로 입력했다
    • sendParentEmails() 함수를 실행하여 테스트 메일을 수신했다
    • 받은 메일에 학생 이름, 성적이 각각 다르게 들어있음을 확인했다
    • G열에 "발송완료", H열에 발송 시각이 자동 기록되었다
    • 스크립트를 다시 실행했을 때 0건 발송(중복 방지)을 확인했다
    • 이메일 주소가 비어있는 행을 추가하고, 해당 행이 건너뛰어지는 것을 확인했다
