    수행평가·성적 집계 ② – 석차 계산과 통계 리포트¶

    Part 5 | [2권] 문서 생성·성적 처리 자동화 – 개별 문서와 성적을 한 번에

    🎯 이 장에서 배우는 것¶

    • 총점 기준 석차를 자동 계산하고, 동점자에게 같은 석차를 부여할 수 있다
    • 반별·학년별 평균, 최고점, 최저점, 표준편차를 자동 산출할 수 있다
    • 집계 결과를 별도 "리포트 시트"로 자동 생성하여 즉시 보고할 수 있다
    • 석차 정확성을 검증하는 체크 루틴을 코드에 포함시킬 수 있다

    💡 왜 이걸 배우나요?¶

    CASE STUDY — I 선생님의 중간고사 야근

    200명 학생의 중간고사 성적이 스프레드시트에 쏟아졌습니다. I 선생님은 총점 순으로 석차를 매기고, 5개 반의 평균·표준편차를 구해 교무실 보고용 리포트를 만들어야 합니다. 수작업으로 정렬→석차 입력→동점자 수정→반별 통계를 반복하다 보니 오류는 3건, 퇴근은 밤 10시였습니다.

    이번 장의 코드를 쓰면 클릭 한 번에 석차 + 통계 + 리포트 시트가 완성됩니다. 성적뿐 아니라 영업 실적 순위, 평가 점수 집계 등 순위와 요약 통계가 필요한 모든 비즈니스 상황에 똑같이 적용할 수 있습니다.

    📚 핵심 개념¶

    개념 1: 석차(Rank) 계산의 원리 — "경쟁 순위"¶

    비유 🏅 마라톤 결승선을 떠올려 보세요. 1등이 들어오고, 2명이 동시에 도착하면 둘 다 2등을 줍니다. 다음 주자는 4등이 됩니다. 이것이 경쟁 석차(Competition Rank) 방식입니다.

    정확한 정의 - 전체 점수를 내림차순 정렬한 뒤, 자기보다 높은 점수를 가진 사람의 수 + 1 = 석차 - 동점자가 k명이면 모두 같은 석차를 받고, 다음 석차는 현재 석차 + k

    예시로 확인

    점수가 [95, 92, 92, 88]일 때: - 95점 → 석차 1 - 92점 2명 → 둘 다 석차 2 - 88점 → 석차 4 (3이 아니라 4!)

    실무 TIP: 엑셀의 RANK.EQ() 함수가 바로 이 방식입니다. openpyxl로 이 함수를 기록해 둘 수도 있지만, 파이썬에서 직접 계산하면 동점자 검증까지 한 번에 가능합니다.

    개념 2: 기술 통계(Descriptive Statistics) 4총사¶

    비유 📊 건강검진표에 내 키만 적혀 있으면 의미가 없습니다. 평균 키, 최대·최소, 표준편차가 함께 있어야 "나는 상위 몇 %인지" 판단할 수 있죠. 성적도 마찬가지입니다.

    4가지 지표 정의 - 평균(Mean): 모든 값의 합 ÷ 개수 — "우리 반 중심이 어디인가" - 최고점(Max): 가장 높은 값 — "천장이 어디인가" - 최저점(Min): 가장 낮은 값 — "바닥이 어디인가" - 표준편차(Std Dev): 값들이 평균에서 얼마나 흩어져 있는가 — "편차가 크면 양극화"

    실무 TIP: Python statistics 모듈의 mean(), stdev()를 사용하면 별도 라이브러리 설치 없이 계산 가능합니다.

    개념 3: 리포트 시트 자동 생성¶

    비유 🖨️ 원본 데이터는 재료 창고, 리포트 시트는 쇼윈도입니다. 고객(상사·학교)에게 보여줄 깔끔한 요약을 별도 시트에 자동으로 진열하는 것이 핵심입니다.

    구현 포인트 - 기존 워크북에 새 시트를 추가 (wb.create_sheet("리포트")) - 제목 행 스타일링 → 데이터 행 반복 입력 → 열 너비 자동 조정 - 한 파일 안에 "원본 데이터 시트 + 리포트 시트"가 공존

    개념 4: 검증 루틴 — 석차 정확성 체크¶

    비유 ✅ 은행 ATM은 돈을 세고, 다시 센 뒤, 세 번째로 확인합니다. 석차 역시 "계산 → 검증"을 거쳐야 민원이 없습니다.

    3가지 검증 규칙 - 규칙 A: 석차 1이 반드시 1개 이상 존재해야 한다 - 규칙 B: 석차의 최댓값 ≤ 전체 학생 수 - 규칙 C: 동점자 수를 합산하면 전체 학생 수와 일치해야 한다

    Step 2: 석차 계산 — 동점자 처리 포함¶

    def calc_rank(students, key="총점"):
    """경쟁 석차(Competition Rank) 계산 — 동점자 동일 석차"""
    # 1) 총점 내림차순 정렬
    sorted_list = sorted(students, key=lambda x: x[key], reverse=True)

    # 2) 석차 부여
    rank = 1
    for i, stu in enumerate(sorted_list):
        if i > 0 and stu[key] < sorted_list[i - 1][key]:
            rank = i + 1          # 동점이 아니면 현재 위치 + 1
        stu["석차"] = rank

    return sorted_list

students = calc_rank(students)
print(f"🏅 석차 계산 완료 — 1등 총점: {students[0]['총점']}점")

    동점자 처리 흐름도

    flowchart TD A["총점 기준 내림차순 정렬"] --> B{"이전 학생과 총점 같은가?"} B -- 같다 --> C["이전과 동일 석차 부여"] B -- 다르다 --> D["현재 인덱스+1 = 새 석차"] C --> E["다음 학생으로"] D --> E E --> B

    실무 TIP: rank = i + 1이 핵심입니다. 동점이 끝나는 시점에서 "건너뛴 만큼" 자동으로 반영됩니다. 별도 카운터가 필요 없어 버그가 줄어듭니다.

    Step 4: 반별·학년 기술 통계 산출¶

    from statistics import mean, stdev

def class_stats(students, class_num):
    """특정 반의 총점 통계 반환"""
    scores = [s["총점"] for s in students if s["반"] == class_num]
    return {
        "반": class_num,
        "인원": len(scores),
        "평균": round(mean(scores), 1),
        "최고점": max(scores),
        "최저점": min(scores),
        "표준편차": round(stdev(scores), 1)
    }

# 반별 통계
class_report = [class_stats(students, c) for c in range(1, 6)]

# 학년 전체 통계
all_scores = [s["총점"] for s in students]
whole = {
    "반": "전체",
    "인원": len(all_scores),
    "평균": round(mean(all_scores), 1),
    "최고점": max(all_scores),
    "최저점": min(all_scores),
    "표준편차": round(stdev(all_scores), 1)
}
class_report.append(whole)

for r in class_report:
    print(f"  {r['반']}반 | 평균 {r['평균']} | 최고 {r['최고점']} | "
          f"최저 {r['최저점']} | 표준편차 {r['표준편차']}")

    핵심 포인트: statistics 모듈은 파이썬 기본 내장이라 별도 설치가 필요 없습니다. stdev()는 표본 표준편차(n-1)를 사용합니다.

    # ── 석차 검증 루틴 ──
def verify_rank(students):
    errors = []
    ranks = [s["석차"] for s in students]
    n = len(students)

    # 규칙 A: 1등이 존재하는가
    if 1 not in ranks:
        errors.append("❌ 석차 1이 존재하지 않습니다")

    # 규칙 B: 최대 석차 ≤ 전체 인원
    if max(ranks) > n:
        errors.append(f"❌ 최대 석차({max(ranks)})가 전체 인원({n})을 초과합니다")

    # 규칙 C: 동점 합산 = 전체 인원
    from collections import Counter
    rank_counts = Counter(ranks)
    total_check = sum(rank_counts.values())
    if total_check != n:
        errors.append(f"❌ 석차 합산({total_check})이 인원({n})과 불일치")

    if not errors:
        print("✅ 석차 검증 통과 — 이상 없음")
    else:
        for e in errors:
            print(e)

    return len(errors) == 0

verify_rank(students)

        "학번": 학번, "이름": 이름, "반": 반,

for i, stu in enumerate(sorted_stu):

students = sorted_stu

def class_stats(data, c):
    scores = [s["총점"] for s in data if s["반"] == c]
    return {"반": c, "인원": len(scores), "평균": round(mean(scores), 1),
            "최고점": max(scores), "최저점": min(scores),
            "표준편차": round(stdev(scores), 1)}

report_data = [class_stats(students, c) for c in range(1, 6)]
all_sc = [s["총점"] for s in students]
report_data.append({"반": "전체", "인원": len(all_sc),

    ⚠️ 자주 하는 실수¶

    실수 1: 동점자 다음 석차를 +1로 계산

    동점자가 2명(석차 3)인데 다음 학생 석차를 4로 매기면 안 됩니다. 경쟁 석차에서는 5가 정답입니다. rank = i + 1 패턴을 사용하면 자동으로 해결됩니다.

    주의사항: 엑셀 RANK.EQ와 동일한 방식이니, 엑셀과 교차 검증할 때 헷갈리지 마세요.

    실수 2: 총점 열을 문자열로 읽어옴

    엑셀 파일에서 숫자가 텍스트로 저장된 경우 sorted()가 사전순 정렬을 합니다. "99" < "100"이 되어 석차가 완전히 엉망이 됩니다.

    해결: 로드 시 int(총점)으로 형변환하거나, 원본 파일에서 셀 서식을 "숫자"로 통일하세요.

    실수 3: 리포트 시트를 매번 중복 생성

    코드를 반복 실행하면 "통계리포트", "통계리포트1", "통계리포트2"… 시트가 늘어납니다. 위 코드처럼 기존 시트 삭제 후 재생성 패턴을 반드시 넣으세요.

    if "통계리포트" in wb.sheetnames:
    del wb["통계리포트"]

    실수 4: 표준편차 계산 시 데이터 1개인 반

    학생이 1명뿐인 그룹에서 stdev()를 호출하면 StatisticsError가 발생합니다. 실무에서 소규모 그룹이 있을 수 있으니 인원 체크 → 2명 미만이면 "N/A" 처리를 권장합니다.
