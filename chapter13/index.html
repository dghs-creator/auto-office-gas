    캘린더 일정 일괄 등록 ① – 학사 일정 한 번에 넣기¶

    Part 4: 일정·환경 세팅 자동화 – 학기 초 세팅을 한 번에

    🎯 이 장에서 배우는 것¶

    • CalendarApp 객체를 사용하여 구글 캘린더에 코드로 일정을 등록할 수 있다
    • 스프레드시트에 정리한 일정 목록을 읽어 캘린더에 일괄 등록할 수 있다
    • 종일 일정과 시간 지정 일정을 구분하여 자동으로 분기 처리할 수 있다
    • 등록 결과를 시트에 기록하여 누락 없이 검증할 수 있다

    💡 왜 이걸 배우나요?¶

    CASE STUDY: 교무부 E 선생님의 3월

    새 학년이 시작되면 연간 학사 일정 약 50건을 캘린더에 등록해야 합니다. 입학식, 중간고사, 기말고사, 개교기념일, 수행평가, 체험학습… 하나씩 클릭하며 입력하면 최소 2시간이 걸립니다. 날짜를 잘못 클릭하면 5월 행사가 4월에 들어가기도 하죠.

    E 선생님은 올해 방법을 바꿨습니다. 학사 일정을 스프레드시트에 정리하고, 스크립트 한 번 실행으로 50건을 캘린더에 넣었습니다. 걸린 시간? 30초.

    이 챕터를 마치면 여러분도 똑같이 할 수 있습니다. 학사 일정뿐 아니라 프로젝트 마일스톤, 팀 행사, 정기 보고 일정 등 어떤 반복적인 캘린더 등록 작업이든 자동화할 수 있습니다.

    📚 핵심 개념¶

    개념 1: CalendarApp – 캘린더의 리모컨 🎮¶

    비유: SpreadsheetApp이 "스프레드시트 리모컨"이었다면, CalendarApp은 "구글 캘린더 리모컨"입니다. 채널 버튼을 누르듯, 메서드 하나로 일정을 만들고, 수정하고, 삭제할 수 있습니다.

    정확한 정의: CalendarApp은 Google Apps Script에서 구글 캘린더를 조작하는 내장 클래스입니다. 로그인한 계정의 캘린더에 접근하며, 일정 생성·조회·삭제 등 모든 작업을 코드로 수행합니다.

    핵심 메서드 3가지

    • getDefaultCalendar() — 내 기본 캘린더를 가져옵니다
    • createEvent(제목, 시작시간, 종료시간) — 시간 지정 일정을 만듭니다
    • createAllDayEvent(제목, 날짜) — 종일 일정을 만듭니다
    // 가장 간단한 예: 종일 일정 하나 만들기
function createOneEvent() {
  var calendar = CalendarApp.getDefaultCalendar();
  calendar.createAllDayEvent('입학식', new Date('2025-03-02'));
}

    실무 TIP: getDefaultCalendar()는 내 기본 캘린더입니다. 팀 공유 캘린더에 등록하려면 getCalendarById('캘린더ID')를 사용하세요. 캘린더 ID는 캘린더 설정 → "캘린더 통합" 섹션에서 확인할 수 있습니다.

    개념 2: Date 객체 – 날짜와 시간의 통역사 📅¶

    비유: 스프레드시트에서 "2025-03-02"는 그냥 텍스트입니다. 캘린더에 등록하려면 자바스크립트가 이해하는 Date 객체로 "통역"해줘야 합니다.

    정확한 정의: new Date('2025-03-02')는 자바스크립트의 날짜/시간 객체를 생성합니다. CalendarApp의 모든 메서드는 이 Date 객체를 기준으로 일정의 시작/종료 시점을 설정합니다.

    예시로 확인:

    // 종일 일정: Date 하나만 필요
new Date('2025-03-02')

// 시간 지정 일정: 시작과 종료 두 개 필요
new Date('2025-03-02T09:00:00')  // 오전 9시 시작
new Date('2025-03-02T12:00:00')  // 오후 12시 종료

    주의사항: 스프레드시트에서 읽어온 날짜는 이미 Date 객체인 경우가 많습니다. 하지만 텍스트로 저장된 경우에는 반드시 new Date()로 감싸야 합니다. 이 차이를 무시하면 "Invalid Date" 오류가 발생합니다.

    개념 3: 종일 vs 시간 지정 – 분기 처리의 핵심 🔀¶

    비유: 택배를 보낼 때 "문 앞에 놓아주세요"와 "오후 2시에 직접 받겠습니다"는 처리 방식이 다릅니다. 캘린더 일정도 마찬가지로, 종일 일정과 시간 지정 일정은 등록 메서드가 다릅니다.

    분기 로직:

    flowchart TD A[일정 한 행 읽기] --> B{시작 시간이 있는가?} B -->|없음| C[createAllDayEvent 호출<br/>종일 일정 등록] B -->|있음| D{종료 시간이 있는가?} D -->|있음| E[createEvent 호출<br/>시간 지정 일정 등록] D -->|없음| F[시작 시간 +1시간을<br/>종료 시간으로 설정] F --> E

    코드 패턴:

    if (startTime === '') {
  // 종일 일정
  calendar.createAllDayEvent(title, new Date(date));
} else {
  // 시간 지정 일정
  var start = new Date(date + 'T' + startTime);
  var end = endTime ? new Date(date + 'T' + endTime) : new Date(start.getTime() + 3600000);
  calendar.createEvent(title, start, end);
}

    개념 4: 시트 → 캘린더 파이프라인 🔗¶

    비유: 공장의 컨베이어 벨트를 떠올리세요. 스프레드시트가 원재료 창고, 스크립트가 가공 라인, 캘린더가 완성품 출고입니다.

    전체 흐름:

    flowchart LR A["📋 스프레드시트<br/>(일정 목록)"] -->|getDataRange| B["⚙️ Apps Script<br/>(반복 처리)"] B -->|createEvent<br/>createAllDayEvent| C["📅 구글 캘린더<br/>(일정 등록 완료)"] B -->|setValue| D["✅ 시트에 결과 기록<br/>(등록 완료 표시)"]

    핵심 포인트: 이 파이프라인에서 가장 중요한 것은 시트의 데이터 구조입니다. 열 순서가 일관되어야 코드가 안정적으로 동작합니다.

    🔨 따라하기¶

    Step 1: 일정 입력용 시트 만들기¶

    구글 스프레드시트를 새로 만들거나, 기존 파일에 시트를 추가합니다.

    시트 이름: 학사일정

    열 구조 (1행은 헤더):

    • A열: 일정명 (예: 입학식)
    • B열: 날짜 (예: 2025-03-02, 반드시 날짜 형식으로 설정)
    • C열: 시작 시간 (예: 09:00, 종일 일정이면 비워둠)
    • D열: 종료 시간 (예: 12:00, 종일 일정이면 비워둠)
    • E열: 등록 상태 (스크립트가 자동으로 채움)

    샘플 데이터 입력 (2행부터):

    • 입학식 / 2025-03-03 / (비움) / (비움)
    • 1학기 중간고사 / 2025-04-21 / (비움) / (비움)
    • 학부모 상담 / 2025-04-25 / 09:00 / 12:00
    • 개교기념일 / 2025-05-15 / (비움) / (비움)
    • 수행평가(국어) / 2025-05-20 / 10:00 / 11:00
    • 1학기 기말고사 / 2025-07-07 / (비움) / (비움)

    실무 TIP: B열은 반드시 셀 서식을 "날짜"로 지정하세요. 텍스트로 입력하면 getValues()에서 문자열로 읽혀 Date 변환 오류가 발생합니다. 서식 → 숫자 → 날짜를 선택하세요.

    Step 2: Apps Script 편집기 열기¶

    1. 스프레드시트 상단 메뉴에서 확장 프로그램 → Apps Script 클릭
    2. 기본 생성된 myFunction을 모두 지웁니다
    3. 아래 코드를 붙여넣습니다

    Step 3: 핵심 함수 작성하기¶

    /**
 * 학사일정 시트의 데이터를 읽어 구글 캘린더에 일괄 등록합니다.
 */
function registerSchedules() {
  // 1) 시트와 캘린더 준비
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학사일정');
  var calendar = CalendarApp.getDefaultCalendar();

  // 2) 데이터 읽기 (2행부터 마지막 행까지)
  var lastRow = sheet.getLastRow();
  var data = sheet.getRange(2, 1, lastRow - 1, 5).getValues();

  var count = 0; // 등록 건수 카운터

  // 3) 한 행씩 순회하며 일정 등록
  for (var i = 0; i < data.length; i++) {
    var title = data[i][0];     // A열: 일정명
    var date = data[i][1];      // B열: 날짜
    var startTime = data[i][2]; // C열: 시작 시간
    var endTime = data[i][3];   // D열: 종료 시간
    var status = data[i][4];    // E열: 등록 상태

    // 이미 등록된 항목은 건너뛰기
    if (status === '등록완료') continue;

    // 일정명이나 날짜가 비어있으면 건너뛰기
    if (!title || !date) continue;

    try {
      // 4) 종일 vs 시간 지정 분기 처리
      if (!startTime || startTime === '') {
        // 종일 일정
        calendar.createAllDayEvent(title, new Date(date));
      } else {
        // 시간 지정 일정
        var dateStr = Utilities.formatDate(new Date(date), 'Asia/Seoul', 'yyyy-MM-dd');
        var startStr = Utilities.formatDate(new Date(startTime), 'Asia/Seoul', 'HH:mm');
        var start = new Date(dateStr + 'T' + startStr + ':00');

        var end;
        if (endTime && endTime !== '') {
          var endStr = Utilities.formatDate(new Date(endTime), 'Asia/Seoul', 'HH:mm');
          end = new Date(dateStr + 'T' + endStr + ':00');
        } else {
          // 종료 시간 없으면 1시간 후로 설정
          end = new Date(start.getTime() + 60 * 60 * 1000);
        }

        calendar.createEvent(title, start, end);
      }

      // 5) 등록 상태 업데이트
      sheet.getRange(i + 2, 5).setValue('등록완료');
      count++;

    } catch (e) {
      // 오류 발생 시 상태에 오류 메시지 기록
      sheet.getRange(i + 2, 5).setValue('오류: ' + e.message);
    }
  }

  // 6) 완료 알림
  SpreadsheetApp.getUi().alert(count + '건의 일정이 등록되었습니다.');
}

    주의사항: 스프레드시트에서 시간을 읽으면 1899-12-30T09:00:00 같은 형태의 Date 객체로 반환됩니다. 이것이 바로 Utilities.formatDate()로 시간 부분만 추출하는 이유입니다.

    Step 4: 권한 승인 및 첫 실행¶

    1. 편집기 상단의 함수 선택 드롭다운에서 registerSchedules를 선택합니다
    2. ▶ 실행 버튼을 클릭합니다
    3. 최초 실행 시 권한 승인 팝업이 나타납니다

    권한 승인 순서: - "권한 검토" 클릭 - 본인 구글 계정 선택 - "고급" 클릭 → "○○ 프로젝트(으)로 이동" 클릭 - "허용" 클릭

    실무 TIP: "이 앱은 확인되지 않았습니다" 경고는 본인이 직접 만든 스크립트이므로 안전합니다. 구글이 공식 검증하지 않은 개인 스크립트에 항상 표시되는 메시지입니다.

    Step 5: 캘린더에서 결과 확인하기¶

    1. calendar.google.com 접속
    2. 등록한 날짜로 이동하여 일정이 정상적으로 표시되는지 확인
    3. 스프레드시트의 E열에 '등록완료'가 표시되었는지 확인

    확인 체크리스트: - 종일 일정(입학식, 중간고사 등)이 날짜 위쪽 종일 영역에 표시되는가? - 시간 지정 일정(학부모 상담 등)이 해당 시간대에 표시되는가? - E열에 '등록완료' 또는 '오류' 메시지가 기록되었는가?

    Step 6: 커스텀 메뉴로 편의성 높이기¶

    매번 Apps Script 편집기를 열지 않고, 시트 메뉴에서 바로 실행할 수 있게 만듭니다.

    /**
 * 스프레드시트를 열 때 커스텀 메뉴를 추가합니다.
 */
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('📅 캘린더 도구')
    .addItem('학사일정 일괄 등록', 'registerSchedules')
    .addItem('등록 상태 초기화', 'resetStatus')
    .addToUi();
}

/**
 * E열의 등록 상태를 모두 지워 재등록할 수 있게 합니다.
 */
function resetStatus() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학사일정');
  var lastRow = sheet.getLastRow();
  if (lastRow > 1) {
    sheet.getRange(2, 5, lastRow - 1, 1).clearContent();
  }
  SpreadsheetApp.getUi().alert('등록 상태가 초기화되었습니다.');
}

    스프레드시트를 새로고침하면 메뉴바에 📅 캘린더 도구가 나타납니다.

    실무 TIP: resetStatus()는 캘린더에서 기존 일정을 삭제하지 않습니다. 상태만 초기화하므로, 다시 실행하면 중복 등록됩니다. 중복 방지 로직은 다음 챕터(14장)에서 다룹니다.

    📝 전체 코드¶

    /**
 * =============================================
 * 캘린더 일정 일괄 등록 스크립트
 * 시트명: 학사일정
 * 열 구조: A(일정명) B(날짜) C(시작시간) D(종료시간) E(상태)
 * =============================================
 */

/** 커스텀 메뉴 생성 */
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('📅 캘린더 도구')
    .addItem('학사일정 일괄 등록', 'registerSchedules')
    .addItem('등록 상태 초기화', 'resetStatus')
    .addToUi();
}

/** 메인 함수: 학사일정 일괄 등록 */
function registerSchedules() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학사일정');
  var calendar = CalendarApp.getDefaultCalendar();
  var lastRow = sheet.getLastRow();

  if (lastRow < 2) {
    SpreadsheetApp.getUi().alert('등록할 일정이 없습니다.');
    return;
  }

  var data = sheet.getRange(2, 1, lastRow - 1, 5).getValues();
  var count = 0;

  for (var i = 0; i < data.length; i++) {
    var title = data[i][0];
    var date = data[i][1];
    var startTime = data[i][2];
    var endTime = data[i][3];
    var status = data[i][4];

    if (status === '등록완료') continue;
    if (!title || !date) continue;

    try {
      if (!startTime || startTime === '') {
        calendar.createAllDayEvent(title, new Date(date));
      } else {
        var dateStr = Utilities.formatDate(
          new Date(date), 'Asia/Seoul', 'yyyy-MM-dd'
        );
        var startStr = Utilities.formatDate(
          new Date(startTime), 'Asia/Seoul', 'HH:mm'
        );
        var start = new Date(dateStr + 'T' + startStr + ':00');

        var end;
        if (endTime && endTime !== '') {
          var endStr = Utilities.formatDate(
            new Date(endTime), 'Asia/Seoul', 'HH:mm'
          );
          end = new Date(dateStr + 'T' + endStr + ':00');
        } else {
          end = new Date(start.getTime() + 60 * 60 * 1000);
        }

        calendar.createEvent(title, start, end);
      }

      sheet.getRange(i + 2, 5).setValue('등록완료');
      count++;

    } catch (e) {
      sheet.getRange(i + 2, 5).setValue('오류: ' + e.message);
    }
  }

  SpreadsheetApp.getUi().alert(count + '건의 일정이 등록되었습니다.');
}

/** 등록 상태 초기화 */
function resetStatus() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학사일정');
  var lastRow = sheet.getLastRow();
  if (lastRow > 1) {
    sheet.getRange(2, 5, lastRow - 1, 1).clearContent();
  }
  SpreadsheetApp.getUi().alert('등록 상태가 초기화되었습니다.');
}

    ⚠️ 자주 하는 실수¶

    실수 1: 날짜 열이 텍스트 형식 😵¶

    증상: "Invalid Date" 오류 발생, 또는 1970년 1월로 일정이 등록됨

    원인: B열의 셀 서식이 "일반 텍스트"로 되어 있어 getValues()가 문자열을 반환

    해결: 1. B열 전체를 선택 2. 서식 → 숫자 → 날짜 선택 3. 셀을 더블클릭하여 날짜로 재입력

    실수 2: 시트 이름 불일치 🔤¶

    증상: TypeError: Cannot call method "getLastRow" of null

    원인: 코드에서 getSheetByName('학사일정')인데 실제 시트 이름이 "학사 일정"(공백 포함)이거나 "Sheet1"

    해결: 시트 탭 이름과 코드의 문자열이 완벽히 동일한지 확인. 공백, 대소문자 모두 일치해야 합니다.

    실수 3: 시간이 '00:00'으로 등록됨 ⏰¶

    증상: C열에 "09:00"을 입력했는데 종일 일정으로 처리되거나 자정으로 등록됨

    원인: C열의 셀 서식이 "시간"이 아닌 "일반"으로 되어 있어, 스프레드시트가 숫자 900으로 인식

    해결: 1. C열과 D열을 선택 2. 서식 → 숫자 → 시간 선택 3. "09:00" 형태로 재입력

    실수 4: 중복 등록 😱¶

    증상: 같은 일정이 캘린더에 2개, 3개씩 생김

    원인: resetStatus()로 E열을 초기화한 후 다시 실행하면, 캘린더에는 이미 등록된 일정이 남아 있으므로 중복 생성

    해결: 재등록 전에 캘린더에서 기존 일정을 수동 삭제하거나, 14장에서 배울 중복 검사 로직을 추가하세요.

    ✅ 스스로 점검하기¶

    아래 항목을 모두 체크할 수 있다면 이 챕터를 완료한 것입니다.

    • CalendarApp.getDefaultCalendar()로 내 캘린더 객체를 가져올 수 있다
    • createAllDayEvent()와 createEvent()의 차이를 설명할 수 있다
    • 스프레드시트에 일정 데이터를 입력하고 일괄 등록 스크립트를 실행할 수 있다
    • 시작 시간 유무에 따라 종일/시간 지정을 분기 처리하는 코드를 이해한다
    • E열의 '등록완료' 표시를 통해 중복 실행을 방지하는 원리를 안다
    • 커스텀 메뉴(onOpen)를 만들어 편리하게 스크립트를 실행할 수 있다
