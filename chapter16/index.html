    구글 클래스룸 자동 생성 ② – 과제 등록과 공지 자동화¶

    🎯 이 장에서 배우는 것¶

    • 생성된 클래스룸에 과제를 코드로 일괄 등록할 수 있다
    • 공지사항을 여러 수업에 동시에 게시할 수 있다
    • 과제 마감일 설정, 첨부파일 연결 등 세부 옵션을 적용할 수 있다
    • 스프레드시트 기반 과제 템플릿으로 반복 작업을 제거할 수 있다

    💡 왜 이걸 배우나요?¶

    🎬 실무 시나리오: 새 학기가 시작됐습니다. 8개 반 구글 클래스룸에 동일한 수행평가 과제 3개, 학기 초 공지사항 2개를 등록해야 합니다. 한 반당 5분이면 총 40분. 매주 반복되면 한 달에 160분이 사라집니다.

    지난 15차시에서 클래스룸을 자동으로 "만드는" 방법을 배웠습니다. 빈 교실은 만들었지만, 교실 안에 교재와 안내문을 배치하지 않으면 수업이 시작될 수 없습니다. 이번 차시는 빈 교실에 가구를 채우는 작업을 자동화합니다.

    이 장을 마치면 달라지는 것:

    • ❌ 8개 반 × 3개 과제 = 24번 수동 클릭 → ✅ 스크립트 한 번 실행으로 끝
    • ❌ 공지사항 복사-붙여넣기 반복 → ✅ 전체 수업에 동시 게시
    • ❌ 마감일·첨부파일 누락 실수 → ✅ 시트에서 관리, 코드가 정확히 반영

    📚 핵심 개념¶

    개념 1: CourseWork – 과제 객체의 구조¶

    🏗️ 비유: 과제를 우편물이라고 생각해보세요. 봉투(제목)에 내용물(설명)을 넣고, 마감 날짜 스탬프를 찍고, 참고자료(첨부파일)를 동봉해서 특정 교실(courseId)에 배달하는 것입니다.

    정확한 정의: CourseWork는 Classroom API에서 과제를 표현하는 객체입니다. 하나의 CourseWork에는 다음 정보가 담깁니다.

    • courseId – 어떤 수업에 등록할지 (배달 주소)
    • title – 과제 제목
    • description – 과제 설명
    • dueDate / dueTime – 마감일과 마감 시각 (UTC 기준)
    • materials – 첨부 파일이나 링크
    • workType – ASSIGNMENT(과제), SHORT_ANSWER(단답형) 등
    • state – PUBLISHED(즉시 게시) 또는 DRAFT(임시 저장)

    예시로 확인:

    // 가장 기본적인 과제 객체
var courseWork = {
  title: "1주차 수행평가: 자기소개 에세이",
  description: "A4 1장 분량으로 자기소개를 작성하세요.",
  workType: "ASSIGNMENT",
  state: "PUBLISHED",
  dueDate: { year: 2025, month: 3, day: 21 },
  dueTime: { hours: 14, minutes: 59 }  // UTC 기준 → 한국시간 23:59
};

    실무 TIP 🕐: dueTime은 UTC 기준입니다. 한국(KST)은 UTC+9이므로, 한국시간 23:59에 마감하려면 hours: 14, minutes: 59로 설정하세요.

    개념 2: Announcement – 공지사항 객체¶

    📢 비유: 공지사항은 교실 게시판에 붙이는 안내문입니다. 과제와 달리 제출할 것이 없고, "읽으세요"가 목적입니다.

    정확한 정의: Announcement는 과제 제출 없이 정보만 전달하는 게시물입니다. CourseWork보다 구조가 단순합니다.

    • courseId – 대상 수업
    • text – 공지 내용 (제목과 본문이 하나)
    • materials – 첨부 파일이나 링크 (선택)
    • state – PUBLISHED 또는 DRAFT
    var announcement = {
  text: "📌 [학기 초 안내] 수업 규칙과 평가 기준을 첨부파일에서 확인하세요.",
  state: "PUBLISHED",
  materials: [
    { link: { url: "https://docs.google.com/document/d/xxxx" } }
  ]
};

    개념 3: Materials – 첨부 자료의 4가지 유형¶

    📎 비유: 이메일에 파일을 첨부하는 것과 같습니다. 다만 Classroom API는 첨부 유형을 명확히 구분합니다.

    graph LR A[Materials 첨부 유형] --> B["driveFile<br/>구글 드라이브 파일"] A --> C["link<br/>웹 URL 링크"] A --> D["youtubeVideo<br/>유튜브 영상"] A --> E["form<br/>구글 설문지"]

    실무에서 가장 많이 쓰는 유형 2가지:

    • driveFile – 드라이브에 있는 문서, 시트, PDF 등을 첨부할 때
    • link – 외부 사이트 URL을 참고자료로 걸 때
    // 드라이브 파일 첨부
{ driveFile: { driveFile: { id: "파일ID", title: "수업규칙.pdf" } } }

// 링크 첨부
{ link: { url: "https://example.com/참고자료", title: "참고사이트" } }

    실무 TIP 📁: 드라이브 파일 ID는 파일 URL에서 /d/ 뒤의 문자열입니다. 예: https://drive.google.com/file/d/1AbCdEfGhIjK/view

    개념 4: 스프레드시트 템플릿 기반 일괄 처리 패턴¶

    📋 비유: 식당 주문서를 생각해보세요. 시트의 각 행이 하나의 주문(과제)이고, 코드는 주방(API)에 주문서를 순서대로 전달하는 웨이터입니다.

    핵심 패턴:

    graph TD A["📋 스프레드시트<br/>과제 정보 입력"] --> B["🔄 Apps Script<br/>행 단위로 읽기"] B --> C["🏫 Classroom API<br/>과제/공지 생성"] C --> D["✅ 시트에 결과 기록<br/>성공/실패 표시"]

    시트 구조 설계:

    • A열: 수업 ID (courseId)
    • B열: 유형 (과제 / 공지)
    • C열: 제목
    • D열: 설명
    • E열: 마감일 (과제만)
    • F열: 첨부 URL (선택)
    • G열: 처리 결과 (코드가 자동 기록)

    핵심 포인트 💎: "데이터는 시트에, 로직은 코드에" 원칙을 지키면 과제 내용이 바뀌어도 코드를 수정할 필요가 없습니다.

    🔨 따라하기¶

    사전 준비¶

    지난 15차시에서 만든 프로젝트와 클래스룸이 있어야 합니다. Classroom API가 이미 활성화되어 있다고 가정합니다. 없다면 15차시를 먼저 완료하세요.

    Step 1: 과제 정보 시트 만들기¶

    구글 스프레드시트를 열고 시트 이름을 과제목록으로 변경합니다.

    1행(헤더)에 다음을 입력하세요:

    • A1: courseId
    • B1: 유형
    • C1: 제목
    • D1: 설명
    • E1: 마감일
    • F1: 첨부URL
    • G1: 결과

    2행부터 샘플 데이터를 입력합니다:

    • 2행: courseId값 / 과제 / 1주차 수행평가: 자기소개 에세이 / A4 1장 분량으로 자기소개를 작성하세요 / 2025-03-21 / (비워둠) / (비워둠)
    • 3행: courseId값 / 과제 / 2주차 과제: 독서 감상문 / 지정 도서를 읽고 감상문을 제출하세요 / 2025-03-28 / https://docs.google.com/document/d/xxxx / (비워둠)
    • 4행: courseId값 / 공지 / (비워둠) / 📌 학기 초 공지: 수업 규칙 안내입니다. 첨부파일을 확인하세요. / (비워둠) / https://docs.google.com/document/d/yyyy / (비워둠)

    실무 TIP 📝: courseId는 15차시에서 클래스룸 생성 시 시트 G열에 기록된 값입니다. 여러 반에 동일 과제를 등록하려면 같은 과제를 courseId만 바꿔서 여러 행으로 입력하면 됩니다.

    Step 2: 단일 과제 등록 함수 작성¶

    스프레드시트에서 확장 프로그램 → Apps Script를 열고 다음 코드를 입력합니다.

    /**
 * 하나의 과제를 특정 수업에 등록하는 함수
 */
function createSingleCourseWork(courseId, title, description, dueDateStr, attachUrl) {

  var courseWork = {
    title: title,
    description: description,
    workType: "ASSIGNMENT",
    state: "PUBLISHED"
  };

  // 마감일 설정 (형식: "2025-03-21")
  if (dueDateStr) {
    var parts = dueDateStr.split("-");
    courseWork.dueDate = {
      year: parseInt(parts[0]),
      month: parseInt(parts[1]),
      day: parseInt(parts[2])
    };
    // 한국시간 23:59 마감 = UTC 14:59
    courseWork.dueTime = { hours: 14, minutes: 59 };
  }

  // 첨부파일 설정
  if (attachUrl) {
    courseWork.materials = [
      { link: { url: attachUrl } }
    ];
  }

  var response = Classroom.Courses.CourseWork.create(courseWork, courseId);
  return response.id;
}

    주의사항 ⚠️: Classroom.Courses.CourseWork.create()는 Apps Script의 고급 서비스를 통해 호출합니다. 15차시에서 Classroom API 고급 서비스를 이미 활성화했다면 바로 사용 가능합니다.

    Step 3: 공지사항 등록 함수 작성¶

    같은 스크립트 파일에 이어서 작성합니다.

    /**
 * 하나의 공지사항을 특정 수업에 게시하는 함수
 */
function createSingleAnnouncement(courseId, text, attachUrl) {

  var announcement = {
    text: text,
    state: "PUBLISHED"
  };

  // 첨부파일 설정
  if (attachUrl) {
    announcement.materials = [
      { link: { url: attachUrl } }
    ];
  }

  var response = Classroom.Courses.Announcements.create(announcement, courseId);
  return response.id;
}

    Step 4: 시트 데이터를 읽어서 일괄 처리하는 메인 함수¶

    /**
 * 시트의 모든 행을 읽어서 과제/공지를 일괄 등록
 */
function batchCreateFromSheet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("과제목록");
  var data = sheet.getDataRange().getValues();

  // 1행은 헤더이므로 2행부터 시작 (인덱스 1)
  for (var i = 1; i < data.length; i++) {
    var row = data[i];
    var courseId  = String(row[0]).trim();
    var type      = String(row[1]).trim();
    var title     = String(row[2]).trim();
    var desc      = String(row[3]).trim();
    var dueDate   = row[4] ? formatDate_(row[4]) : "";
    var attachUrl = String(row[5]).trim();

    // 이미 처리된 행은 건너뛰기
    if (String(row[6]).trim() !== "") {
      continue;
    }

    // courseId가 비어있으면 건너뛰기
    if (!courseId) continue;

    try {
      var resultId = "";

      if (type === "과제") {
        resultId = createSingleCourseWork(courseId, title, desc, dueDate, attachUrl);
        sheet.getRange(i + 1, 7).setValue("✅ 과제등록 ID:" + resultId);

      } else if (type === "공지") {
        resultId = createSingleAnnouncement(courseId, desc, attachUrl);
        sheet.getRange(i + 1, 7).setValue("✅ 공지등록 ID:" + resultId);
      }

      // API 호출 간격 조절 (과부하 방지)
      Utilities.sleep(1000);

    } catch (e) {
      sheet.getRange(i + 1, 7).setValue("❌ 오류: " + e.message);
      Logger.log("행 " + (i + 1) + " 오류: " + e.message);
    }
  }

  SpreadsheetApp.getUi().alert("일괄 등록이 완료되었습니다! 결과열(G)을 확인하세요.");
}

/**
 * 날짜를 "YYYY-MM-DD" 문자열로 변환하는 헬퍼 함수
 */
function formatDate_(value) {
  if (value instanceof Date) {
    var y = value.getFullYear();
    var m = ("0" + (value.getMonth() + 1)).slice(-2);
    var d = ("0" + value.getDate()).slice(-2);
    return y + "-" + m + "-" + d;
  }
  return String(value).trim();
}

    1. Apps Script 편집기 상단에서 함수 선택 → batchCreateFromSheet 선택
    2. ▶ 실행 클릭
    3. 최초 실행 시 권한 승인 팝업 → 허용
    4. 스프레드시트로 돌아가 G열 확인
    5. ✅ 과제등록 ID:xxxxx → 성공

    6. ❌ 오류: ... → 오류 내용 확인 후 수정

    7. 구글 클래스룸에 접속하여 실제로 과제와 공지가 등록되었는지 확인

    실무 TIP 🔄: 오류가 난 행만 G열을 지우고 다시 실행하면 해당 행만 재처리됩니다. 이미 ✅가 있는 행은 자동으로 건너뜁니다.

    Step 6: 여러 수업에 동시 게시 – 실전 활용¶

    8개 반에 같은 과제를 등록하려면 시트를 이렇게 구성합니다:

    행2: courseId_1반 / 과제 / 1주차 수행평가 / 설명... / 2025-03-21 / /
행3: courseId_2반 / 과제 / 1주차 수행평가 / 설명... / 2025-03-21 / /
행4: courseId_3반 / 과제 / 1주차 수행평가 / 설명... / 2025-03-21 / /
... (8개 반 모두)

    매번 이렇게 복사하기 번거롭다면, 자동 확장 함수를 추가하세요:

    /**
 * 하나의 과제를 여러 수업에 동시 등록
 * courseIds: 쉼표로 구분된 수업 ID 문자열
 */
function createWorkForMultipleClasses(courseIds, title, desc, dueDate, attachUrl) {
  var ids = courseIds.split(",");
  var results = [];

  for (var i = 0; i < ids.length; i++) {
    var cid = ids[i].trim();
    try {
      var workId = createSingleCourseWork(cid, title, desc, dueDate, attachUrl);
      results.push(cid + ": ✅");
      Utilities.sleep(1000);
    } catch (e) {
      results.push(cid + ": ❌ " + e.message);
    }
  }

  return results.join("\n");
}

    이 함수를 사용하면 A열에 id1, id2, id3, ...처럼 쉼표로 여러 수업 ID를 넣고 한 행으로 처리할 수 있습니다.

    📝 전체 코드¶

    // ===================================
// 구글 클래스룸 과제·공지 일괄 등록
// 시트명: "과제목록"
// 열 구성: A-courseId, B-유형, C-제목, D-설명, E-마감일, F-첨부URL, G-결과
// ===================================

function createSingleCourseWork(courseId, title, description, dueDateStr, attachUrl) {
  var courseWork = {
    title: title,
    description: description,
    workType: "ASSIGNMENT",
    state: "PUBLISHED"
  };

  if (dueDateStr) {
    var parts = dueDateStr.split("-");
    courseWork.dueDate = {
      year: parseInt(parts[0]),
      month: parseInt(parts[1]),
      day: parseInt(parts[2])
    };
    courseWork.dueTime = { hours: 14, minutes: 59 };
  }

  if (attachUrl) {
    courseWork.materials = [{ link: { url: attachUrl } }];
  }

  var response = Classroom.Courses.CourseWork.create(courseWork, courseId);
  return response.id;
}

function createSingleAnnouncement(courseId, text, attachUrl) {
  var announcement = {
    text: text,
    state: "PUBLISHED"
  };

  if (attachUrl) {
    announcement.materials = [{ link: { url: attachUrl } }];
  }

  var response = Classroom.Courses.Announcements.create(announcement, courseId);
  return response.id;
}

    ⚠️ 자주 하는 실수¶

    실수 1: 마감 시간을 한국 시간으로 넣는다¶

    // ❌ 잘못된 예 – 한국시간 23:59를 그대로 입력
courseWork.dueTime = { hours: 23, minutes: 59 };
// → 실제로는 한국시간 다음날 오전 8:59에 마감됨!

// ✅ 올바른 예 – UTC로 변환 (한국시간 -9시간)
courseWork.dueTime = { hours: 14, minutes: 59 };
// → 한국시간 23:59 정확히 마감

    Classroom API의 시간은 항상 UTC입니다. 한국시간에서 9시간을 빼세요.

    실수 2: 공지사항에 title 필드를 넣는다¶

    // ❌ 잘못된 예 – Announcement에는 title 필드가 없음
var announcement = {
  title: "학기 초 공지",  // API 오류 발생!
  text: "내용..."
};

// ✅ 올바른 예 – text 필드 하나에 제목과 내용을 함께 작성
var announcement = {
  text: "📌 [학기 초 공지] 내용...",
  state: "PUBLISHED"
};

    CourseWork는 title + description, Announcement는 text 하나뿐입니다. 구조가 다릅니다.

    실수 3: 드라이브 파일 공유 설정을 잊는다¶

    첨부한 드라이브 파일이 "비공개"로 되어 있으면 학생이 열 수 없습니다.

    • 링크가 있는 모든 사용자 또는 조직 내 사용자로 공유 설정을 먼저 변경하세요
    • API로 첨부할 때 자동으로 공유 권한이 바뀌지 않습니다

    실수 4: API 호출 속도 제한을 무시한다¶

    // ❌ sleep 없이 연속 호출 → 429 Too Many Requests 오류
for (var i = 0; i < 50; i++) {
  Classroom.Courses.CourseWork.create(...);
}

// ✅ 호출 사이에 1초 대기
for (var i = 0; i < 50; i++) {
  Classroom.Courses.CourseWork.create(...);
  Utilities.sleep(1000);  // 필수!
}

    ✅ 스스로 점검하기¶

    다음 항목을 모두 체크할 수 있다면 이 차시를 완료한 것입니다.

    • 스프레드시트에 과제 정보 시트(과제목록)를 만들었다
    • batchCreateFromSheet() 함수를 실행하여 과제가 실제 클래스룸에 등록되었다
    • 공지사항이 정상적으로 게시되었다
    • 마감일이 한국시간 기준으로 정확히 설정되었다 (UTC 변환 확인)
    • 첨부 URL이 과제/공지에 정상적으로 연결되었다
    • G열에 ✅ 결과가 기록되고, 재실행 시 중복 등록되지 않는다
    • 오류가 발생한 행만 G열을 지우고 재실행하여 복구할 수 있다

courseWork.materials = [

courseWork.state = "DRAFT";

// 나중에 상태 변경 (scheduledDate에 트리거 설정)
Classroom.Courses.CourseWork.patch(
  { state: "PUBLISHED" },
  courseId,
  courseWorkId,
  { updateMask: "state" }
