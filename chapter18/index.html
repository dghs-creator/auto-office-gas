    개별 문서 자동 생성 ② – PDF 변환과 폴더 정리¶

    Part 5 | [2권] 문서 생성·성적 처리 자동화 – 개별 문서와 성적을 한 번에

    🎯 이 장에서 배우는 것¶

    • 생성된 구글 문서를 PDF로 자동 변환할 수 있다
    • 학년별·반별 폴더를 자동 생성하고 문서를 분류하여 저장할 수 있다
    • 문서 공유 권한을 코드로 설정할 수 있다
    • PDF 변환 + 폴더 정리 + 권한 설정을 하나의 워크플로우로 통합할 수 있다

    💡 왜 이걸 배우나요?¶

    지난 장에서 스프레드시트 데이터를 기반으로 개별 문서 30개를 자동 생성했습니다. 그런데 현실은 여기서 끝나지 않습니다.

    "문서 30개를 하나하나 열어서 PDF로 다운로드하고, 반별 폴더에 나눠 넣고, 담당자에게 공유 설정까지…"

    이 후속 작업이 문서 생성만큼, 아니 그 이상으로 시간을 잡아먹습니다.

    택배 비유로 생각해 보세요. 지난 장에서 우리는 30개의 택배 상자를 포장했습니다(문서 생성). 이번 장에서는 그 상자에 송장을 붙이고(PDF 변환), 배송 구역별로 분류하고(폴더 정리), 수령인에게 배송 알림을 보내는(공유 권한 설정) 작업을 자동화합니다.

    실무 TIP: PDF 변환이 필요한 대표적 상황 - 📄 가정통신문: 수정 불가한 PDF로 배포해야 할 때 - 🏆 수상장/인증서: 인쇄용 고정 포맷이 필요할 때 - 📊 성적표/평가서: 개인정보 보호를 위해 편집 차단이 필요할 때 - 📋 계약서/제안서: 원본 보존이 중요한 비즈니스 문서

    📚 핵심 개념¶

    개념 1: PDF 변환의 원리 – getAs()¶

    🎨 비유: 구글 문서를 PDF로 변환하는 것은 요리를 도시락에 담는 것과 같습니다. 접시 위의 요리(구글 문서)는 자유롭게 추가·수정할 수 있지만, 도시락(PDF)에 담으면 고정된 상태로 안전하게 전달됩니다.

    정확한 정의: getAs(MimeType) 메서드는 구글 드라이브의 파일을 다른 형식의 Blob(바이너리 데이터 덩어리)으로 변환합니다. PDF 변환 시 MimeType.PDF를 사용합니다.

    예시로 확인:

    // 구글 문서를 PDF Blob으로 변환
var doc = DriveApp.getFileById('문서ID');
var pdfBlob = doc.getAs(MimeType.PDF);
pdfBlob.setName('가정통신문_홍길동.pdf');

    여기서 Blob은 파일의 실체(바이너리 데이터)를 담은 객체입니다. 이 Blob을 폴더에 저장하면 실제 PDF 파일이 생성됩니다.

    핵심 포인트: getAs(MimeType.PDF)는 원본 문서를 건드리지 않고 복사본을 PDF 형태로 만들어냅니다. 원본은 그대로 남아 있습니다.

    개념 2: 폴더 자동 생성 – DriveApp.createFolder()¶

    📁 비유: 서류 캐비닛에 새 칸막이를 꽂는 것과 같습니다. DriveApp은 구글 드라이브를 프로그래밍으로 조작하는 리모컨이고, createFolder()는 "새 칸막이 만들기" 버튼입니다.

    정확한 정의: DriveApp은 구글 드라이브의 파일과 폴더를 생성·이동·삭제·검색할 수 있는 Apps Script 내장 서비스입니다.

    폴더 구조 설계:

    graph TD A["📁 2024 가정통신문"] --> B["📁 1학년"] A --> C["📁 2학년"] A --> D["📁 3학년"] B --> B1["📁 1반"] B --> B2["📁 2반"] C --> C1["📁 1반"] C --> C2["📁 2반"] D --> D1["📁 1반"] D --> D2["📁 2반"] B1 --> F1["📄 홍길동.pdf"] B1 --> F2["📄 김영희.pdf"]

    예시로 확인:

    // 상위 폴더 생성
var rootFolder = DriveApp.createFolder('2024 가정통신문');

// 하위 폴더 생성 (상위 폴더 안에)
var gradeFolder = rootFolder.createFolder('1학년');
var classFolder = gradeFolder.createFolder('1반');

    핵심 포인트: 폴더 안에 폴더를 만들 때는 상위 폴더 객체의 createFolder()를 호출합니다. DriveApp.createFolder()는 최상위(내 드라이브)에 생성합니다.

    개념 3: 중복 폴더 방지 – 있으면 쓰고, 없으면 만들기¶

    🔍 비유: 냉장고를 열어 우유가 있는지 확인하고, 없을 때만 사세요. 코드를 여러 번 실행하면 같은 이름의 폴더가 계속 생기는 문제를 방지합니다.

    정확한 정의: getFoldersByName()으로 기존 폴더를 검색하고, hasNext()로 존재 여부를 확인한 후 조건 분기합니다.

    function getOrCreateFolder(parentFolder, folderName) {
  var folders = parentFolder.getFoldersByName(folderName);
  if (folders.hasNext()) {
    return folders.next(); // 기존 폴더 반환
  } else {
    return parentFolder.createFolder(folderName); // 새로 생성
  }
}

    주의사항: getFoldersByName()은 정확한 이름 일치만 검색합니다. "1학년"과 "1 학년"(공백 포함)은 다른 이름으로 인식됩니다. 스프레드시트의 데이터 정합성이 중요합니다.

    핵심 포인트: getOrCreateFolder 패턴은 실무에서 가장 많이 쓰는 유틸리티 함수입니다. 한 번 만들어 두면 모든 프로젝트에서 재활용할 수 있습니다.

    개념 4: 공유 권한 설정 – addViewer() / addEditor()¶

    🔐 비유: 문서에 자물쇠를 채우고 열쇠의 종류를 정하는 것입니다. "읽기 전용 열쇠"를 주면 내용만 볼 수 있고, "편집 열쇠"를 주면 내용을 수정할 수 있습니다.

    정확한 정의:

    • addViewer(email) — 보기 전용 권한 부여
    • addEditor(email) — 편집 권한 부여
    • setSharing(accessType, permissionType) — 전체 공유 범위 설정
    // 특정 사용자에게 보기 전용 권한 부여
var file = DriveApp.getFileById('파일ID');
file.addViewer('student@school.com');

// 링크가 있는 사용자 누구나 보기 가능하게 설정
file.setSharing(
  DriveApp.Access.ANYONE_WITH_LINK, 
  DriveApp.Permission.VIEW
);

    핵심 포인트: 성적표나 개인 문서는 반드시 addViewer()로 개별 공유하세요. ANYONE_WITH_LINK는 링크가 유출되면 누구나 볼 수 있어 개인정보 문서에는 부적합합니다.

    🔨 따라하기¶

    실습 시나리오¶

    스프레드시트에 학생 정보가 있고, 이미 개별 구글 문서가 생성되어 있다고 가정합니다. 이번 실습에서는 PDF 변환 → 폴더 정리 → 권한 설정을 한 번에 처리합니다.

    스프레드시트 구조 (시트명: "학생목록")

    • A열: 이름
    • B열: 학년
    • C열: 반
    • D열: 이메일
    • E열: 문서ID (지난 장에서 생성된 구글 문서 ID)

    예시 데이터:

    • 행2: 홍길동 / 1 / 1 / hong@school.com / (문서ID)
    • 행3: 김영희 / 1 / 2 / kim@school.com / (문서ID)
    • 행4: 박철수 / 2 / 1 / park@school.com / (문서ID)

    Step 1: 스프레드시트에 테스트 데이터 준비¶

    1. 구글 스프레드시트를 새로 만들거나, 지난 장에서 사용한 파일을 엽니다
    2. "학생목록" 시트에 위 구조대로 데이터를 입력합니다
    3. E열(문서ID)은 일단 비워두고, 테스트용 구글 문서를 2~3개 수동 생성한 뒤 그 ID를 넣어주세요

    실무 TIP: 구글 문서의 ID는 URL에서 확인합니다. https://docs.google.com/document/d/여기가_문서ID/edit 에서 굵은 부분이 ID입니다.

    Step 2: 유틸리티 함수 작성¶

    Apps Script 편집기(확장 프로그램 → Apps Script)를 열고 다음 코드를 입력합니다.

    /**
 * 상위 폴더 안에서 이름으로 폴더를 찾고, 없으면 새로 생성
 */
function getOrCreateFolder(parentFolder, folderName) {
  var folders = parentFolder.getFoldersByName(folderName);
  if (folders.hasNext()) {
    Logger.log('기존 폴더 사용: ' + folderName);
    return folders.next();
  }
  Logger.log('새 폴더 생성: ' + folderName);
  return parentFolder.createFolder(folderName);
}

    이 함수는 이후 모든 단계에서 반복 호출됩니다. 한 번 정의해 두면 끝입니다.

    Step 3: 폴더 구조 자동 생성¶

    /**
 * 스프레드시트 데이터를 읽어 폴더 구조를 미리 생성
 */
function createFolderStructure() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('학생목록');
  var data = sheet.getDataRange().getValues();

  // 최상위 폴더 생성 (내 드라이브에)
  var rootFolder = getOrCreateFolder(
    DriveApp.getRootFolder(), 
    '2024 가정통신문 PDF'
  );

  // 2행부터 (1행은 헤더)
  for (var i = 1; i < data.length; i++) {
    var grade = data[i][1]; // B열: 학년
    var cls = data[i][2];   // C열: 반

    if (!grade || !cls) continue; // 빈 행 건너뛰기

    var gradeFolder = getOrCreateFolder(rootFolder, grade + '학년');
    var classFolder = getOrCreateFolder(gradeFolder, cls + '반');
  }

  Logger.log('폴더 구조 생성 완료!');
  Logger.log('루트 폴더: ' + rootFolder.getUrl());
}

    Step 4: PDF 변환 + 폴더 저장 통합¶

    이 단계가 핵심입니다. 문서를 PDF로 변환하고, 해당 학생의 반 폴더에 저장합니다.

    /**
 * 개별 문서를 PDF로 변환하여 반별 폴더에 저장
 */
function convertToPdfAndOrganize() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('학생목록');
  var data = sheet.getDataRange().getValues();

  // 최상위 폴더 찾기
  var rootFolder = getOrCreateFolder(
    DriveApp.getRootFolder(), 
    '2024 가정통신문 PDF'
  );

  var successCount = 0;
  var errorCount = 0;

  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];    // A열: 이름
    var grade = data[i][1];   // B열: 학년
    var cls = data[i][2];     // C열: 반
    var docId = data[i][4];   // E열: 문서ID

    // 필수 데이터 확인
    if (!name || !docId) {
      Logger.log('행 ' + (i+1) + ': 데이터 누락, 건너뜀');
      errorCount++;
      continue;
    }

    try {
      // 1) 대상 폴더 준비
      var gradeFolder = getOrCreateFolder(rootFolder, grade + '학년');
      var classFolder = getOrCreateFolder(gradeFolder, cls + '반');

      // 2) 문서를 PDF로 변환
      var docFile = DriveApp.getFileById(docId);
      var pdfBlob = docFile.getAs(MimeType.PDF);
      pdfBlob.setName('가정통신문_' + name + '.pdf');

      // 3) 해당 폴더에 PDF 저장
      var pdfFile = classFolder.createFile(pdfBlob);

      Logger.log('✅ ' + name + ' → ' + pdfFile.getUrl());
      successCount++;

    } catch (e) {
      Logger.log('❌ ' + name + ' 오류: ' + e.message);
      errorCount++;
    }

    // API 호출 제한 방지 (0.5초 대기)
    Utilities.sleep(500);
  }

  Logger.log('=== 완료 ===');
  Logger.log('성공: ' + successCount + '건, 실패: ' + errorCount + '건');
}

    Step 5: 공유 권한 자동 설정¶

    PDF가 저장되었으면, 학생(또는 학부모)에게 보기 전용 권한을 부여합니다.

    /**
 * 생성된 PDF에 보기 전용 권한을 부여
 */
function sharePdfWithStudents() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('학생목록');
  var data = sheet.getDataRange().getValues();

  var rootFolder = getOrCreateFolder(
    DriveApp.getRootFolder(), 
    '2024 가정통신문 PDF'
  );

  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];
    var grade = data[i][1];
    var cls = data[i][2];
    var email = data[i][3]; // D열: 이메일

    if (!name || !email) continue;

    try {
      var gradeFolder = getOrCreateFolder(rootFolder, grade + '학년');
      var classFolder = getOrCreateFolder(gradeFolder, cls + '반');

      // 파일명으로 PDF 검색
      var fileName = '가정통신문_' + name + '.pdf';
      var files = classFolder.getFilesByName(fileName);

      if (files.hasNext()) {
        var pdfFile = files.next();
        pdfFile.addViewer(email);
        Logger.log('🔓 ' + name + '(' + email + ') 공유 완료');
      } else {
        Logger.log('⚠️ ' + name + ' PDF 파일 없음');
      }

    } catch (e) {
      Logger.log('❌ ' + name + ' 공유 오류: ' + e.message);
    }

    Utilities.sleep(300);
  }

  Logger.log('공유 설정 완료!');
}

    📝 전체 코드¶

    아래는 위의 모든 함수를 하나로 합친 전체 코드입니다. 복사하여 바로 사용할 수 있습니다.

    // ==========================================
// 유틸리티 함수
// ==========================================

function getOrCreateFolder(parentFolder, folderName) {
  var folders = parentFolder.getFoldersByName(folderName);
  if (folders.hasNext()) {
    return folders.next();
  }
  return parentFolder.createFolder(folderName);
}

// ==========================================

}

function convertToPdfAndOrganize() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet()
                            .getSheetByName('학생목록');
  var data = sheet.getDataRange().getValues();
  var rootFolder = getOrCreateFolder(

    ⚠️ 자주 하는 실수¶

    실수 1: PDF를 실행할 때마다 중복 생성¶

    증상: 스크립트를 2번 실행하니 같은 PDF가 2개씩 생겼다.

    원인: 폴더는 getOrCreateFolder로 중복 방지했지만, 파일은 별도 체크 없이 createFile을 호출했기 때문입니다.

    해결법: PDF 생성 전에 동일 이름 파일이 있는지 확인하세요.

    // PDF 생성 전 중복 체크 추가
var existingFiles = classFolder.getFilesByName(fileName);
if (existingFiles.hasNext()) {
  // 기존 파일 삭제 후 재생성 (또는 건너뛰기)
  existingFiles.next().setTrashed(true);
}
classFolder.createFile(pdfBlob);

    실수 2: API 호출 제한(Rate Limit)으로 오류 발생¶

    증상: 50건 이상 처리 시 Exception: Service invoked too many times 오류

    원인: 구글 API는 단시간 내 과도한 호출을 제한합니다.

    해결법: Utilities.sleep()으로 호출 간격을 확보하세요. 100건 이상이면 배치 처리(20건씩 나누어 실행)를 고려합니다.

    // 매 20건마다 추가 대기
if (i % 20 === 0 && i > 0) {
  Logger.log(i + '건 처리 완료, 5초 대기...');
  Utilities.sleep(5000);
}

    실수 3: 이메일 형식 오류로 공유 실패¶

    증상: addViewer() 호출 시 Invalid email 오류

    원인: 스프레드시트의 이메일 셀에 공백이 포함되었거나 형식이 잘못된 경우

    해결법: 이메일 값을 trim()으로 정리하고, 기본 형식을 검증하세요.

    var email = data[i][3].toString().trim();

// 간단한 이메일 형식 검증
if (email.indexOf('@') === -1) {
  Logger.log('잘못된 이메일: ' + email);
  continue;
}

    실수 4: 문서ID 열이 비어 있는데 실행¶

    증상: DriveApp.getFileById(null) → Exception: Invalid argument: id

    원인: 지난 장의 문서 생성을 하지 않았거나, E열에 ID를 기록하지 않은 상태

    해결법: 코드 상단의 필수 데이터 확인 로직(if (!name || !docId) continue;)이 이를 방어합니다. 반드시 유효성 검사를 넣으세요.

    ✅ 스스로 점검하기¶

    아래 항목을 하나씩 체크해 보세요.

    • getOrCreateFolder 함수의 역할을 설명할 수 있다
    • getAs(MimeType.PDF)가 원본 문서를 변경하지 않는다는 것을 이해했다
    • 구글 드라이브에 "학년 → 반" 폴더 구조가 자동 생성된 것을 확인했다
    • PDF 파일이 올바른 반 폴더에 저장된 것을 확인했다
    • addViewer()와 addEditor()의 차이를 알고 있다
    • 스크립트를 재실행해도 폴더가 중복 생성되지 않는 것을 확인했다
    • API 호출 제한을 방지하기 위한 방법을 알고 있다
