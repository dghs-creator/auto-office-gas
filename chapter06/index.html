    📋 Chapter 06. 신청서 자동 집계 ① – 구글 폼 응답을 깔끔하게 정리하기¶

    Part 2: 데이터 수집·정리 자동화 – 신청서와 설문을 코드로 해결하기 | 6차시 / 25차시

    🎯 이 장에서 배우는 것¶

    • 구글 폼 응답 시트의 데이터를 Apps Script로 읽어올 수 있다
    • 응답을 반별·항목별로 자동 분류하는 코드를 작성할 수 있다
    • 중복 응답과 빈 값 등 예외 상황을 처리하는 코드를 적용할 수 있다
    • 자동 집계 스크립트를 트리거에 연결해 "손 안 대는 파이프라인"을 만들 수 있다

    💡 왜 이걸 배우나요?¶

    3월 초, 체험학습 신청서 30건이 구글 폼으로 쏟아져 들어옵니다. 담당자 A 씨는 응답 시트를 열어 한 줄씩 읽으며 부서별로 색을 칠하고, 중복 제출은 없는지 눈으로 확인하고, 빈 칸이 있으면 직접 연락합니다. 30분이면 끝날 일이 2시간이 됩니다.

    이 작업의 본질은 단순합니다.

    "원본 데이터 → 분류 → 예외 처리 → 정리된 결과"

    반복적이고 규칙이 명확한 작업은 코드에 맡기기 딱 좋은 일입니다. 이번 장에서 만드는 스크립트를 한 번 세팅해 두면, 다음부터는 폼 응답이 들어올 때마다 자동으로 깔끔한 집계표가 만들어집니다.

    실무 TIP: 이 패턴은 신청서뿐 아니라 설문 결과 정리, 교육 수요 조사, 행사 참가 접수 등 "구글 폼 → 시트 정리"가 필요한 모든 업무에 그대로 적용됩니다.

    📚 핵심 개념¶

    개념 1: 구글 폼 응답 시트의 구조¶

    🎒 비유 — 구글 폼 응답 시트는 우체통입니다. 누가 언제 어떤 내용을 넣었는지 시간순으로 차곡차곡 쌓입니다. 우리가 할 일은 이 우체통에서 편지를 꺼내 수신인별 서랍에 넣는 것입니다.

    정확한 정의 - 구글 폼에 "응답을 스프레드시트로 보기"를 설정하면, 시트 첫 행이 질문(헤더), 이후 행이 각 응답이 됩니다. - A열은 항상 타임스탬프, 이후 열은 폼 질문 순서대로 배치됩니다.

    예시 — "방과후 수강 신청" 폼의 응답 시트

    • A열: 타임스탬프 (2025-03-01 09:12:34)
    • B열: 이름
    • C열: 부서(반)
    • D열: 신청 과목
    • E열: 연락처

    핵심 포인트: 코드에서 데이터를 읽을 때 헤더 행(1행)은 건너뛰고, 2행부터 처리한다는 것만 기억하세요.

    개념 2: getDataRange()와 2차원 배열¶

    🎒 비유 — 시트 전체 데이터를 가져오는 것은 엑셀 표를 통째로 복사해서 메모리에 붙여넣기하는 것과 같습니다. 결과는 "행 배열 안에 열 배열이 들어 있는" 2차원 배열입니다.

    data[0]  →  ["타임스탬프", "이름", "부서", "신청 과목", "연락처"]   ← 헤더
data[1]  →  ["2025-03-01 09:12:34", "김민수", "영업1팀", "Excel 고급", "010-..."]
data[2]  →  ["2025-03-01 09:15:02", "이지은", "마케팅팀", "Python 기초", "010-..."]

    접근법 - data[행 인덱스][열 인덱스] — 예: data[1][2] → "영업1팀" - 행 인덱스 0 = 헤더이므로 실제 데이터는 인덱스 1부터 시작

    핵심 포인트: getValues()는 시트 ↔ 스크립트 통신을 한 번에 처리하므로, 셀 하나씩 읽는 것보다 수십 배 빠릅니다.

    개념 3: 분류(그루핑) 로직¶

    🎒 비유 — 카드 게임에서 패를 같은 무늬끼리 모으는 것과 같습니다. 우리는 특정 열(예: 부서명)을 기준으로 응답을 그룹화합니다.

    패턴: 객체(Object)를 딕셔너리처럼 사용

    var groups = {};

for (var i = 1; i < data.length; i++) {
  var key = data[i][2]; // 부서명이 C열(인덱스 2)
  if (!groups[key]) {
    groups[key] = [];
  }
  groups[key].push(data[i]);
}

    실행 후 groups 모습:

    {
  "영업1팀": [[행1], [행4], ...],
  "마케팅팀": [[행2], [행3], ...],
  ...
}

    핵심 포인트: 분류 기준 열 인덱스만 바꾸면 과목별, 사이즈별, 지역별 등 어떤 기준이든 같은 코드로 그루핑할 수 있습니다.

    개념 4: 예외 처리 – 중복 응답 & 빈 값¶

    🎒 비유 — 우편물에 같은 사람이 두 번 보낸 편지가 섞여 있거나, 주소가 빠진 편지가 있는 상황입니다. 사람이 일일이 걸러내던 것을 코드가 대신합니다.

    중복 응답 제거 — 같은 이름(또는 이메일)이 여러 번 나오면 가장 마지막 응답만 유지합니다.

    // 뒤에서부터 순회하면 자연스럽게 "마지막 응답"이 남음
var seen = {};
var unique = [];

for (var i = data.length - 1; i >= 1; i--) {
  var id = data[i][1]; // 이름 또는 이메일
  if (!seen[id]) {
    seen[id] = true;
    unique.unshift(data[i]); // 원래 순서 유지
  }
}

    빈 값 기본값 채우기

    for (var i = 0; i < unique.length; i++) {
  if (!unique[i][4] || unique[i][4].toString().trim() === "") {
    unique[i][4] = "미입력";
  }
}

    핵심 포인트: 예외 처리는 "분류 전에" 실행하세요. 더러운 데이터를 먼저 정리하고, 깨끗한 데이터를 분류해야 결과가 정확합니다.

    🔨 따라하기¶

    시나리오: "방과후 수강 신청" 구글 폼의 응답을 부서별 시트에 자동 분류하겠습니다.

    Step 1: 구글 폼 만들기 & 응답 시트 연결¶

    1. Google Forms에서 새 폼을 만듭니다.
    2. 질문 구성:
    3. 이름 (단답형)
    4. 부서 (드롭다운: 영업1팀 / 마케팅팀 / 개발팀)
    5. 신청 과목 (드롭다운: Excel 고급 / Python 기초 / 프레젠테이션)
    6. 연락처 (단답형)
    7. 응답 탭 → 스프레드시트 아이콘 클릭 → "새 스프레드시트 만들기" 선택
    8. 테스트 응답 5~10개를 직접 제출합니다. (다양한 부서, 중복 이름, 빈 연락처 포함)

    실무 TIP: 테스트 데이터에 일부러 중복 이름 2건, 빈 연락처 1건을 넣어 두세요. 예외 처리가 잘 되는지 바로 확인할 수 있습니다.

    Step 2: Apps Script 에디터 열기¶

    1. 응답 스프레드시트에서 확장 프로그램 → Apps Script 클릭
    2. 기본 myFunction 코드를 모두 지웁니다
    3. 아래 코드를 붙여넣을 준비를 합니다

    Step 3: 데이터 읽기 & 예외 처리 코드 작성¶

    아래 코드를 에디터에 붙여넣습니다.

    function organizeResponses() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var responseSheet = ss.getSheetByName("설문지 응답 1");
  // ↑ 시트 이름이 다르면 실제 이름으로 변경하세요

  var data = responseSheet.getDataRange().getValues();
  var header = data[0];

  // ── 1) 중복 응답 제거 (마지막 응답만 유지) ──
  var seen = {};
  var unique = [];

  for (var i = data.length - 1; i >= 1; i--) {
    var id = data[i][1]; // B열: 이름
    if (!seen[id]) {
      seen[id] = true;
      unique.unshift(data[i]);
    }
  }

  // ── 2) 빈 값 기본값 채우기 ──
  for (var i = 0; i < unique.length; i++) {
    if (!unique[i][4] || unique[i][4].toString().trim() === "") {
      unique[i][4] = "미입력"; // E열: 연락처
    }
  }

  // ── 3) 부서별 그루핑 ──
  var groups = {};

  for (var i = 0; i < unique.length; i++) {
    var dept = unique[i][2]; // C열: 부서
    if (!groups[dept]) {
      groups[dept] = [];
    }
    groups[dept].push(unique[i]);
  }

  // ── 4) 부서별 시트에 쓰기 ──
  for (var dept in groups) {
    var targetSheet = ss.getSheetByName(dept);

    // 시트가 없으면 새로 생성
    if (!targetSheet) {
      targetSheet = ss.insertSheet(dept);
    } else {
      targetSheet.clearContents(); // 기존 내용 초기화
    }

    // 헤더 쓰기
    targetSheet.getRange(1, 1, 1, header.length).setValues([header]);

    // 데이터 쓰기
    if (groups[dept].length > 0) {
      targetSheet.getRange(2, 1, groups[dept].length, header.length)
        .setValues(groups[dept]);
    }
  }

  // ── 5) 요약 시트 생성 ──
  var summarySheet = ss.getSheetByName("집계 요약");
  if (!summarySheet) {
    summarySheet = ss.insertSheet("집계 요약");
  } else {
    summarySheet.clearContents();
  }

  summarySheet.getRange(1, 1).setValue("부서");
  summarySheet.getRange(1, 2).setValue("신청 인원");

  var row = 2;
  for (var dept in groups) {
    summarySheet.getRange(row, 1).setValue(dept);
    summarySheet.getRange(row, 2).setValue(groups[dept].length);
    row++;
  }

  SpreadsheetApp.getUi().alert("✅ 집계 완료! " + unique.length + "건 처리됨");
}

    주의사항: "설문지 응답 1" 부분은 여러분의 실제 응답 시트 탭 이름과 정확히 일치해야 합니다. 탭 이름에 공백이나 숫자가 포함되어 있을 수 있으니 꼭 확인하세요.

    📝 전체 코드¶

    아래는 위 따라하기의 완성 코드입니다. 복사하여 바로 사용할 수 있습니다.

    /**
 * 구글 폼 응답을 부서별로 자동 분류·집계하는 스크립트
 * 
 * 사용법:
 *   1. 구글 폼 응답 시트에서 확장 프로그램 > Apps Script
 *   2. 이 코드를 붙여넣고 실행
 *   3. 트리거 설정: "양식 응답 제출 시" → organizeResponses
 * 
 * 커스터마이징:
 *   - RESPONSE_SHEET_NAME: 응답 시트 탭 이름
 *   - NAME_COL: 이름(중복 판별 기준) 열 인덱스 (0부터 시작)
 *   - GROUP_COL: 분류 기준 열 인덱스
 *   - EMPTY_CHECK_COL: 빈 값 체크할 열 인덱스
 */

// ===== 설정 영역 (여기만 수정하세요) =====
var CONFIG = {
  RESPONSE_SHEET_NAME: "설문지 응답 1",
  NAME_COL: 1,          // B열: 이름 (중복 판별 기준)
  GROUP_COL: 2,          // C열: 부서 (분류 기준)
  EMPTY_CHECK_COL: 4,    // E열: 연락처 (빈 값 체크 대상)
  DEFAULT_VALUE: "미입력"  // 빈 값 대체 텍스트
};

function organizeResponses() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var responseSheet = ss.getSheetByName(CONFIG.RESPONSE_SHEET_NAME);

  if (!responseSheet) {
    SpreadsheetApp.getUi().alert(
      "❌ '" + CONFIG.RESPONSE_SHEET_NAME + "' 시트를 찾을 수 없습니다."
    );
    return;
  }

  var data = responseSheet.getDataRange().getValues();

  if (data.length < 2) {
    SpreadsheetApp.getUi().alert("⚠️ 응답 데이터가 없습니다.");
    return;
  }

  var header = data[0];

  // 1) 중복 응답 제거 (마지막 응답 유지)
  var seen = {};
  var unique = [];
  for (var i = data.length - 1; i >= 1; i--) {
    var id = data[i][CONFIG.NAME_COL];
    if (id && !seen[id]) {
      seen[id] = true;
      unique.unshift(data[i]);
    }
  }

  // 2) 빈 값 기본값 채우기
  for (var i = 0; i < unique.length; i++) {
    var val = unique[i][CONFIG.EMPTY_CHECK_COL];
    if (!val || val.toString().trim() === "") {
      unique[i][CONFIG.EMPTY_CHECK_COL] = CONFIG.DEFAULT_VALUE;
    }
  }

  // 3) 그루핑
  var groups = {};
  for (var i = 0; i < unique.length; i++) {
    var key = unique[i][CONFIG.GROUP_COL];
    if (!key || key.toString().trim() === "") key = "미분류";
    if (!groups[key]) groups[key] = [];
    groups[key].push(unique[i]);
  }

  // 4) 분류별 시트 생성 & 데이터 쓰기
  for (var key in groups) {
    var sheet = ss.getSheetByName(key);
    if (!sheet) {
      sheet = ss.insertSheet(key);
    } else {
      sheet.clearContents();
    }
    sheet.getRange(1, 1, 1, header.length).setValues([header]);
    sheet.getRange(2, 1, groups[key].length, header.length)
      .setValues(groups[key]);
  }

  // 5) 집계 요약 시트
  var summary = ss.getSheetByName("집계 요약");
  if (!summary) {
    summary = ss.insertSheet("집계 요약");
  } else {
    summary.clearContents();
  }

  summary.getRange(1, 1).setValue("분류");
  summary.getRange(1, 2).setValue("신청 인원");
  summary.getRange(1, 1, 1, 2).setFontWeight("bold");

  var row = 2;
  var total = 0;
  for (var key in groups) {
    summary.getRange(row, 1).setValue(key);
    summary.getRange(row, 2).setValue(groups[key].length);
    total += groups[key].length;
    row++;
  }
  summary.getRange(row, 1).setValue("합계").setFontWeight("bold");
  summary.getRange(row, 2).setValue(total).setFontWeight("bold");

  SpreadsheetApp.getUi().alert(
    "✅ 집계 완료!\n" +
    "- 전체 응답: " + (data.length - 1) + "건\n" +
    "- 중복 제거 후: " + unique.length + "건\n" +
    "- 분류 그룹: " + Object.keys(groups).length + "개"
  );
}

    ⚠️ 자주 하는 실수¶

    실수 1: 시트 이름 불일치 🔤¶

    증상: "Cannot call method 'getDataRange' of null" 에러

    원인: CONFIG.RESPONSE_SHEET_NAME에 적은 이름과 실제 시트 탭 이름이 다릅니다. 한글 폼의 기본 시트명은 "설문지 응답 1"이지만, 영문 환경에서는 "Form Responses 1"입니다.

    해결: 시트 하단 탭의 이름을 정확히 복사해서 붙여넣으세요. 공백, 숫자까지 모두 일치해야 합니다.

    실수 2: 열 인덱스 착각 🔢¶

    증상: 부서별 분류가 이상하게 되거나, 엉뚱한 데이터가 중복 기준이 됨

    원인: 열 인덱스는 0부터 시작합니다. A열=0, B열=1, C열=2...

    해결: 폼 질문 순서를 바꿨다면, 응답 시트의 열 순서도 바뀝니다. 시트를 열어 실제 열 위치를 확인한 뒤 CONFIG 값을 수정하세요.

    실수 3: 트리거 중복 설정 ⏰⏰¶

    증상: 폼 제출 1건에 스크립트가 2~3번 실행되어 알림이 여러 번 뜸

    원인: 트리거를 여러 번 추가했습니다.

    해결: Apps Script 에디터 > 트리거 메뉴에서 중복된 트리거를 삭제하고 하나만 남기세요.

    실수 4: 기존 시트 데이터가 사라짐 😱¶

    증상: 부서별 시트에 수동으로 추가했던 메모나 서식이 초기화됨

    원인: clearContents()가 매 실행마다 시트 내용을 지웁니다.

    해결: 분류 시트에 수동 작업이 필요하다면, 별도의 "작업용" 시트를 만들고 분류 시트는 원본 참조용으로만 사용하세요. 또는 clearContents() 대신 기존 데이터 아래에 추가하는 로직으로 변경할 수 있습니다.
