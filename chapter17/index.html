    개별 문서 자동 생성 ① – 학생별 문서를 한 번에 만들기¶

    Part 5 | [2권] 문서 생성·성적 처리 자동화 – 개별 문서와 성적을 한 번에

    🎯 이 장에서 배우는 것¶

    • 구글 문서 템플릿에 치환 태그({{학생이름}} 등)를 설계할 수 있다
    • Apps Script로 템플릿을 복사하고 태그를 학생 정보로 자동 치환할 수 있다
    • 학생 수만큼 개별 문서를 한 번에 생성하여 드라이브 폴더에 저장할 수 있다
    • 생성된 문서의 URL을 스프레드시트에 자동 기록할 수 있다

    💡 왜 이걸 배우나요?¶

    CASE STUDY: 담임 G 선생님의 3월

    G 선생님은 30명 학생의 생활기록부 초안을 개별 문서로 만들어야 합니다. 지금까지의 방법은 이렇습니다. 1. 빈 양식 문서를 연다 2. "이름"란에 학생 이름을 타이핑한다 3. "학번"란에 학번을 타이핑한다 4. "다른 이름으로 저장"한다 5. … 이 작업을 30번 반복한다

    한 명당 2분이면 단순 복사·붙여넣기에만 1시간. 오타라도 나면 처음부터 다시입니다.

    이 장에서 만드는 스크립트는 버튼 한 번으로 30개 문서를 생성하고, 각 문서 링크까지 스프레드시트에 자동 기록합니다. 생활기록부뿐 아니라 상담 기록지, 진로 포트폴리오, 개별 안내문 등 "같은 양식 × N명"이 필요한 모든 업무에 즉시 적용됩니다.

    📚 핵심 개념¶

    개념 1: 문서 템플릿과 치환 태그¶

    비유 🏷️ 편지지를 떠올려 보세요. "Dear _____, " 빈칸에 이름만 바꿔 넣으면 개인 편지가 됩니다. 구글 문서 템플릿도 동일합니다. 빈칸 대신 {{학생이름}}처럼 치환 태그를 넣어두면, 스크립트가 이 태그를 실제 데이터로 교체합니다.

    정의 - 템플릿: 반복 사용할 구글 문서 원본. 내용은 완성본과 동일하되, 바뀌는 부분만 태그로 표시 - 치환 태그: {{태그이름}} 형태의 문자열. 스크립트가 replaceText()로 찾아 치환

    예시로 확인

    실제 템플릿 문서에 이렇게 작성합니다:

    [생활기록부 초안]

학번: {{학번}}
이름: {{학생이름}}
학년/반: {{학년반}}
담임: {{담임이름}}

1. 출결 상황: {{출결}}
2. 학습 활동 특기사항: {{학습특기}}
3. 행동 특성 및 종합 의견: {{종합의견}}

    실무 TIP 💼 태그 이름은 스프레드시트 열 헤더와 정확히 일치시키세요. {{학생이름}}이면 시트 헤더도 학생이름으로 맞추면 코드가 훨씬 단순해집니다.

    개념 2: 템플릿 복사 → 치환 → 저장 흐름¶

    전체 자동화는 세 단계로 이루어집니다.

    flowchart LR A["1️⃣ 템플릿 복사\nDriveApp.getFileById()\n.makeCopy()"] --> B["2️⃣ 태그 치환\nBody.replaceText()\n{{태그}} → 실제값"] B --> C["3️⃣ 저장 & 기록\n문서 URL을\n시트에 기록"]
    • 1단계 – 복사: 원본 템플릿은 건드리지 않고 사본을 생성합니다
    • 2단계 – 치환: 사본의 본문(Body)에서 태그를 학생 데이터로 교체합니다
    • 3단계 – 기록: 완성된 문서의 URL을 스프레드시트에 남겨 관리합니다

    주의사항 ⚠️ 원본 템플릿을 직접 수정하면 다음 실행 시 태그가 없어 치환이 불가합니다. 반드시 makeCopy()로 사본을 만든 뒤 사본을 수정하세요.

    개념 3: replaceText()의 작동 원리¶

    Body.replaceText(searchPattern, replacement)는 구글 문서 본문 전체에서 해당 패턴을 찾아 바꿉니다.

    핵심 특성 - 첫 번째 인수는 정규표현식(Regex)으로 처리됩니다 - {{, }}는 정규표현식에서 특수문자이므로, 문자 그대로 찾으려면 이스케이프(\\{\\{)가 필요합니다 - 단, Apps Script의 replaceText()는 내부적으로 단순 문자열 매칭도 지원하므로 {{학생이름}}을 그대로 넣어도 대부분 작동합니다

    // 안전한 방식 (이스케이프 적용)
body.replaceText('\\{\\{학생이름\\}\\}', '김민수');

// 간편한 방식 (대부분 정상 작동)
body.replaceText('{{학생이름}}', '김민수');

    실무 TIP 💼 태그 안에 특수문자(+, *, ( 등)를 넣지 마세요. 정규표현식 오류의 원인이 됩니다. 한글+영문+숫자만 사용하는 것이 안전합니다.

    개념 4: 폴더 관리와 URL 기록¶

    문서가 30개씩 생성되면 드라이브가 금방 어질러집니다. 전용 폴더에 저장하고, 시트에 URL을 남기는 것이 실무의 핵심입니다.

    flowchart TD subgraph 구글_드라이브 F["📁 2024_생활기록부_초안"] F --> D1["📄 생활기록부_김민수"] F --> D2["📄 생활기록부_이서연"] F --> D3["📄 생활기록부_박준호"] F --> D4["📄 ... (30명)"] end subgraph 스프레드시트 S["학번 | 이름 | ... | 문서링크\n자동 기록 ✅"] end D1 -.->|URL| S D2 -.->|URL| S D3 -.->|URL| S

    🔨 따라하기¶

    Step 1: 스프레드시트에 학생 명단 준비¶

    구글 스프레드시트를 새로 만들고 시트 이름을 학생명단으로 변경합니다.

    1행(헤더)을 다음과 같이 입력합니다: - A1: 학번 - B1: 학생이름 - C1: 학년반 - D1: 담임이름 - E1: 문서링크

    2행부터 학생 데이터를 입력합니다 (테스트용으로 3~5명이면 충분합니다):

    • 2행: 20240101 / 김민수 / 2-3 / G선생님
    • 3행: 20240102 / 이서연 / 2-3 / G선생님
    • 4행: 20240103 / 박준호 / 2-3 / G선생님

    실무 TIP 💼 E열(문서링크)은 비워두세요. 스크립트가 자동으로 채웁니다.

    Step 2: 구글 문서 템플릿 만들기¶

    구글 문서(Docs)를 새로 만들고, 아래 내용을 입력합니다:

    [생활기록부 초안]

학번: {{학번}}
이름: {{학생이름}}
학년/반: {{학년반}}
담임: {{담임이름}}

1. 출결 상황:


2. 학습 활동 특기사항:


3. 행동 특성 및 종합 의견:

    문서를 저장한 뒤, 주소창에서 문서 ID를 복사합니다.

    https://docs.google.com/document/d/여기가_문서ID/edit

    여기가_문서ID 부분(긴 영문+숫자 문자열)을 메모해 두세요.

    Step 3: 저장용 폴더 만들기¶

    구글 드라이브에서 2024_생활기록부_초안 폴더를 새로 만듭니다.

    폴더를 열고 주소창에서 폴더 ID를 복사합니다.

    https://drive.google.com/drive/folders/여기가_폴더ID

    Step 4: Apps Script 작성¶

    스프레드시트로 돌아와서 확장 프로그램 → Apps Script를 엽니다.

    기존 코드를 모두 지우고, 아래 코드를 붙여넣습니다.

    function createStudentDocs() {
  // ═══════════ 설정 영역 (여기만 수정하세요) ═══════════
  var TEMPLATE_ID = '여기에_템플릿_문서ID_붙여넣기';
  var FOLDER_ID   = '여기에_폴더ID_붙여넣기';
  var SHEET_NAME  = '학생명단';
  // ═══════════════════════════════════════════════════

  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(SHEET_NAME);
  var data = sheet.getDataRange().getValues();
  var headers = data[0]; // 1행: 헤더

  var folder = DriveApp.getFolderById(FOLDER_ID);
  var templateFile = DriveApp.getFileById(TEMPLATE_ID);

  // 문서링크 열 인덱스 찾기
  var linkCol = headers.indexOf('문서링크');

  for (var i = 1; i < data.length; i++) {
    var row = data[i];

    // 이미 링크가 있으면 건너뛰기 (중복 생성 방지)
    if (row[linkCol] && row[linkCol].toString().length > 0) {
      Logger.log((i + 1) + '행: 이미 생성됨 - 건너뜀');
      continue;
    }

    // Step A: 템플릿 복사
    var studentName = row[headers.indexOf('학생이름')];
    var docName = '생활기록부_' + studentName;
    var copiedFile = templateFile.makeCopy(docName, folder);

    // Step B: 문서 열고 태그 치환
    var doc = DocumentApp.openById(copiedFile.getId());
    var body = doc.getBody();

    for (var j = 0; j < headers.length; j++) {
      var tag = '{{' + headers[j] + '}}';
      var value = row[j] ? row[j].toString() : '';
      body.replaceText(tag, value);
    }

    doc.saveAndClose();

    // Step C: 시트에 URL 기록
    var docUrl = doc.getUrl();
    sheet.getRange(i + 1, linkCol + 1).setValue(docUrl);

    Logger.log('생성 완료: ' + docName);
  }

  SpreadsheetApp.getUi().alert('문서 생성이 완료되었습니다! 🎉');
}

    주의사항 ⚠️ TEMPLATE_ID와 FOLDER_ID를 반드시 본인의 ID로 교체하세요. 따옴표('...') 안에 ID만 붙여넣으면 됩니다.

    Step 5: 실행 및 권한 승인¶

    1. 스크립트 편집기 상단에서 함수가 createStudentDocs인지 확인
    2. ▶ 실행 버튼 클릭
    3. 첫 실행 시 권한 승인 팝업 → "고급" → "이동" → "허용"
    4. 실행이 끝나면 알림 창이 뜹니다

    스프레드시트로 돌아가면 E열에 문서 링크가 자동 입력되어 있습니다. 링크를 클릭하면 학생별 생활기록부 초안이 열립니다.

    Step 6: 커스텀 메뉴 추가 (편의 기능)¶

    매번 스크립트 편집기를 열지 않아도 되도록, 스프레드시트에 메뉴를 추가합니다.

    아래 코드를 createStudentDocs 함수 위에 추가하세요:

    function onOpen() {

    .createMenu('📄 문서 자동화')

    스프레드시트를 새로고침하면 상단 메뉴에 📄 문서 자동화가 나타납니다.

    📝 전체 코드¶

    // ──────────────────────────────────────
// 메뉴 등록
// ──────────────────────────────────────
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('📄 문서 자동화')
    .addItem('학생별 문서 생성', 'createStudentDocs')
    .addToUi();
}

// ──────────────────────────────────────
// 학생별 개별 문서 자동 생성
// ──────────────────────────────────────
function createStudentDocs() {
  // ═══════════ 설정 영역 ═══════════
  var TEMPLATE_ID = '여기에_템플릿_문서ID';
  var FOLDER_ID   = '여기에_폴더ID';
  var SHEET_NAME  = '학생명단';
  // ══════════════════════════════════

  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(SHEET_NAME);
  var data = sheet.getDataRange().getValues();
  var headers = data[0];

  var folder = DriveApp.getFolderById(FOLDER_ID);
  var templateFile = DriveApp.getFileById(TEMPLATE_ID);

  var linkCol = headers.indexOf('문서링크');
  var created = 0;

  for (var i = 1; i < data.length; i++) {
    var row = data[i];

    // 중복 생성 방지
    if (row[linkCol] && row[linkCol].toString().length > 0) {
      continue;
    }

    // 1. 템플릿 복사
    var studentName = row[headers.indexOf('학생이름')];
    var docName = '생활기록부_' + studentName;
    var copiedFile = templateFile.makeCopy(docName, folder);

    // 2. 태그 치환
    var doc = DocumentApp.openById(copiedFile.getId());
    var body = doc.getBody();

    for (var j = 0; j < headers.length; j++) {
      var tag = '{{' + headers[j] + '}}';
      var value = row[j] ? row[j].toString() : '';
      body.replaceText(tag, value);
    }

    doc.saveAndClose();

    // 3. URL 기록
    var docUrl = doc.getUrl();
    sheet.getRange(i + 1, linkCol + 1).setValue(docUrl);

    created++;
    Logger.log('생성 완료: ' + docName);
  }

  SpreadsheetApp.getUi().alert(
    created + '개 문서가 생성되었습니다! 🎉'
  );
}

    ⚠️ 자주 하는 실수¶

    실수 1: 태그가 치환되지 않는다

    • 원인: 시트 헤더와 템플릿 태그 이름이 다릅니다. 시트에는 학생 이름(공백 포함), 템플릿에는 {{학생이름}}(공백 없음)
    • 해결: 헤더와 태그를 글자 하나까지 동일하게 맞추세요. 복사·붙여넣기가 가장 안전합니다

    실수 2: 실행할 때마다 문서가 중복 생성된다

    • 원인: E열(문서링크)을 지우고 다시 실행했거나, 중복 방지 로직이 빠진 경우
    • 해결: 코드에 이미 포함된 if (row[linkCol]...) 조건이 중복을 방지합니다. E열의 링크를 임의로 삭제하지 마세요

    실수 3: "문서를 열 수 없습니다" 오류

    • 원인: TEMPLATE_ID 또는 FOLDER_ID가 잘못되었습니다
    • 해결: URL에서 ID를 다시 복사하세요. 앞뒤 공백이 들어가지 않았는지 확인합니다

    실수 4: 구글 문서에서 태그가 서식 코드로 쪼개진다

    • 원인: {{학생이름}}을 입력한 뒤 일부만 굵게/색상 변경하면, 내부적으로 {{학생 + 이름}}으로 분리됩니다
    • 해결: 태그를 메모장에서 먼저 작성 → 통째로 복사·붙여넣기 → 이후 서식 적용

    실무 TIP 💼 태그가 제대로 치환되는지 확인하려면 먼저 1명만 테스트하세요. 2행만 데이터를 넣고 실행한 뒤, 생성된 문서를 열어보면 됩니다.

    ✅ 스스로 점검하기¶

    아래 항목을 모두 체크할 수 있으면 이 장의 학습이 완료된 것입니다.

    • 구글 문서에 {{태그}} 형태로 치환 태그를 작성할 수 있다
    • DriveApp.getFileById().makeCopy()로 템플릿을 복사할 수 있다
    • Body.replaceText()로 태그를 실제 값으로 치환할 수 있다
    • 생성된 문서가 지정 폴더에 저장되는 것을 확인했다
    • 스프레드시트 E열에 문서 링크가 자동 입력되었다
    • 같은 스크립트를 다시 실행해도 중복 문서가 생성되지 않는다
    • 커스텀 메뉴에서 버튼으로 실행할 수 있다

var docName = '2024_' + row[headers.indexOf('학년반')] + '_' + studentName + '_생활기록부';

    핵심 포인트 정리 📌

    • 템플릿 + 치환 태그 = "같은 양식 × N명" 문제의 정답
    • makeCopy() → replaceText() → URL 기록 3단계가 핵심 흐름
    • 시트 헤더와 태그 이름을 완전히 일치시키면 코드가 단순해진다
    • 중복 생성 방지 로직은 실무에서 반드시 포함해야 한다
    • 먼저 1명으로 테스트, 확인 후 전체 실행하는 습관을 들이자
