    구글 앱스 스크립트란? – 선생님의 비서를 소개합니다¶

    🎯 이 장에서 배우는 것¶

    • 구글 앱스 스크립트(GAS)가 무엇이고 왜 유용한지 설명할 수 있다
    • GAS와 구글 워크스페이스 서비스 간의 연동 구조를 이해할 수 있다
    • 자신의 반복 업무 중 자동화 대상을 스스로 찾아 정리할 수 있다

    📖 이야기로 시작하기: 김 선생님의 하루¶

    월요일 아침, 김 선생님은 출근하자마자 한숨부터 나옵니다.

    🔹 구글 폼으로 들어온 현장학습 신청서 47건을 스프레드시트에서 일일이 확인 🔹 미제출 학생 명단을 뽑아 담임 선생님 8명에게 개별 이메일 발송 🔹 지난주 설문 결과를 학년별로 분류해서 보고서 작성 🔹 다음 주 행사 일정을 구글 캘린더에 하나씩 수동 입력

    "이걸 매주 반복하다니… 누가 좀 대신 해줬으면!"

    김 선생님에게 필요한 건 디지털 비서 한 명입니다. 바로 그 비서가 오늘 소개할 구글 앱스 스크립트(Google Apps Script) 입니다.

    📚 핵심 개념¶

    개념 1: 구글 앱스 스크립트(GAS)란?¶

    1. 비유로 시작

    GAS는 마치 구글 워크스페이스 전용 리모컨과 같습니다. TV 리모컨 하나로 채널·볼륨·입력소스를 모두 제어하듯, GAS 하나로 스프레드시트·Gmail·캘린더·드라이브를 모두 조종할 수 있습니다.

    2. 정확한 정의

    구글 앱스 스크립트는 구글이 제공하는 클라우드 기반 스크립팅 플랫폼입니다. 자바스크립트(JavaScript) 문법을 사용하며, 별도 설치 없이 웹 브라우저만 있으면 바로 코드를 작성하고 실행할 수 있습니다.

    3. 예시로 확인

    • 스프레드시트의 데이터를 읽어 → Gmail로 자동 발송
    • 구글 폼 응답이 들어오면 → 즉시 캘린더에 일정 등록
    • 매일 오전 9시에 → 드라이브 폴더 정리를 자동 실행

    💡 실무 TIP: GAS는 무료입니다. 구글 계정만 있으면 지금 바로 사용할 수 있고, 별도 프로그램 설치가 전혀 필요 없습니다.

    개념 2: GAS와 구글 워크스페이스 연동 구조¶

    GAS의 진짜 힘은 구글 서비스들을 하나로 연결하는 데 있습니다. 아래 다이어그램을 보세요.

    • 연동 자동화 → 폼 응답 → 시트 정리 → 이메일 발송 → 캘린더 등록 (한 번에!)

    개념 3: GAS로 자동화할 수 있는 실제 업무¶

    CASE STUDY: 학교 현장의 7가지 자동화 사례

    🔹 1. 신청서 자동 집계 - 구글 폼 응답을 학년·반별로 자동 분류하고 요약 시트 생성

    🔹 2. 미제출자 알림 발송 - 제출 명단과 전체 명단을 비교해 미제출자에게 자동 이메일 발송

    🔹 3. 성적 통지표 자동 생성 - 시트의 성적 데이터를 읽어 학생별 구글 문서(통지표)를 일괄 생성

    🔹 4. 행사 일정 일괄 등록 - 시트에 정리한 연간 일정을 캘린더에 한 번에 등록

    🔹 5. 설문 결과 자동 보고서 - 폼 응답 데이터를 집계하여 차트 포함 보고서 문서를 자동 생성

    🔹 6. 파일 자동 정리 - 드라이브 폴더 안의 파일을 날짜·유형별로 자동 분류 및 이동

    🔹 7. 정기 리마인더 - 매주 월요일 오전 9시에 "이번 주 할 일" 이메일을 자동 전송

    💡 실무 TIP: 자동화 대상 선정의 황금 기준은 "주 1회 이상 반복 + 매번 같은 패턴" 인 업무입니다. 해당되는 업무가 있다면 GAS가 거의 확실히 도와줄 수 있습니다.

    🔨 따라하기: 첫 번째 앱스 스크립트 열어보기¶

    아직 코드를 깊이 다루지는 않지만, 스크립트 편집기를 여는 것까지는 직접 해봅시다.

    Step 1: 구글 스프레드시트 생성¶

    • Google Sheets에 접속합니다.
    • 빈 스프레드시트를 하나 새로 만듭니다.
    • 파일 이름을 GAS 연습장으로 변경합니다.

    Step 2: 스크립트 편집기 열기¶

    • 상단 메뉴에서 확장 프로그램 → Apps Script 를 클릭합니다.
    • 새 탭에 스크립트 편집기가 열립니다. 🎉

    Step 3: 첫 코드 입력¶

    편집기에 기본으로 적힌 코드를 모두 지우고, 아래 코드를 복사해서 붙여넣으세요.

    코드: 

    function myFirstScript() {
  // 현재 스프레드시트를 가져옵니다
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  // A1 셀에 메시지를 씁니다
  sheet.getRange("A1").setValue("🎉 앱스 스크립트가 작동합니다!");

  // 실행 완료 로그를 남깁니다
  Logger.log("첫 스크립트 실행 성공!");
}

    Step 4: 저장 및 실행¶

    • 상단의 💾 저장 아이콘(또는 Ctrl + S)을 클릭합니다.
    • 함수 선택 드롭다운이 myFirstScript로 되어 있는지 확인합니다.
    • ▶ 실행 버튼을 클릭합니다.

    Step 5: 권한 승인¶

    • 처음 실행 시 "승인 필요" 팝업이 뜹니다.
    • 권한 검토 → 본인 계정 선택 → 허용 순서로 클릭합니다.

    ⚠️ 주의사항: "확인되지 않은 앱" 경고가 뜰 수 있습니다. 본인이 직접 작성한 스크립트이므로 고급 → (프로젝트명)(으)로 이동 을 클릭하면 됩니다.

    Step 6: 결과 확인¶

    • 스프레드시트 탭으로 돌아가면 A1 셀에 🎉 앱스 스크립트가 작동합니다!가 적혀 있습니다.
    • 스크립트 편집기에서 실행 로그 보기(하단 또는 Ctrl + Enter)를 확인하면 "첫 스크립트 실행 성공!"이 출력됩니다.

    실행 결과: 

    A1 셀 → "🎉 앱스 스크립트가 작동합니다!"
로그  → "첫 스크립트 실행 성공!"

    💡 핵심 포인트: 지금 여러분은 코드 4줄로 스프레드시트를 원격 제어했습니다. 이것이 GAS의 기본 원리 — 코드로 구글 서비스를 조작하는 것 — 의 전부입니다.

    📝 전체 코드¶

    function myFirstScript() {
  // 현재 스프레드시트를 가져옵니다
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  // A1 셀에 메시지를 씁니다
  sheet.getRange("A1").setValue("🎉 앱스 스크립트가 작동합니다!");

  // 실행 완료 로그를 남깁니다
  Logger.log("첫 스크립트 실행 성공!");
}

    📋 워크시트: 우리 학교 반복 업무 찾기¶

    아래 질문에 답하면서, 자동화 후보 업무를 3개 이상 적어보세요.

    🔍 질문 1: 매주 또는 매달 반복하는 업무는 무엇인가요?

    (예: 매주 금요일 방과후 신청 집계)

    🔍 질문 2: 그중 "복사-붙여넣기" 또는 "수동 입력"이 포함된 업무는?

    (예: 폼 응답을 학년별 시트에 수동 복사)

    🔍 질문 3: 해당 업무에 구글 서비스(시트, 폼, 이메일 등)가 관련되어 있나요?

    (예: 구글 폼 + 구글 시트 + Gmail)

    💡 실무 TIP: 질문 1~3에 모두 "예"라면, 그 업무는 GAS 자동화 적합도 최상입니다. 이 과정을 마칠 때쯤이면 직접 자동화할 수 있게 됩니다.

    ⚠️ 주의할 점¶

    1. GAS는 만능이 아닙니다 - GAS는 구글 워크스페이스 내에서 강력하지만, 구글 생태계 밖의 프로그램(한글, MS Office 등)을 직접 제어할 수는 없습니다. 다만 외부 API 연동을 통해 확장할 수 있으며, 이는 이후 차시에서 다룹니다.

    2. 실행 시간 제한이 있습니다 - 하나의 스크립트는 최대 6분까지 실행됩니다. 수천 건의 데이터를 처리할 때는 나눠서 실행하는 전략이 필요하며, 이 역시 뒤에서 배웁니다.

    ✅ 점검하기¶

    1. 구글 앱스 스크립트(GAS)를 한 문장으로 설명한다면?

    정답 확인 GAS는 구글 워크스페이스의 여러 서비스(시트, Gmail, 캘린더 등)를 자바스크립트 코드로 연결하고 자동화할 수 있는 클라우드 기반 스크립팅 플랫폼입니다.

    2. GAS가 다른 자동화 도구(예: 엑셀 매크로)와 가장 다른 점은?

    정답 확인 GAS는 단일 프로그램이 아니라 **구글 서비스 간 연동**이 가능합니다. 엑셀 매크로는 엑셀 안에서만 동작하지만, GAS는 시트 → Gmail → 캘린더 → 드라이브를 하나의 스크립트로 모두 제어할 수 있습니다. 또한 클라우드에서 실행되므로 별도 설치가 필요 없습니다.

    3. 자동화 대상 업무를 판단하는 핵심 기준 3가지는?

    정답 확인 ① 주기적으로 반복되는 업무 (주 1회 이상) ② 수동 입력·복사·붙여넣기 등 패턴이 일정한 업무 ③ 구글 워크스페이스 서비스가 관련된 업무
