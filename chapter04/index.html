    반복과 조건 – 30명 학생 데이터를 한 번에 처리하기¶

    🎯 이 장에서 배우는 것¶

    • for 반복문으로 스프레드시트의 여러 행 데이터를 한 번에 처리할 수 있다
    • if 조건문으로 특정 조건에 맞는 데이터만 골라낼 수 있다
    • 반복문 + 조건문을 조합하여 실무 필터링 로직을 작성할 수 있다
    • 이 패턴을 자신의 업무 데이터에 응용할 수 있다

    💡 왜 이걸 배우나요?¶

    김 선생님의 월요일 아침

    체험학습 동의서 제출 마감이 내일입니다. 30명 학생 명단이 담긴 스프레드시트를 열고, 한 줄 한 줄 스크롤하며 "미제출"을 눈으로 찾습니다. 10명쯤 확인하다 전화가 와서 어디까지 봤는지 잊어버립니다. 다시 처음부터...

    이런 경험, 비즈니스 현장에서도 똑같습니다.

    • 📋 100건의 주문서에서 "미입금" 건만 추출
    • 📊 직원 평가표에서 "B등급 이하" 인원만 필터링
    • 📩 설문 응답에서 특정 부서 응답만 골라내기

    이 모든 작업의 핵심은 단 두 가지입니다: "전부 훑어보고"(반복) + "조건에 맞는 것만 골라내기"(조건). 이번 장에서 이 두 가지를 배우면, 30줄이든 3,000줄이든 코드 한 번 실행으로 끝납니다.

    📚 핵심 개념¶

    개념 1: for 반복문 – "1번부터 30번까지 한 명씩 호명"¶

    🎯 비유로 시작

    출석 체크를 떠올려 보세요. 선생님이 "1번 김민수, 2번 이서연, 3번 박지호..." 하고 번호 순서대로 한 명씩 이름을 부릅니다. for 반복문은 바로 이 "번호 순서대로 하나씩" 처리하는 구조입니다.

    📖 정확한 정의

    for 반복문은 정해진 횟수만큼 같은 작업을 반복하는 명령어입니다.

    for (var i = 0; i < 30; i++) {
  // 이 안의 코드가 30번 반복됩니다
  Logger.log(i + "번째 실행");
}

    세 부분으로 나뉩니다.

    • var i = 0 → 시작점: "0번부터 시작할게"
    • i < 30 → 조건: "30보다 작을 동안 계속해"
    • i++ → 증가: "한 번 끝날 때마다 1 올려"

    ✅ 예시로 확인

    function sayHello() {
  for (var i = 1; i <= 5; i++) {
    Logger.log(i + "번 학생, 안녕!");
  }
}

    실행 결과(로그): 

    1번 학생, 안녕!
2번 학생, 안녕!
3번 학생, 안녕!
4번 학생, 안녕!
5번 학생, 안녕!

    실무 TIP: i는 그냥 변수 이름입니다. row, count 등 의미 있는 이름을 써도 됩니다. 실무에서는 row를 많이 씁니다.

    개념 2: if 조건문 – "미제출이면 형광펜으로 표시"¶

    🎯 비유로 시작

    출석부를 넘기면서 결석이라고 적힌 칸만 빨간 펜으로 동그라미를 칩니다. "만약 결석이면 → 표시한다." 이것이 if 조건문입니다.

    📖 정확한 정의

    if 조건문은 조건이 참(true)일 때만 특정 코드를 실행합니다.

    if (조건) {
  // 조건이 참이면 여기가 실행됩니다
}

    ✅ 예시로 확인

    function checkScore() {
  var score = 55;

  if (score < 60) {
    Logger.log("과락입니다. 보충 학습이 필요합니다.");
  }
}

    조건 비교에 쓰는 기호들:

    • == → 같다 ("미제출"과 같은가?)
    • != → 다르다 ("제출"이 아닌가?)
    • < → 작다 (60보다 작은가?)
    • >= → 크거나 같다 (90 이상인가?)

    주의사항: =은 "값을 넣는 것"이고, ==은 "비교하는 것"입니다. 가장 흔한 실수이니 꼭 구분하세요!

    개념 3: if-else – "제출이면 ✓, 미제출이면 ✗"¶

    🎯 비유로 시작

    신호등과 같습니다. 초록불이면 직진, 빨간불이면 정지. 둘 중 하나를 선택하는 구조입니다.

    📖 정확한 정의

    if (조건) {
  // 조건이 참이면 실행
} else {
  // 조건이 거짓이면 실행
}

    ✅ 예시로 확인

    function checkSubmission() {
  var status = "미제출";

  if (status == "제출") {
    Logger.log("✓ 확인 완료");
  } else {
    Logger.log("✗ 독촉 연락 필요");
  }
}

    개념 4: 반복 + 조건 조합 – "30명 전부 훑으면서 미제출만 골라내기"¶

    🎯 비유로 시작

    사과 상자에서 상한 사과를 골라내는 것과 같습니다. 하나씩 꺼내보고(반복) → 상했으면 따로 모은다(조건). 이 두 가지가 합쳐지면 실무의 거의 모든 데이터 처리를 할 수 있습니다.

    flowchart TD A[시작: 1번 학생부터] --> B{아직 확인할 학생이 남았나?} B -- 예 --> C[해당 학생 데이터 읽기] C --> D{미제출인가?} D -- 예 --> E[미제출 목록에 추가] D -- 아니오 --> F[그냥 넘어가기] E --> G[다음 학생으로 이동] F --> G G --> B B -- 아니오 --> H[종료: 미제출 목록 완성!]

    📖 코드 패턴

    for (var i = 0; i < data.length; i++) {
  if (data[i][조건열] == "찾는값") {
    // 원하는 처리
  }
}

    이 패턴 하나로 업무 자동화의 80%를 커버할 수 있습니다.

    핵심 포인트: 반복문은 "전부 훑는 엔진", 조건문은 "골라내는 필터"입니다. 둘을 합치면 강력한 데이터 처리기가 됩니다.

    🔨 따라하기¶

    실습 준비: 스프레드시트 만들기¶

    아래와 같은 스프레드시트를 만들어 주세요. 시트 이름은 "학생명단"으로 설정합니다.

    A열(이름), B열(반), C열(동의서), D열(점수) 순서로 1행은 헤더, 2행부터 데이터를 입력합니다.

    1행 헤더: 이름 | 반 | 동의서 | 점수

    2행~11행 데이터 (10명으로 실습, 원리는 30명도 동일):

    • 김민수, 1반, 제출, 85
    • 이서연, 1반, 미제출, 92
    • 박지호, 2반, 제출, 58
    • 최수아, 2반, 미제출, 45
    • 정우진, 1반, 제출, 73
    • 한예린, 3반, 미제출, 88
    • 오태윤, 3반, 제출, 62
    • 강하은, 2반, 제출, 91
    • 윤도현, 3반, 미제출, 37
    • 임서윤, 1반, 제출, 76

    실무 TIP: 실습은 10명으로 하지만, 코드는 데이터가 몇 행이든 자동으로 처리합니다. 나중에 300명이 되어도 코드를 수정할 필요가 없습니다.

    Step 1: 전체 데이터 읽어오기¶

    스프레드시트에서 확장 프로그램 → Apps Script를 열고 아래 코드를 입력합니다.

    function readAllStudents() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("학생명단");
  var data = sheet.getDataRange().getValues();

  Logger.log("전체 행 수: " + data.length);
  Logger.log("첫 번째 행(헤더): " + data[0]);
  Logger.log("두 번째 행(첫 학생): " + data[1]);
}

    실행 후 로그 확인 (Ctrl+Enter 또는 ▶ 버튼 → 실행 로그 확인):

    전체 행 수: 11
첫 번째 행(헤더): [이름, 반, 동의서, 점수]
두 번째 행(첫 학생): [김민수, 1반, 제출, 85]

    여기서 알 수 있는 것: - data는 2차원 배열입니다 (행과 열로 이루어진 표) - data[0]은 1행(헤더), data[1]은 2행(첫 학생) - data[1][0]은 "김민수", data[1][2]는 "제출"

    배열 번호는 0부터 시작합니다. 사람은 1행이라 부르지만, 코드에서는 data[0]입니다.

    Step 2: for문으로 전체 학생 이름 출력하기¶

    function printAllNames() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("학생명단");
  var data = sheet.getDataRange().getValues();

  // i = 1부터 시작 → 헤더(0번)를 건너뛰기
  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];    // A열: 이름
    var className = data[i][1]; // B열: 반
    Logger.log(name + " (" + className + ")");
  }
}

    실행 결과: 

    김민수 (1반)
이서연 (1반)
박지호 (2반)
... (10명 전부 출력)

    핵심 포인트: i = 1로 시작하는 이유는 data[0]이 헤더행이기 때문입니다. 실무에서 거의 항상 이렇게 씁니다.

    Step 5: 조건 두 개 합치기 (AND/OR)¶

    실무에서는 조건이 하나가 아닌 경우가 많습니다.

    function findSpecificStudents() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("학생명단");
  var data = sheet.getDataRange().getValues();

  Logger.log("=== 2반이면서 미제출인 학생 ===");

  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];
    var className = data[i][1];
    var submission = data[i][2];

    // && 는 "그리고" (AND) - 두 조건 모두 참이어야 함
    if (className == "2반" && submission == "미제출") {
      Logger.log(name);
    }
  }

  Logger.log("");
  Logger.log("=== 미제출이거나 60점 미만인 학생 ===");

  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];
    var submission = data[i][2];
    var score = data[i][3];

    // || 는 "또는" (OR) - 둘 중 하나만 참이면 됨
    if (submission == "미제출" || score < 60) {
      Logger.log(name + " (동의서:" + submission + ", 점수:" + score + ")");
    }
  }
}

    조건 연결 기호 정리: - && (AND) → "~이고 ~인" → 두 조건 모두 충족 - || (OR) → "~이거나 ~인" → 하나만 충족해도 OK

    Step 6: 결과를 스프레드시트에 쓰기 (실무 완성형)¶

    로그가 아닌, 새 시트에 결과를 정리해봅니다.

    function exportNotSubmitted() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sourceSheet = ss.getSheetByName("학생명단");
  var data = sourceSheet.getDataRange().getValues();

  // 결과를 담을 배열
  var results = [];
  results.push(["이름", "반", "상태"]); // 헤더 추가

  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];
    var className = data[i][1];
    var submission = data[i][2];

    if (submission == "미제출") {
      results.push([name, className, "독촉 필요"]);
    }
  }

  // "미제출명단" 시트가 있으면 가져오고, 없으면 새로 만들기
  var resultSheet = ss.getSheetByName("미제출명단");
  if (!resultSheet) {
    resultSheet = ss.insertSheet("미제출명단");
  }

  // 기존 내용 지우고 새로 쓰기
  resultSheet.clear();
  resultSheet.getRange(1, 1, results.length, results[0].length).setValues(results);

  Logger.log("미제출명단 시트에 " + (results.length - 1) + "명 기록 완료!");
}

    실행하면: "미제출명단"이라는 새 시트가 생기고, 미제출 학생 목록이 깔끔하게 정리됩니다.

    실무 TIP: results.push([값1, 값2, 값3])는 배열에 새 행을 추가하는 명령입니다. 엑셀에서 새 행을 삽입하는 것과 같다고 생각하세요.

    📝 전체 코드¶

    가장 많이 쓰는 반복+조건 조합 템플릿입니다. 복사해서 조건만 바꾸면 바로 쓸 수 있습니다.

    function filterAndExport() {
  // ① 데이터 읽기
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("학생명단");  // ← 시트 이름 변경
  var data = sheet.getDataRange().getValues();

  // ② 결과 배열 준비
  var results = [];
  results.push(["이름", "반", "점수"]);  // ← 헤더 변경

  // ③ 반복하면서 조건 확인
  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];       // A열
    var className = data[i][1];  // B열
    var score = data[i][3];      // D열

    // ← 이 조건만 바꾸면 됩니다!
    if (score < 60) {
      results.push([name, className, score]);
    }
  }

  // ④ 결과 시트에 쓰기
  var resultSheet = ss.getSheetByName("필터결과");
  if (!resultSheet) {
    resultSheet = ss.insertSheet("필터결과");
  }
  resultSheet.clear();

  if (results.length > 1) {
    resultSheet.getRange(1, 1, results.length, results[0].length).setValues(results);
    Logger.log((results.length - 1) + "건 추출 완료!");
  } else {
    Logger.log("조건에 맞는 데이터가 없습니다.");
  }
}

    이 템플릿 사용법: 1. 시트 이름 → 자신의 시트에 맞게 변경 2. 헤더 → 원하는 열 이름으로 변경 3. 조건 (if 안의 내용) → 자신의 필터링 조건으로 변경 4. push할 값 → 추출하고 싶은 열 선택

    ⚠️ 자주 하는 실수¶

    실수 1: =과 == 혼동 🔴¶

    // ❌ 잘못된 코드 - 값을 덮어씀!
if (status = "미제출") {
  // 항상 실행됨 (비교가 아니라 대입)
}

// ✅ 올바른 코드 - 비교
if (status == "미제출") {
  // "미제출"일 때만 실행
}

    = 하나는 "넣어라", == 두 개는 "같니?"입니다.

    실수 2: 헤더행을 건너뛰지 않음 🔴¶

    // ❌ i = 0부터 시작하면 헤더도 처리됨
for (var i = 0; i < data.length; i++) { ... }

// ✅ i = 1부터 시작하여 헤더 건너뛰기
for (var i = 1; i < data.length; i++) { ... }

    실수 3: 열 번호를 잘못 지정 🔴¶

    // 스프레드시트: A열=이름, B열=반, C열=동의서, D열=점수
// 배열 번호:    [0]      [1]    [2]        [3]

// ❌ D열(점수)을 가져오려고 했는데 4를 씀
var score = data[i][4];  // 존재하지 않는 5번째 열!

// ✅ D열은 배열에서 3번
var score = data[i][3];

    기억법: A열=0, B열=1, C열=2, D열=3... 알파벳 순서에서 1을 빼면 배열 번호입니다.

    실수 4: 문자열 비교 시 공백/대소문자 🔴¶

    // ❌ 셀에 " 미제출"(앞에 공백)이 있으면 매칭 안 됨
if (submission == "미제출") { ... }

// ✅ trim()으로 앞뒤 공백 제거 후 비교
if (submission.toString().trim() == "미제출") { ... }

    ✅ 스스로 점검하기¶

    아래 질문에 자신 있게 "예" 라고 답할 수 있는지 체크해 보세요.

    • for (var i = 1; i < data.length; i++)가 무슨 뜻인지 말로 설명할 수 있다
    • i = 1에서 0이 아닌 1로 시작하는 이유를 안다
    • ==과 =의 차이를 안다
    • &&(AND)와 ||(OR)로 조건을 두 개 이상 연결할 수 있다
    • 스프레드시트의 특정 열 데이터를 조건으로 필터링하여 새 시트에 출력하는 코드를 작성할 수 있다

    4개 이상 체크했다면 → 다음 장으로 넘어가세요! 👏

    3개 이하라면 → 따라하기 Step 3~5를 한 번 더 실행해 보세요. 직접 조건을 바꿔보는 것이 가장 빠른 학습법입니다.
