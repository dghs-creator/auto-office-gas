    학부모 개별 알림 ② – 첨부파일과 대량 발송 관리¶

    Part 3: 알림·소통 자동화 – 필요한 사람에게 정확히 전달하기 | 12차시

    🎯 이 장에서 배우는 것¶

    • 구글 드라이브의 PDF·이미지 파일을 이메일에 자동 첨부하여 발송할 수 있다
    • 대량 발송 시 일일 한도를 계산하고 분할 발송 전략을 설계할 수 있다
    • 발송 실패 건을 자동 감지하고 재발송하는 로직을 구현할 수 있다
    • 발송 진행 상황을 시트에 기록하여 추적·관리할 수 있다

    💡 왜 이걸 배우나요?¶

    11차시에서 학부모 개별 이메일을 보내는 기본기를 익혔습니다. 하지만 현실은 텍스트만으로 끝나지 않습니다.

    "상담 안내문 PDF를 학부모 180명에게 각각 첨부해서 보내주세요."

    이런 요청을 받으면 어떻게 하시겠습니까? 수동으로 하면 하루 종일 걸리는 작업이지만, 이번 차시를 마치면 버튼 한 번으로 해결할 수 있습니다.

    단, 대량 발송에는 함정이 있습니다. 구글은 하루에 보낼 수 있는 이메일 수를 제한합니다. 한도를 넘기면 계정이 일시 정지될 수 있습니다. 안전하게 대량 발송하는 전략까지 이번 차시에서 함께 다룹니다.

    📚 핵심 개념¶

    개념 1: DriveApp – 구글 드라이브 파일 가져오기¶

    🎒 비유: 구글 드라이브는 거대한 서류 캐비닛이고, DriveApp은 그 캐비닛에서 원하는 서류를 꺼내주는 비서입니다. 파일 이름이나 고유 ID를 알려주면 정확히 그 파일을 찾아옵니다.

    정확한 정의: DriveApp은 Apps Script에서 구글 드라이브의 파일과 폴더에 접근할 수 있게 해주는 내장 클래스입니다.

    자주 쓰는 메서드 3가지

    • DriveApp.getFileById(파일ID) → 파일 ID로 정확히 하나의 파일을 가져옴
    • DriveApp.getFilesByName(파일명) → 이름이 같은 파일 목록을 가져옴 (동명 파일 주의!)
    • DriveApp.getFolderById(폴더ID) → 특정 폴더에 접근하여 그 안의 파일을 탐색

    파일 ID는 어디서 찾나요?

    구글 드라이브에서 파일을 우클릭 → "링크 복사"를 하면 아래 같은 URL이 나옵니다:

    https://drive.google.com/file/d/1aBcDeFgHiJkLmNoPqRsTuVwXyZ/view

    여기서 1aBcDeFgHiJkLmNoPqRsTuVwXyZ 부분이 파일 ID입니다.

    // 파일 ID로 가져오기 (가장 정확한 방법)
var file = DriveApp.getFileById('1aBcDeFgHiJkLmNoPqRsTuVwXyZ');
Logger.log(file.getName()); // 파일명 확인

    실무 TIP 🏷️: 파일 ID를 스프레드시트 셀에 미리 적어두면 코드를 수정하지 않고도 첨부 파일을 바꿀 수 있습니다.

    개념 2: 이메일에 파일 첨부하기 – attachments 옵션¶

    🎒 비유: 편지를 보낼 때 봉투 안에 서류를 함께 넣는 것처럼, MailApp.sendEmail에 attachments 옵션을 추가하면 파일이 이메일에 동봉됩니다.

    정확한 정의: MailApp.sendEmail의 고급 매개변수에 attachments 배열을 넣으면, 해당 파일들이 이메일 첨부파일로 전송됩니다.

    // 기본 구조
MailApp.sendEmail({
  to: '수신자@email.com',
  subject: '제목',
  htmlBody: '<p>본문 내용</p>',
  attachments: [file.getAs(MimeType.PDF)]  // 핵심!
});

    attachments에 넣을 수 있는 형태

    • file.getBlob() → 원본 형식 그대로 첨부
    • file.getAs(MimeType.PDF) → PDF로 변환하여 첨부 (구글 문서 → PDF 변환에 유용)
    • 여러 파일 첨부 → 배열에 여러 개를 넣으면 됩니다: [file1.getBlob(), file2.getBlob()]

    개념 3: 일일 발송 한도와 분할 발송 전략¶

    🎒 비유: 고속도로 톨게이트에 하루 통과 가능 차량 수가 정해져 있다고 생각하세요. 한꺼번에 몰리면 차단됩니다. 여러 날에 나눠서 통과시키는 것이 분할 발송입니다.

    구글 이메일 일일 한도

    • 무료 Gmail 계정: 하루 100건
    • Google Workspace (교육용 포함): 하루 1,500건

    주의사항 ⚠️: 한도를 초과하면 그날 나머지 시간 동안 이메일 발송이 완전 차단됩니다. 업무 이메일도 못 보내게 되므로 절대 한도를 넘기면 안 됩니다.

    남은 한도 확인 코드

    var remaining = MailApp.getRemainingDailyQuota();
Logger.log('오늘 남은 발송 가능 건수: ' + remaining);

    분할 발송 전략의 핵심 원리

    flowchart LR A["전체 대상\n350명"] --> B["1일차\n1~100명"] A --> C["2일차\n101~200명"] A --> D["3일차\n201~300명"] A --> E["4일차\n301~350명"] B --> F["시간 트리거\n매일 오전 8시"] C --> F D --> F E --> F

    스프레드시트에 "발송완료" 열을 만들어두고, 매일 트리거가 실행될 때 아직 발송되지 않은 행부터 한도 내에서 처리하는 방식입니다.

    개념 4: 발송 실패 감지와 재발송¶

    🎒 비유: 택배를 보냈는데 주소 오류로 반송되면, 배송 기록에 "실패"라고 찍히고 다시 보내죠. 이메일도 마찬가지로 try-catch로 실패를 감지하고 "실패" 표시를 남긴 뒤 나중에 재발송합니다.

    정확한 정의: JavaScript의 try-catch 구문으로 sendEmail 실행 중 발생하는 오류를 잡아내어, 실패 원인을 기록하고 해당 건만 나중에 다시 시도하는 로직입니다.

    try {
  MailApp.sendEmail({ /* ... */ });
  sheet.getRange(row, statusCol).setValue('발송완료');
} catch (e) {
  sheet.getRange(row, statusCol).setValue('실패: ' + e.message);
}

    흔한 실패 원인 3가지

    • 잘못된 이메일 주소 → Invalid email 오류
    • 일일 한도 초과 → Service invoked too many times 오류
    • 첨부파일 크기 초과 → 이메일 1건당 첨부 합계 25MB 제한

    🔨 따라하기¶

    시나리오¶

    학부모 상담 안내문 PDF를 구글 드라이브에서 가져와 각 학부모에게 개별 발송합니다. 200명 대상이므로 분할 발송을 적용하고, 실패 건은 자동 기록합니다.

    Step 1: 스프레드시트 준비¶

    학부모발송 시트를 아래 구조로 만듭니다.

    • A열 (학생이름): 김하늘, 이도윤, 박서연 …
    • B열 (학부모이메일): parent1@example.com, parent2@example.com …
    • C열 (반): 1반, 2반 …
    • D열 (발송상태): ← 비워둡니다 (코드가 자동으로 채움)
    • E열 (발송일시): ← 비워둡니다

    1행은 헤더로 사용하고, 2행부터 데이터를 입력합니다.

    Step 2: 구글 드라이브에 첨부할 PDF 준비¶

    1. 구글 드라이브에 "상담안내문.pdf"를 업로드합니다
    2. 파일을 우클릭 → 링크 복사
    3. URL에서 파일 ID를 추출합니다

    실무 TIP 🏷️: 테스트 시에는 아무 PDF나 하나 올려두세요. 구글 문서로 만든 안내문이 있다면 getAs(MimeType.PDF)로 변환 첨부도 가능합니다.

    Step 3: 기본 첨부 발송 코드 작성¶

    Apps Script 편집기를 열고 아래 코드를 입력합니다.

    function sendWithAttachment() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학부모발송');
  var data = sheet.getDataRange().getValues();

  // ✅ 여기에 본인의 파일 ID를 넣으세요
  var fileId = '여기에_파일ID_붙여넣기';
  var file = DriveApp.getFileById(fileId);
  var attachment = file.getBlob(); // 원본 형식 그대로 첨부

  for (var i = 1; i < data.length; i++) {
    var studentName = data[i][0];
    var email = data[i][1];
    var className = data[i][2];
    var status = data[i][3];

    // 이미 발송 완료된 건은 건너뜀
    if (status === '발송완료') continue;

    var subject = '[' + className + '] ' + studentName + ' 학부모님 상담 안내';
    var body = '<p>' + studentName + ' 학부모님 안녕하세요.</p>'
             + '<p>첨부된 상담 안내문을 확인해 주시기 바랍니다.</p>'
             + '<p>감사합니다.</p>';

    try {
      MailApp.sendEmail({
        to: email,
        subject: subject,
        htmlBody: body,
        attachments: [attachment]
      });
      sheet.getRange(i + 1, 4).setValue('발송완료');
      sheet.getRange(i + 1, 5).setValue(new Date());
    } catch (e) {
      sheet.getRange(i + 1, 4).setValue('실패: ' + e.message);
      sheet.getRange(i + 1, 5).setValue(new Date());
    }
  }
}

    실무 TIP 🏷️: file.getBlob() 대신 file.getAs(MimeType.PDF)를 쓰면 구글 문서(Docs)를 PDF로 자동 변환하여 첨부합니다.

    Step 4: 한도 체크가 포함된 분할 발송 코드 작성¶

    200명 이상을 한 번에 보내면 한도 초과 위험이 있습니다. 아래 코드는 남은 한도를 확인하고 안전 마진을 남겨둔 채 발송합니다.

    function sendBatch() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학부모발송');
  var data = sheet.getDataRange().getValues();

  var fileId = '여기에_파일ID_붙여넣기';
  var file = DriveApp.getFileById(fileId);
  var attachment = file.getBlob();

  // ✅ 핵심: 남은 한도 확인 후 안전 마진 20건 확보
  var quota = MailApp.getRemainingDailyQuota();
  var safeLimit = quota - 20; // 업무 이메일용 20건 예비
  var sentCount = 0;

  Logger.log('오늘 발송 가능: ' + safeLimit + '건');

  for (var i = 1; i < data.length; i++) {
    if (sentCount >= safeLimit) {
      Logger.log('한도 도달. ' + sentCount + '건 발송 후 중단.');
      break;
    }

    var studentName = data[i][0];
    var email = data[i][1];
    var className = data[i][2];
    var status = data[i][3];

    if (status === '발송완료') continue;
    if (!email || email.indexOf('@') === -1) {
      sheet.getRange(i + 1, 4).setValue('실패: 이메일 형식 오류');
      continue;
    }

    var subject = '[' + className + '] ' + studentName + ' 학부모님 상담 안내';
    var body = '<p>' + studentName + ' 학부모님 안녕하세요.</p>'
             + '<p>첨부된 상담 안내문을 확인해 주시기 바랍니다.</p>';

    try {
      MailApp.sendEmail({
        to: email,
        subject: subject,
        htmlBody: body,
        attachments: [attachment]
      });
      sheet.getRange(i + 1, 4).setValue('발송완료');
      sheet.getRange(i + 1, 5).setValue(new Date());
      sentCount++;

      // ✅ 과부하 방지: 10건마다 1초 대기
      if (sentCount % 10 === 0) {
        Utilities.sleep(1000);
      }
    } catch (e) {
      sheet.getRange(i + 1, 4).setValue('실패: ' + e.message);
      sheet.getRange(i + 1, 5).setValue(new Date());
    }
  }

  Logger.log('이번 실행에서 총 ' + sentCount + '건 발송 완료');
}

    Step 5: 시간 트리거 설정으로 매일 자동 실행¶

    분할 발송은 매일 정해진 시간에 자동 실행되어야 의미가 있습니다.

    1. Apps Script 편집기 왼쪽 메뉴에서 ⏰ 트리거 클릭
    2. + 트리거 추가 클릭
    3. 설정:
    4. 실행할 함수: sendBatch
    5. 이벤트 소스: 시간 기반
    6. 트리거 유형: 일별 타이머
    7. 시간대: 오전 8시~9시
    8. 저장 클릭

    Step 6: 실패 건만 재발송하기¶

    발송이 모두 끝난 후, D열에 "실패"가 적힌 건만 골라서 재발송하는 함수입니다.

    var className = data[i][2];

    try {
      MailApp.sendEmail({
        to: email,
        subject: subject,
        htmlBody: body,
        attachments: [attachment]
      });
      sheet.getRange(i + 1, 4).setValue('재발송완료');

    실무 TIP 🏷️: "재실패" 건은 이메일 주소 자체가 잘못된 경우가 많습니다. 담당자에게 이메일 주소 확인을 요청하세요.

// ============================
// 2. 분할 발송 (대량용, 트리거 연동)
// ============================
function sendBatch() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONFIG.SHEET_NAME);
  var data = sheet.getDataRange().getValues();
  var file = DriveApp.getFileById(CONFIG.FILE_ID);
  var attachment = file.getBlob();

  var quota = MailApp.getRemainingDailyQuota();
  var safeLimit = quota - CONFIG.SAFE_MARGIN;
  var sentCount = 0;

  if (safeLimit <= 0) {
    Logger.log('한도 부족. 내일 다시 실행됩니다.');
    return;
  }

  for (var i = 1; i < data.length; i++) {
    if (sentCount >= safeLimit) break;

    var studentName = data[i][0];
    var email = data[i][1];
    var className = data[i][2];
    var status = data[i][3];

    if (status === '발송완료' || status === '재발송완료') continue;
    if (!email || email.indexOf('@') === -1) {
      sheet.getRange(i + 1, 4).setValue('실패: 이메일 형식 오류');
      continue;
    }

    var subject = '[' + className + '] ' + studentName + ' 학부모님 상담 안내';
    var body = '<p>' + studentName + ' 학부모님 안녕하세요.</p>'
             + '<p>첨부된 상담 안내문을 확인해 주시기 바랍니다.</p>';

    try {
      MailApp.sendEmail({
        to: email, subject: subject,
        htmlBody: body, attachments: [attachment]
      });
      sheet.getRange(i + 1, 4).setValue('발송완료');
      sheet.getRange(i + 1, 5).setValue(new Date());
      sentCount++;

      if (sentCount % CONFIG.BATCH_SIZE === 0) {
        Utilities.sleep(CONFIG.BATCH_PAUSE);
      }
    } catch (e) {
      sheet.getRange(i + 1, 4).setValue('실패: ' + e.message);
      sheet.getRange(i + 1, 5).setValue(new Date());
    }
  }
  Logger.log('이번 실행: ' + sentCount + '건 발송');
}

    ⚠️ 자주 하는 실수¶

    실수 1: 파일 ID 대신 파일 이름으로 가져오기¶

    // ❌ 위험한 방법 - 동명 파일이 여러 개면 엉뚱한 파일이 첨부됨
var files = DriveApp.getFilesByName('안내문.pdf');
var file = files.next();

// ✅ 안전한 방법 - 파일 ID는 전 세계에서 유일
var file = DriveApp.getFileById('1aBcDeFgHiJk...');

    왜 위험한가요? 구글 드라이브는 같은 이름의 파일을 여러 개 허용합니다. getFilesByName은 어떤 파일이 먼저 나올지 보장하지 않습니다.

    실수 2: 한도 확인 없이 전체 발송 실행¶

    무료 Gmail 계정에서 150명에게 한 번에 보내면 100건째에서 갑자기 멈추고, 나머지 50건은 "실패" 처리됩니다. 더 심각한 문제는 그날 하루 동안 일반 업무 이메일도 보낼 수 없다는 것입니다.

    반드시 MailApp.getRemainingDailyQuota()를 먼저 확인하세요.

    실수 3: 첨부파일 크기를 고려하지 않음¶

    이메일 1건당 첨부파일 합계 25MB가 한계입니다. 고화질 사진 여러 장을 첨부하면 쉽게 초과합니다.

    // 파일 크기 확인 방법
var file = DriveApp.getFileById('파일ID');
var sizeMB = file.getSize() / (1024 * 1024);
Logger.log('파일 크기: ' + sizeMB.toFixed(2) + 'MB');

    대안: 큰 파일은 첨부 대신 공유 링크를 본문에 삽입하세요. file.getUrl()로 링크를 가져올 수 있습니다.

    ✅ 스스로 점검하기¶

    아래 항목을 모두 체크할 수 있으면 이번 차시를 충분히 이해한 것입니다.

    • DriveApp.getFileById()로 구글 드라이브 파일을 가져올 수 있다
    • attachments 옵션을 사용하여 PDF를 이메일에 첨부할 수 있다
    • MailApp.getRemainingDailyQuota()로 남은 발송 한도를 확인할 수 있다
    • 분할 발송 코드가 왜 발송완료 건을 건너뛰는지 설명할 수 있다
    • try-catch로 발송 실패를 감지하고 시트에 기록하는 원리를 이해했다
    • 시간 기반 트리거를 설정하여 매일 자동 실행되게 할 수 있다

    도전 3: 발송 대시보드 만들기

    별도 시트에 발송 통계를 자동 집계하는 함수를 추가해보세요:

    function updateDashboard() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학부모발송');
  var data = sheet.getDataRange().getValues();
  var total = data.length - 1;
  var sent = 0, failed = 0, pending = 0;

  for (var i = 1; i < data.length; i++) {
    var s = String(data[i][3]);
    if (s.indexOf('완료') > -1) sent++;
    else if (s.indexOf('실패') > -1) failed++;
    else pending++;
  }

  Logger.log('전체: ' + total + ' | 완료: ' + sent + ' | 실패: ' + failed + ' | 대기: ' + pending);
}
