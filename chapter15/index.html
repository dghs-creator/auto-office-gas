    구글 클래스룸 자동 생성 ① – 수업 개설과 학생 초대¶

    Part 4: 일정·환경 세팅 자동화 – 학기 초 세팅을 한 번에

    🎯 이 장에서 배우는 것¶

    • Classroom API를 활성화하고 Apps Script에서 연결할 수 있다
    • 스프레드시트에 정리된 수업 정보를 기반으로 여러 수업을 한 번에 자동 생성할 수 있다
    • 학생 이메일 목록을 읽어 각 수업에 자동 초대하는 스크립트를 작성할 수 있다
    • 공동 담당 교사를 자동으로 추가할 수 있다

    💡 왜 이걸 배우나요?¶

    CASE STUDY: 교과 F 선생님의 3월

    새 학기가 시작되면 F 선생님은 매번 같은 작업을 반복합니다. 1학년 1반부터 2학년 4반까지 8개 수업을 구글 클래스룸에 하나씩 만들고, 반별로 30~35명의 학생 이메일을 일일이 입력해 초대합니다.

    수업 하나당 약 10분, 학생 초대까지 포함하면 수업당 20분. 총 160분(약 2시간 40분)을 클릭과 타이핑에 씁니다. 그런데 매년 3월이면 이 작업을 반복합니다.

    이 장을 마치면, F 선생님의 2시간 40분 작업이 3분으로 줄어듭니다.

    비즈니스 환경에서도 동일합니다. 사내 교육 과정을 부서별로 개설하거나, 프로젝트별 워크스페이스를 만들 때 "스프레드시트 하나로 일괄 생성" 패턴은 반복적으로 활용됩니다.

    📚 핵심 개념¶

    개념 1: Classroom API란?¶

    비유: 구글 클래스룸 웹사이트가 "매장 카운터"라면, Classroom API는 "매장 뒤편의 도매 창구"입니다. 카운터에서는 한 명씩 주문을 받지만, 도매 창구에서는 주문서 한 장으로 수백 건을 한꺼번에 처리할 수 있습니다.

    정확한 정의: Classroom API는 구글이 제공하는 프로그래밍 인터페이스로, 코드를 통해 수업 생성·학생 초대·과제 배부 등을 자동으로 수행할 수 있게 해주는 서비스입니다.

    예시로 확인: Apps Script에서 Classroom.Courses.create() 한 줄을 호출하면, 웹에서 클릭 5번 할 작업이 코드 한 줄로 끝납니다.

    실무 TIP: Classroom API는 Google Workspace for Education뿐 아니라, 일반 Google Workspace 계정에서도 사용 가능합니다. 다만 개인 Gmail 계정에서는 일부 기능이 제한될 수 있습니다.

    개념 2: 고급 서비스(Advanced Services) 활성화¶

    비유: 스마트폰에 앱이 설치되어 있어도, 처음 실행할 때 "권한 허용"을 눌러야 카메라나 위치를 쓸 수 있죠? Apps Script의 고급 서비스도 마찬가지입니다. Classroom API는 기본으로 꺼져 있어서, 수동으로 켜주는 단계가 필요합니다.

    정확한 정의: Apps Script의 "고급 서비스"란 Google의 REST API를 Apps Script 환경에서 직접 호출할 수 있도록 래핑(wrapping)한 기능입니다. Classroom, Calendar, Drive 등 다양한 API를 이 방식으로 사용합니다.

    활성화 절차 요약:

    1. Apps Script 에디터 왼쪽 메뉴 → 서비스(+) 클릭
    2. 목록에서 Google Classroom API 선택
    3. 추가 버튼 클릭
    4. Google Cloud 프로젝트에서도 Classroom API가 사용 설정되어 있는지 확인
    flowchart LR A["Apps Script 에디터"] --> B["왼쪽 메뉴: 서비스 +"] B --> C["Google Classroom API 선택"] C --> D["추가 클릭"] D --> E["✅ Classroom 사용 가능"]

    주의사항: Google Workspace 관리자가 Classroom API를 조직 단위에서 비활성화해 둔 경우, 개인이 켤 수 없습니다. 이 경우 IT 관리자에게 API 활성화를 요청하세요.

    개념 3: 스프레드시트 기반 데이터 설계¶

    비유: 요리를 시작하기 전에 재료를 손질해두는 "미장플라스(mise en place)"처럼, 자동화의 첫 단계는 데이터를 깔끔하게 정리하는 것입니다.

    정확한 정의: 자동화 스크립트가 읽어갈 수 있도록, 수업 정보와 학생 정보를 정해진 형식으로 스프레드시트에 정리하는 것을 말합니다.

    시트 구조 – "수업목록" 시트:

    • A열 (수업명): 예) "2025 수학 1-1반"
    • B열 (섹션): 예) "1학년 1반"
    • C열 (설명): 예) "2025학년도 1학기 수학 수업"
    • D열 (과목): 예) "수학"
    • E열 (생성여부): 스크립트 실행 후 "완료" 표시용

    시트 구조 – "학생목록" 시트:

    • A열 (수업명): "수업목록" 시트의 A열과 정확히 일치
    • B열 (학생이메일): 예) "student01@school.edu"
    • C열 (초대여부): 스크립트 실행 후 "완료" 표시용

    실무 TIP: 수업명을 "키(key)"로 사용하므로, 두 시트 간 수업명이 정확히 일치해야 합니다. 공백이나 오타 하나가 오류의 원인이 됩니다. 데이터 유효성 검사(드롭다운)를 활용하면 실수를 줄일 수 있습니다.

    개념 4: Classroom.Courses & Classroom.Invitations¶

    비유: Classroom.Courses는 "수업이라는 방을 만드는 도구"이고, Classroom.Invitations는 "그 방에 초대장을 보내는 도구"입니다. 방을 먼저 만들고, 그다음 초대장을 보내는 2단계 프로세스입니다.

    주요 메서드 정리:

    • Classroom.Courses.create(resource) → 수업 생성, courseId 반환
    • Classroom.Invitations.create(resource) → 학생/교사 초대
    • Classroom.Courses.list() → 기존 수업 목록 조회

    초대 역할 구분:

    • "STUDENT" → 학생으로 초대
    • "TEACHER" → 공동 담당 교사로 초대
    flowchart TB subgraph "1단계: 수업 생성" A["시트에서 수업 정보 읽기"] --> B["Classroom.Courses.create()"] B --> C["courseId 저장"] end subgraph "2단계: 학생 초대" C --> D["시트에서 학생 이메일 읽기"] D --> E["Classroom.Invitations.create()"] E --> F["초대 완료 표시"] end

    🔨 따라하기¶

    Step 1: 스프레드시트 준비하기¶

    1. 구글 드라이브에서 새 스프레드시트를 만들고, 이름을 클래스룸 자동생성으로 지정합니다.
    2. 첫 번째 시트 탭 이름을 수업목록으로 변경합니다.
    3. 1행(헤더)에 다음을 입력합니다:
    4. A1: 수업명
    5. B1: 섹션
    6. C1: 설명
    7. D1: 과목
    8. E1: courseId
    9. F1: 생성여부
    10. 2행부터 테스트 데이터를 입력합니다:
    11. A2: 2025 수학 1-1반 / B2: 1학년1반 / C2: 2025학년도 1학기 / D2: 수학
    12. A3: 2025 수학 1-2반 / B3: 1학년2반 / C3: 2025학년도 1학기 / D3: 수학
    13. 두 번째 시트 탭을 추가하고 이름을 학생목록으로 변경합니다.
    14. 1행(헤더)에 다음을 입력합니다:
    15. A1: 수업명
    16. B1: 학생이메일
    17. C1: 초대여부
    18. 2행부터 테스트 데이터를 입력합니다:
    19. A2: 2025 수학 1-1반 / B2: student01@your-domain.com
    20. A3: 2025 수학 1-1반 / B3: student02@your-domain.com
    21. A4: 2025 수학 1-2반 / B4: student03@your-domain.com

    주의사항: 테스트 시에는 본인 소유의 이메일이나 테스트용 계정을 사용하세요. 실제 학생 이메일로 테스트하면 불필요한 초대 알림이 발송됩니다.

    Step 2: Classroom API 활성화하기¶

    1. 스프레드시트 메뉴 → 확장 프로그램 → Apps Script 클릭
    2. 왼쪽 패널에서 서비스 옆의 + 버튼 클릭
    3. 스크롤해서 Google Classroom API 찾기 → 추가 클릭
    4. 왼쪽 서비스 목록에 Classroom이 표시되면 성공

    실무 TIP: "Google Classroom API를 찾을 수 없다"는 경우, Google Cloud Console(console.cloud.google.com)에 접속해서 해당 프로젝트의 API 및 서비스 → 라이브러리에서 "Google Classroom API"를 검색하여 직접 활성화하세요.

    Step 3: 수업 일괄 생성 코드 작성¶

    Apps Script 에디터에서 기본 Code.gs 파일에 다음 코드를 입력합니다.

    /**
 * "수업목록" 시트를 읽어 구글 클래스룸 수업을 일괄 생성합니다.
 */
function createCourses() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('수업목록');
  var data = sheet.getDataRange().getValues();

  // 1행은 헤더이므로 2행(index 1)부터 시작
  for (var i = 1; i < data.length; i++) {
    var courseName = data[i][0]; // A열: 수업명
    var section    = data[i][1]; // B열: 섹션
    var description = data[i][2]; // C열: 설명
    var subject    = data[i][3]; // D열: 과목
    var existingId = data[i][4]; // E열: courseId (이미 생성된 경우)
    var status     = data[i][5]; // F열: 생성여부

    // 이미 생성된 수업은 건너뛰기
    if (status === '완료') {
      Logger.log('건너뜀: ' + courseName);
      continue;
    }

    // 수업명이 비어있으면 건너뛰기
    if (!courseName) continue;

    try {
      // Classroom API로 수업 생성
      var course = Classroom.Courses.create({
        name: courseName,
        section: section,
        descriptionHeading: description,
        room: subject,
        ownerId: 'me',
        courseState: 'PROVISIONED'  // 준비 상태로 생성
      });

      // 생성된 courseId와 상태를 시트에 기록
      sheet.getRange(i + 1, 5).setValue(course.id);        // E열
      sheet.getRange(i + 1, 6).setValue('완료');             // F열

      Logger.log('생성 완료: ' + courseName + ' (ID: ' + course.id + ')');

      // API 호출 간 잠시 대기 (속도 제한 방지)
      Utilities.sleep(1000);

    } catch (e) {
      sheet.getRange(i + 1, 6).setValue('오류: ' + e.message);
      Logger.log('오류 발생: ' + courseName + ' - ' + e.message);
    }
  }

  SpreadsheetApp.getUi().alert('수업 생성이 완료되었습니다!');
}

    코드 핵심 포인트:

    • courseState: 'PROVISIONED' → 수업을 "준비 중" 상태로 생성합니다. 모든 설정이 끝난 후 ACTIVE로 변경하면 학생에게 공개됩니다.
    • continue 패턴 → 이미 "완료"된 행은 건너뛰어, 스크립트를 여러 번 실행해도 중복 생성되지 않습니다.
    • Utilities.sleep(1000) → API 호출 사이에 1초 대기하여 속도 제한(quota)에 걸리지 않도록 합니다.

    Step 4: 학생 자동 초대 코드 작성¶

    같은 Code.gs 파일 아래에 이어서 작성합니다.

    /**
 * "학생목록" 시트를 읽어 각 수업에 학생을 자동 초대합니다.
 */
function inviteStudents() {
  var courseSheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('수업목록');
  var studentSheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학생목록');

  // 수업명 → courseId 매핑 생성
  var courseData = courseSheet.getDataRange().getValues();
  var courseMap = {};
  for (var i = 1; i < courseData.length; i++) {
    var name = courseData[i][0];
    var id = courseData[i][4];
    if (name && id) {
      courseMap[name] = id;
    }
  }

  // 학생 목록 순회하며 초대
  var studentData = studentSheet.getDataRange().getValues();
  var count = 0;

  for (var j = 1; j < studentData.length; j++) {
    var courseName = studentData[j][0];  // A열: 수업명
    var email      = studentData[j][1];  // B열: 학생 이메일
    var invited    = studentData[j][2];  // C열: 초대여부

    // 이미 초대된 학생은 건너뛰기
    if (invited === '완료') continue;
    if (!courseName || !email) continue;

    // 수업명으로 courseId 찾기
    var courseId = courseMap[courseName];
    if (!courseId) {
      studentSheet.getRange(j + 1, 3).setValue('수업없음');
      continue;
    }

    try {
      Classroom.Invitations.create({
        courseId: courseId,
        userId: email,
        role: 'STUDENT'
      });

      studentSheet.getRange(j + 1, 3).setValue('완료');
      count++;
      Logger.log('초대 완료: ' + email + ' → ' + courseName);

      Utilities.sleep(500);

    } catch (e) {
      studentSheet.getRange(j + 1, 3).setValue('오류: ' + e.message);
      Logger.log('초대 오류: ' + email + ' - ' + e.message);
    }
  }

  SpreadsheetApp.getUi().alert(count + '명의 학생 초대가 완료되었습니다!');
}

    코드 핵심 포인트:

    • courseMap 객체 → 수업명을 키로, courseId를 값으로 저장해서 빠르게 조회합니다.
    • role: 'STUDENT' → 'TEACHER'로 바꾸면 공동 담당 교사 초대가 됩니다.
    • 수업없음 표시 → 학생목록의 수업명이 수업목록과 일치하지 않을 때 즉시 확인 가능합니다.

    Step 5: 공동 담당 교사 추가 (보너스)¶

    교사 초대도 같은 구조입니다. role만 변경하면 됩니다.

    /**
 * 공동 담당 교사를 특정 수업에 추가합니다.
 * 시트에 별도 "교사목록" 탭을 만들거나, 아래처럼 직접 호출합니다.
 */
function inviteTeacher(courseId, teacherEmail) {
  try {
    Classroom.Invitations.create({
      courseId: courseId,
      userId: teacherEmail,
      role: 'TEACHER'
    });
    Logger.log('교사 초대 완료: ' + teacherEmail);
  } catch (e) {
    Logger.log('교사 초대 오류: ' + e.message);
  }
}

    실무 TIP: 교사 초대용 시트도 학생목록과 동일한 구조로 만들면, inviteStudents() 함수의 role을 'TEACHER'로 바꾼 버전을 복사해서 바로 쓸 수 있습니다.

/**
 * 스프레드시트 메뉴에 커스텀 메뉴를 추가합니다.

function onOpen() {
  SpreadsheetApp.getUi()

    .addItem('1. 수업 일괄 생성', 'createCourses')

    .addSeparator()
    .addItem('3. 수업 활성화(ACTIVE)', 'activateCourses')
    .addToUi();

/**
 * "수업목록" 시트를 읽어 구글 클래스룸 수업을 일괄 생성합니다.
 */
function createCourses() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('수업목록');
  var data = sheet.getDataRange().getValues();
  var created = 0;

  for (var i = 1; i < data.length; i++) {
    var courseName  = data[i][0];
    var section     = data[i][1];
    var description = data[i][2];
    var subject     = data[i][3];
    var status      = data[i][5];

    if (status === '완료' || !courseName) continue;

    try {
      var course = Classroom.Courses.create({
        name: courseName,
        section: section,
        descriptionHeading: description,
        room: subject,
        ownerId: 'me',
        courseState: 'PROVISIONED'
      });

      sheet.getRange(i + 1, 5).setValue(course.id);
      sheet.getRange(i + 1, 6).setValue('완료');
      created++;
      Utilities.sleep(1000);

    } catch (e) {
      sheet.getRange(i + 1, 6).setValue('오류: ' + e.message);
    }
  }

  SpreadsheetApp.getUi().alert(created + '개 수업이 생성되었습니다!');
}

/**
 * "학생목록" 시트를 읽어 각 수업에 학생을 자동 초대합니다.
 */
function inviteStudents() {
  var courseSheet  = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('수업목록');
  var studentSheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('학생목록');

  var courseData = courseSheet.getDataRange().getValues();
  var courseMap = {};
  for (var i = 1; i < courseData.length; i++) {
    if (courseData[i][0] && courseData[i][4]) {
      courseMap[courseData[i][0]] = courseData[i][4];
    }
  }

  var studentData = studentSheet.getDataRange().getValues();
  var count = 0;

  for (var j = 1; j < studentData.length; j++) {
    var courseName = studentData[j][0];
    var email      = studentData[j][1];
    var invited    = studentData[j][2];

    if (invited === '완료' || !courseName || !email) continue;

    var courseId = courseMap[courseName];
    if (!courseId) {
      studentSheet.getRange(j + 1, 3).setValue('수업없음');
      continue;
    }

    try {
      Classroom.Invitations.create({
        courseId: courseId,
        userId: email,
        role: 'STUDENT'
      });
      studentSheet.getRange(j + 1, 3).setValue('완료');
      count++;
      Utilities.sleep(500);

    } catch (e) {
      studentSheet.getRange(j + 1, 3).setValue('오류: ' + e.message);
    }
  }

  SpreadsheetApp.getUi().alert(count + '명의 학생 초대가 완료되었습니다!');
}

/**
 * 생성된 수업을 ACTIVE 상태로 변경합니다.
 */
function activateCourses() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('수업목록');
  var data = sheet.getDataRange().getValues();
  var activated = 0;

  for (var i = 1; i < data.length; i++) {
    var courseId = data[i][4];
    if (!courseId || data[i][5] !== '완료') continue;

    try {
      Classroom.Courses.patch(
        { courseState: 'ACTIVE' },
        courseId,
        { updateMask: 'courseState' }
      );
      activated++;
      Utilities.sleep(500);
    } catch (e) {
      Logger.log('활성화 오류: ' + e.message);
    }
  }

  SpreadsheetApp.getUi().alert(activated + '개 수업이 활성화되었습니다!');
}

    ⚠️ 자주 하는 실수¶

    실수 1: 🔴 Classroom API 활성화를 잊고 실행¶

    증상: "Classroom is not defined" 또는 "Classroom has no method" 오류

    해결: Apps Script 에디터 → 서비스(+) → Google Classroom API 추가를 반드시 먼저 수행하세요. 추가한 후에도 에디터를 새로고침해야 인식되는 경우가 있습니다.

    실수 2: 🔴 수업명 불일치로 학생 초대 실패¶

    증상: 학생목록 시트의 C열에 "수업없음"이 계속 표시됨

    해결: 수업목록의 A열과 학생목록의 A열이 공백, 대소문자, 특수문자까지 완벽히 일치해야 합니다. TRIM() 함수로 앞뒤 공백을 제거하거나, 드롭다운 유효성 검사를 활용하세요.

    실수 3: 🔴 API 속도 제한(Quota) 초과¶

    증상: "Rate Limit Exceeded" 또는 "RESOURCE_EXHAUSTED" 오류

    해결: Utilities.sleep(1000) 으로 호출 간격을 두세요. 한 번에 100개 이상의 초대를 보낼 때는 sleep 값을 1500~2000으로 늘리는 것이 안전합니다.

    실수 4: 🔴 개인 Gmail 계정으로 실행¶

    증상: "@gmail.com does not have permission" 류의 권한 오류

    해결: Classroom API는 Google Workspace 계정(조직 계정)에서 원활하게 작동합니다. 개인 Gmail에서는 수업 생성은 가능하지만 학생 초대에 제약이 있을 수 있습니다.
