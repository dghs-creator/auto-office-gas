    수행평가·성적 집계 ① – 점수 합산과 등급 자동 계산¶

    Part 5 | 문서 생성·성적 처리 자동화 – 개별 문서와 성적을 한 번에

    🎯 이 장에서 배우는 것¶

    • 여러 수행평가 항목의 점수를 자동 합산하는 스크립트를 작성할 수 있다
    • 가중치(반영 비율)가 다른 항목들의 점수를 정확히 계산할 수 있다
    • 총점 기준으로 등급(A~E)을 자동 부여하는 코드를 활용할 수 있다
    • 등급 기준표를 별도 시트에 관리하여 유연하게 운영할 수 있다

    💡 왜 이걸 배우나요?¶

    교과 H 선생님의 상황

    "국어 수행평가 5개 항목, 학생이 120명입니다. 항목마다 배점이 다르고, 매번 계산기로 합산하고 등급표 보면서 등급 적는 데만 반나절이 걸려요. 한 줄이라도 밀리면 처음부터 다시 확인해야 하고요."

    익숙한 상황이시죠? 이 문제는 비단 학교만의 이야기가 아닙니다. 직원 평가 점수 합산, 프로젝트 성과 등급 부여, 거래처 신용 등급 산정 등 비즈니스 현장에서도 동일한 패턴이 반복됩니다.

    이번 장에서 만드는 스크립트 하나면, 점수 입력만 마치면 합산·등급이 자동으로 채워집니다. 반나절 걸리던 작업이 3초로 줄어듭니다.

    📚 핵심 개념¶

    개념 1: 점수 합산 – "장바구니에 물건 담기"¶

    비유 🛒 마트에서 장바구니에 물건을 하나씩 담으면, 계산대에서 바코드를 찍어 총액이 나옵니다. 점수 합산도 똑같습니다. 각 항목의 점수를 하나씩 읽어서 더하면 총점이 됩니다.

    정확한 정의 시트의 특정 행에서 여러 열(항목)에 입력된 숫자 값을 순회하며 누적 합계를 구하는 것입니다. Apps Script에서는 getRange().getValues()로 2차원 배열을 가져온 뒤, 각 행(row)의 항목 열을 반복문으로 더합니다.

    예시로 확인 - 학생 A: 발표(18) + 토론(15) + 에세이(22) + 독서록(9) + 퀴즈(16) = 80점 - 코드 관점: row[1] + row[2] + row[3] + row[4] + row[5]

    실무 TIP: 항목 수가 바뀔 수 있으므로, 열 번호를 하드코딩하지 말고 시작 열~끝 열을 변수로 관리하세요.

    개념 2: 가중치 적용 – "과목마다 학점이 다르다"¶

    비유 🎓 대학 학점 계산할 때 3학점 과목 A와 1학점 과목 A는 GPA에 미치는 영향이 다릅니다. 가중치 적용도 같은 원리입니다. "이 항목이 전체에서 얼마나 중요한가"를 비율로 반영하는 것이죠.

    정확한 정의 각 항목의 원점수에 해당 항목의 가중치(weight)를 곱한 뒤 합산합니다. 가중치의 총합은 보통 1(=100%)로 맞춥니다.

    가중 총점 = (항목1 점수 × 가중치1) + (항목2 점수 × 가중치2) + ...

    예시로 확인 – 체육 실기+필기 - 실기: 85점 × 0.7(70%) = 59.5 - 필기: 90점 × 0.3(30%) = 27.0 - 가중 총점: 86.5점

    주의사항: 가중치 합이 1이 아니면 점수가 왜곡됩니다. 스크립트에 가중치 합 검증 로직을 넣어두면 실수를 방지할 수 있습니다.

    개념 3: 등급 자동 부여 – "자동 분류 기계"¶

    비유 🏭 택배 분류 센터에서 무게별로 컨베이어 벨트가 갈라지듯, 총점 범위에 따라 등급이 자동으로 분류됩니다.

    정확한 정의 미리 정의한 등급 기준표(컷오프)를 기준으로, 총점이 어느 구간에 속하는지 판별하여 등급 문자열을 반환하는 로직입니다.

    예시로 확인 - 90점 이상 → A - 80점 이상 → B - 70점 이상 → C - 60점 이상 → D - 60점 미만 → E

    코드에서는 if-else 체인 또는 등급 기준 배열을 순회하는 방식으로 구현합니다. 후자가 기준 변경에 훨씬 유연합니다.

    개념 4: 등급 기준표 시트 분리 – "설정 파일은 따로"¶

    비유 ⚙️ 게임의 난이도 설정을 게임 코드 안에 박아두면 난이도를 바꿀 때마다 개발자를 불러야 합니다. 설정 파일을 따로 두면 누구나 수정할 수 있죠. 등급 기준표도 마찬가지입니다.

    정확한 정의 등급 경계값(컷오프)을 코드에 직접 쓰지 않고, 별도 시트("등급기준")에 입력해 둡니다. 스크립트는 실행 시 이 시트를 읽어 기준을 적용하므로, 기준이 바뀌어도 코드 수정 없이 시트만 고치면 됩니다.

    핵심 포인트 요약 - 합산: 각 행의 항목 점수를 반복문으로 누적 - 가중치: 점수 × 가중치를 곱한 뒤 합산, 가중치 합 = 1 검증 - 등급: 기준 배열 순회로 구간 판별 - 기준표 분리: 시트에서 읽어오면 유지보수가 쉬움

    🔨 따라하기¶

    실습 시나리오¶

    국어 수행평가 5개 항목(발표, 토론, 에세이, 독서록, 퀴즈)의 점수를 합산하고, 등급을 자동 부여합니다. 항목별 가중치가 다릅니다.

    Step 1: 스프레드시트 준비¶

    "점수입력" 시트 구성 (1행은 헤더):

    • A열: 이름
    • B열: 발표 (배점 20)
    • C열: 토론 (배점 20)
    • D열: 에세이 (배점 25)
    • E열: 독서록 (배점 15)
    • F열: 퀴즈 (배점 20)
    • G열: 가중총점 ← 스크립트가 채움
    • H열: 등급 ← 스크립트가 채움

    샘플 데이터를 5명 이상 입력하세요. 예시:

    • 김민수: 18, 15, 22, 12, 16
    • 이지은: 20, 18, 25, 14, 19
    • 박서준: 12, 10, 15, 8, 11

    Step 2: 등급기준 시트 만들기¶

    같은 스프레드시트에 "등급기준" 시트를 추가합니다.

    • A열: 등급 (A, B, C, D, E)
    • B열: 최소점수 (90, 80, 70, 60, 0)
    행2: A | 90
행3: B | 80
행4: C | 70
행5: D | 60
행6: E | 0

    실무 TIP: 등급을 높은 순서대로 입력하세요. 코드가 위에서부터 순회하며 첫 번째로 만족하는 등급을 반환합니다.

    Step 3: 가중치 설정 이해¶

    5개 항목의 배점이 다르므로, 각 항목의 만점 대비 비율을 가중치로 사용합니다.

    • 발표: 20/100 = 0.20
    • 토론: 20/100 = 0.20
    • 에세이: 25/100 = 0.25
    • 독서록: 15/100 = 0.15
    • 퀴즈: 20/100 = 0.20
    • 합계: 1.00 ✅

    이 방식을 쓰면, 원점수 그대로의 합산이 곧 100점 만점 가중 합산이 됩니다. 만약 항목별 배점이 동일하지 않은데 반영 비율을 별도로 지정하고 싶다면(예: 실기 70%, 필기 30%), 가중치를 명시적으로 배열에 넣어야 합니다.

    Step 4: 핵심 코드 작성¶

    Apps Script 에디터를 열고(확장 프로그램 → Apps Script) 아래 코드를 입력합니다.

    /**
 * 점수 합산 및 등급 자동 계산
 * 시트 "점수입력"의 B~F열 점수를 가중 합산하여 G열에,
 * "등급기준" 시트 기반으로 H열에 등급을 기록합니다.
 */
function calculateGrades() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();

  // ── 1. 등급 기준 읽기 ──
  var gradeSheet = ss.getSheetByName("등급기준");
  var gradeData = gradeSheet.getRange(2, 1, gradeSheet.getLastRow() - 1, 2).getValues();
  // gradeData = [["A",90], ["B",80], ["C",70], ["D",60], ["E",0]]

  // ── 2. 가중치 설정 ──
  var weights = [0.20, 0.20, 0.25, 0.15, 0.20]; // 발표,토론,에세이,독서록,퀴즈

  // 가중치 합 검증
  var weightSum = weights.reduce(function(a, b) { return a + b; }, 0);
  if (Math.abs(weightSum - 1.0) > 0.001) {
    SpreadsheetApp.getUi().alert("⚠️ 가중치 합이 " + weightSum + "입니다. 1.0이어야 합니다.");
    return;
  }

  // ── 3. 점수 데이터 읽기 ──
  var dataSheet = ss.getSheetByName("점수입력");
  var lastRow = dataSheet.getLastRow();
  if (lastRow < 2) {
    SpreadsheetApp.getUi().alert("데이터가 없습니다.");
    return;
  }

  var dataRange = dataSheet.getRange(2, 1, lastRow - 1, 6); // A~F열
  var data = dataRange.getValues();

  // ── 4. 합산 및 등급 계산 ──
  var results = []; // [[가중총점, 등급], ...]

  for (var i = 0; i < data.length; i++) {
    var row = data[i];
    var name = row[0];

    // 이름이 비어있으면 건너뜀
    if (!name || name === "") {
      results.push(["", ""]);
      continue;
    }

    // 가중 합산
    var weightedTotal = 0;
    for (var j = 0; j < weights.length; j++) {
      var score = Number(row[j + 1]) || 0; // B열부터 = index 1
      weightedTotal += score * (weights[j] / weights[j]); 
      // 배점=가중치 비율이므로 원점수 합산과 동일
    }

    // 실제 가중 합산 (배점이 다를 때 정규화)
    weightedTotal = 0;
    for (var j = 0; j < weights.length; j++) {
      var score = Number(row[j + 1]) || 0;
      weightedTotal += score; // 이 시나리오에서는 배점 합=100이므로 단순 합산
    }

    // 등급 판별
    var grade = "E"; // 기본값
    for (var k = 0; k < gradeData.length; k++) {
      if (weightedTotal >= gradeData[k][1]) {
        grade = gradeData[k][0];
        break; // 첫 번째 매칭에서 중단
      }
    }

    results.push([weightedTotal, grade]);
  }

  // ── 5. 결과 쓰기 ──
  var outputRange = dataSheet.getRange(2, 7, results.length, 2); // G~H열
  outputRange.setValues(results);

  SpreadsheetApp.getUi().alert("✅ " + results.length + "명의 성적 계산 완료!");
}

    주의사항: 위 코드에서 단순 합산을 사용한 이유는, 이 시나리오의 배점 합계가 정확히 100이기 때문입니다. 배점 합이 100이 아닌 경우를 위해 Step 5에서 범용 가중 합산 코드를 제공합니다.

    Step 5: 범용 가중 합산 함수 (배점이 100이 아닐 때)¶

    실기 70% + 필기 30%처럼 항목 만점이 다르고, 반영 비율도 별도 지정할 때 사용합니다.

    /**
 * 범용 가중 합산 함수
 * @param {Array} scores - 원점수 배열 [85, 90]
 * @param {Array} maxScores - 항목별 만점 배열 [100, 100]
 * @param {Array} weights - 반영 비율 배열 [0.7, 0.3]
 * @returns {number} 100점 만점 환산 점수
 */
function calcWeightedScore(scores, maxScores, weights) {
  var total = 0;
  for (var i = 0; i < scores.length; i++) {
    var ratio = scores[i] / maxScores[i]; // 만점 대비 비율 (0~1)
    total += ratio * weights[i] * 100;     // 가중치 반영 후 100점 환산
  }
  return Math.round(total * 10) / 10; // 소수점 첫째 자리까지
}

// 사용 예시: 체육 실기 85/100(70%) + 필기 90/100(30%)
// calcWeightedScore([85, 90], [100, 100], [0.7, 0.3])
// → 85×0.7 + 90×0.3 = 59.5 + 27.0 = 86.5

    이 함수를 Step 4의 메인 코드에서 호출하면 됩니다:

    // Step 4의 합산 부분을 이렇게 교체
var maxScores = [20, 20, 25, 15, 20]; // 항목별 만점
weightedTotal = calcWeightedScore(
  [row[1], row[2], row[3], row[4], row[5]],
  maxScores,
  weights
);

    📝 전체 코드¶

    /**
 * ========================================
 * 수행평가 점수 합산 및 등급 자동 계산
 * ========================================
 * 
 * [시트 구조]
 * "점수입력" 시트: A(이름), B~F(항목별 점수), G(가중총점), H(등급)
 * "등급기준" 시트: A(등급명), B(최소점수) - 높은 등급부터 정렬
 *
 * [사용법] 
 * Apps Script 에디터에서 calculateGrades() 실행
 * 또는 사용자 정의 메뉴에서 클릭
 */

// ── 사용자 정의 메뉴 등록 ──
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu("🎯 성적 처리")
    .addItem("점수 합산 & 등급 계산", "calculateGrades")
    .addToUi();
}

// ── 범용 가중 합산 함수 ──
function calcWeightedScore(scores, maxScores, weights) {
  var total = 0;
  for (var i = 0; i < scores.length; i++) {
    var s = Number(scores[i]) || 0;
    var m = Number(maxScores[i]) || 1; // 0으로 나누기 방지
    total += (s / m) * weights[i] * 100;
  }
  return Math.round(total * 10) / 10;
}

// ── 등급 판별 함수 ──
function getGrade(score, gradeTable) {
  for (var i = 0; i < gradeTable.length; i++) {
    if (score >= gradeTable[i][1]) {
      return gradeTable[i][0];
    }
  }
  return "등급없음";
}

// ── 메인 함수 ──
function calculateGrades() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var ui = SpreadsheetApp.getUi();

  // 1. 등급 기준 읽기
  var gradeSheet = ss.getSheetByName("등급기준");
  if (!gradeSheet) {
    ui.alert("⚠️ '등급기준' 시트가 없습니다. 시트를 만들어주세요.");
    return;
  }
  var gradeTable = gradeSheet.getRange(2, 1, gradeSheet.getLastRow() - 1, 2).getValues();

  // 2. 설정값 (필요에 따라 수정)
  var weights   = [0.20, 0.20, 0.25, 0.15, 0.20];
  var maxScores = [20,   20,   25,   15,   20];
  var startCol  = 2; // B열 (점수 시작)
  var itemCount = 5; // 항목 수

  // 가중치 합 검증
  var wSum = weights.reduce(function(a, b) { return a + b; }, 0);
  if (Math.abs(wSum - 1.0) > 0.001) {
    ui.alert("⚠️ 가중치 합이 " + wSum.toFixed(3) + "입니다.\n1.0으로 맞춰주세요.");
    return;
  }

  // 3. 점수 데이터 읽기
  var dataSheet = ss.getSheetByName("점수입력");
  if (!dataSheet) {
    ui.alert("⚠️ '점수입력' 시트가 없습니다.");
    return;
  }

  var lastRow = dataSheet.getLastRow();
  if (lastRow < 2) {
    ui.alert("데이터가 없습니다.");
    return;
  }

  var data = dataSheet.getRange(2, 1, lastRow - 1, startCol + itemCount - 1).getValues();

  // 4. 계산
  var results = [];
  var processedCount = 0;

  for (var i = 0; i < data.length; i++) {
    var row = data[i];

    if (!row[0] || row[0] === "") {
      results.push(["", ""]);
      continue;
    }

    var scores = [];
    for (var j = 0; j < itemCount; j++) {
      scores.push(row[j + 1]); // B열부터
    }

    var weightedTotal = calcWeightedScore(scores, maxScores, weights);
    var grade = getGrade(weightedTotal, gradeTable);

    results.push([weightedTotal, grade]);
    processedCount++;
  }

  // 5. 결과 쓰기
  var outputCol = startCol + itemCount; // G열
  dataSheet.getRange(2, outputCol, results.length, 2).setValues(results);

  ui.alert("✅ 완료!\n" + processedCount + "명의 가중총점과 등급을 기록했습니다.");
}

    ⚠️ 자주 하는 실수¶

    실수 1: 가중치 합이 1이 아닌 채로 실행 🔢¶

    가중치를 수정하다가 합계가 0.95나 1.05가 되는 경우가 흔합니다. 코드에 검증 로직을 넣어두었지만, 수정할 때마다 합을 확인하는 습관이 중요합니다. 가중치를 등급기준 시트처럼 별도 시트에서 관리하면 더 안전합니다.

    실수 2: 등급 기준표 정렬 순서가 뒤집힘 🔄¶

    등급기준 시트에서 E(0점)를 맨 위에 놓으면, 모든 학생이 E등급을 받습니다. 높은 등급(A)부터 내림차순으로 정렬해야 if (score >= 최소점수) 로직이 정상 작동합니다.

    실수 3: 점수 셀에 문자열이 섞임 📝¶

    "결석"이나 "-" 같은 텍스트가 점수 셀에 들어있으면 Number() 변환 시 NaN이 됩니다. 코드의 || 0 처리로 0점이 되는데, 이것이 의도한 것인지 확인하세요. 결석자는 별도 처리하는 것이 바람직합니다.

    실수 4: 소수점 반올림 시점 불일치 🔢¶

    항목별로 반올림 → 합산 vs. 합산 → 마지막에 반올림은 결과가 다를 수 있습니다. 최종 합산 후 한 번만 반올림하는 것이 일반적인 관행입니다. 위 코드는 이 방식을 따릅니다.
