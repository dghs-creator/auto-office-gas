    캘린더 일정 일괄 등록 ② – 수정·삭제와 공유 캘린더 관리¶

    Part 4 | [2권] 일정·환경 세팅 자동화 – 학기 초 세팅을 한 번에

    🎯 이 장에서 배우는 것¶

    • 이미 등록된 캘린더 일정을 제목 기준으로 검색할 수 있다
    • 검색한 일정의 날짜·제목을 코드로 일괄 수정할 수 있다
    • 취소된 일정을 코드로 일괄 삭제할 수 있다
    • 학년부·교과부 등 공유 캘린더에 일정을 등록하고 관리할 수 있다

    💡 왜 이걸 배우나요?¶

    💬 "중간고사 일정이 일주일 뒤로 밀렸습니다."

    이 한 마디에 담당자는 캘린더를 열고, 시험 관련 일정 10건을 하나하나 클릭해서 날짜를 바꿉니다. 혹시 빠뜨린 건 없는지 다시 스크롤을 올려 확인하고, 공유 캘린더에도 같은 작업을 반복합니다.

    이 장이 해결하는 현실적 문제 3가지:

    • 🔄 일정 변경: 시험·행사 날짜가 바뀌면 관련 일정 10건을 수작업 → 코드 한 번 실행으로 해결
    • 🗑️ 일정 삭제: 취소된 행사 관련 일정이 캘린더에 남아 혼란 → 키워드로 찾아 일괄 삭제
    • 👥 공유 캘린더: 개인 캘린더에만 등록하면 팀원이 못 봄 → 공유 캘린더 ID 지정으로 팀 전체 반영

    지난 장(13차시)에서 일정을 일괄 등록하는 법을 배웠습니다. 이번 장에서는 등록 이후의 생명주기, 즉 "수정 → 삭제 → 공유" 를 완성합니다. 이 세 가지만 갖추면 캘린더 관리의 전체 사이클이 자동화됩니다.

    📚 핵심 개념¶

    개념 1: 캘린더 일정 검색 – "창고에서 물건 찾기" 🔍¶

    비유부터 시작하겠습니다.

    창고(캘린더)에 물건(일정)을 잔뜩 넣어뒀습니다. 이제 "중간고사"라는 라벨이 붙은 상자만 꺼내고 싶습니다. 모든 상자를 하나씩 열어볼 수는 없으니, 라벨(제목)과 입고일(날짜 범위) 두 가지 조건으로 검색합니다.

    정확한 정의:

    Google Apps Script의 CalendarApp.getDefaultCalendar().getEvents(startDate, endDate) 메서드는 지정한 기간 내의 모든 일정을 배열로 가져옵니다. 여기서 .getTitle() 을 확인하면 제목 기준 필터링이 가능합니다.

    예시로 확인:

    // 2025년 4월의 모든 일정 중 "중간고사"가 포함된 것만 찾기
function findExamEvents() {
  var calendar = CalendarApp.getDefaultCalendar();
  var startDate = new Date('2025-04-01');
  var endDate = new Date('2025-04-30');

  var events = calendar.getEvents(startDate, endDate);
  var results = [];

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle().indexOf('중간고사') !== -1) {
      results.push(events[i]);
      Logger.log('찾음: ' + events[i].getTitle() + ' | ' + events[i].getStartTime());
    }
  }

  Logger.log('총 ' + results.length + '건 발견');
  return results;
}

    실무 TIP: indexOf는 제목에 키워드가 포함되어 있으면 찾습니다. "중간고사 1일차", "중간고사 2일차" 등 모두 잡힙니다. 정확히 일치하는 것만 찾으려면 === 연산자를 사용하세요.

    개념 2: 일정 수정 – "택배 주소 변경" 📝¶

    비유:

    이미 발송된 택배의 배송 주소를 바꾸는 것과 비슷합니다. 택배 송장번호(이벤트 객체)를 알면 운송장 정보(날짜, 제목, 설명)를 변경할 수 있습니다. 핵심은 "먼저 찾고, 그 다음 바꾼다" 는 2단계 과정입니다.

    정확한 정의:

    검색으로 얻은 이벤트 객체에 대해 다음 메서드를 호출하면 일정 내용이 변경됩니다.

    • event.setTitle('새 제목') → 일정 제목 변경
    • event.setTime(newStart, newEnd) → 일정 날짜/시간 변경
    • event.setDescription('새 설명') → 일정 상세 설명 변경
    • event.setLocation('새 장소') → 장소 변경

    예시로 확인:

    // 찾은 일정의 날짜를 7일 뒤로 미루기
function postponeExamEvents() {
  var events = findExamEvents(); // 위에서 만든 검색 함수 재사용

  for (var i = 0; i < events.length; i++) {
    var oldStart = events[i].getStartTime();
    var oldEnd = events[i].getEndTime();

    // 7일(밀리초 환산) 더하기
    var newStart = new Date(oldStart.getTime() + 7 * 24 * 60 * 60 * 1000);
    var newEnd = new Date(oldEnd.getTime() + 7 * 24 * 60 * 60 * 1000);

    events[i].setTime(newStart, newEnd);
    Logger.log('수정 완료: ' + events[i].getTitle() + ' → ' + newStart);
  }

  Logger.log('총 ' + events.length + '건 수정 완료');
}

    주의사항: setTime()은 종일 일정(All-day event)에는 사용할 수 없습니다. 종일 일정은 setAllDayDate(newDate) 또는 setAllDayDates(startDate, endDate)를 사용해야 합니다. 이 부분에서 오류가 자주 발생하니 꼭 구분하세요.

    개념 3: 일정 삭제 – "서류 파쇄기" 🗑️¶

    비유:

    파쇄기에 서류를 넣으면 복구할 수 없듯이, deleteEvent()는 되돌릴 수 없습니다. 그래서 실무에서는 삭제 전에 반드시 "어떤 일정이 삭제 대상인지" 먼저 로그로 확인하는 드라이런(Dry Run) 단계를 거칩니다.

    정확한 정의:

    event.deleteEvent() 메서드를 호출하면 해당 캘린더 일정이 영구 삭제됩니다. 캘린더의 휴지통에 30일간 보관되지만, 코드로 복원하는 API는 제공되지 않습니다.

    예시로 확인:

    // 드라이런 모드: 실제 삭제 없이 대상만 확인
function deleteEventsbyKeyword(keyword, dryRun) {
  var calendar = CalendarApp.getDefaultCalendar();
  var startDate = new Date('2025-04-01');
  var endDate = new Date('2025-06-30');

  var events = calendar.getEvents(startDate, endDate);
  var deleteCount = 0;

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle().indexOf(keyword) !== -1) {
      if (dryRun) {
        Logger.log('[삭제 예정] ' + events[i].getTitle() + ' | ' + events[i].getStartTime());
      } else {
        events[i].deleteEvent();
        Logger.log('[삭제 완료] ' + events[i].getTitle());
      }
      deleteCount++;
    }
  }

  Logger.log('총 ' + deleteCount + '건 ' + (dryRun ? '삭제 예정' : '삭제 완료'));
}

// 사용법
// deleteEventsbyKeyword('체육대회', true);  // 먼저 확인
// deleteEventsbyKeyword('체육대회', false); // 확인 후 실제 삭제

    실무 TIP: 삭제 함수에는 항상 dryRun 파라미터를 만드세요. true로 먼저 실행 → 로그 확인 → false로 실행 이 3단계가 데이터 사고를 막는 안전장치입니다.

    개념 4: 공유 캘린더 – "공용 게시판에 글 올리기" 📋¶

    비유:

    개인 캘린더는 내 책상 위 플래너이고, 공유 캘린더는 사무실 벽에 걸린 공용 게시판입니다. 내 플래너에 적으면 나만 보지만, 공용 게시판에 적으면 팀원 전체가 봅니다. 차이는 딱 하나, "어떤 캘린더에 등록하느냐" 입니다.

    정확한 정의:

    CalendarApp.getDefaultCalendar() 대신 CalendarApp.getCalendarById('캘린더ID') 를 사용하면 공유 캘린더에 접근합니다. 캘린더 ID는 Google 캘린더 설정에서 확인할 수 있는 이메일 형식의 고유 식별자입니다.

    캘린더 ID를 찾는 방법:

    1. Google 캘린더 웹 → 좌측 "다른 캘린더" 옆 점 3개(⋮) 클릭
    2. "설정 및 공유" 선택
    3. "캘린더 통합" 섹션의 캘린더 ID 복사
    4. 형식: abcdefg1234@group.calendar.google.com
    // 공유 캘린더에 일정 등록하기
function addEventToSharedCalendar() {
  // 공유 캘린더 ID (Google 캘린더 설정에서 복사)
  var calendarId = 'abcdefg1234@group.calendar.google.com'; // ← 실제 ID로 교체
  var sharedCalendar = CalendarApp.getCalendarById(calendarId);

  if (!sharedCalendar) {
    Logger.log('⚠️ 캘린더를 찾을 수 없습니다. ID를 확인하세요.');
    return;
  }

  sharedCalendar.createEvent(
    '2분기 전략 회의',
    new Date('2025-07-15 14:00'),
    new Date('2025-07-15 16:00'),
    { description: '전 부서 참석', location: '대회의실' }
  );

  Logger.log('공유 캘린더에 등록 완료!');
}

    주의사항: 공유 캘린더에 일정을 등록하려면 해당 캘린더에 대한 "일정 변경" 이상의 권한이 있어야 합니다. "일정 보기만" 권한으로는 등록·수정·삭제가 불가능합니다. 관리자에게 권한을 요청하세요.

    flowchart LR A[캘린더 유형 선택] --> B{개인용?} B -->|Yes| C["getDefaultCalendar()"] B -->|No| D{공유 캘린더 ID 있음?} D -->|Yes| E["getCalendarById('ID')"] D -->|No| F[캘린더 설정에서 ID 확인] F --> E C --> G[createEvent / setTime / deleteEvent] E --> G

    📌 핵심 포인트: 개인 캘린더와 공유 캘린더의 코드 차이는 첫 줄의 캘린더 객체 가져오기 부분뿐입니다. 나머지 등록·수정·삭제 코드는 완전히 동일합니다.

    🔨 따라하기: 시험 일정 변경 일괄 수정 시스템 만들기¶

    시나리오¶

    중간고사 일정이 1주일 연기되었습니다. 이미 등록된 "중간고사" 관련 일정 5건의 날짜를 일괄 수정하고, 취소된 "모의고사" 일정 3건을 삭제하며, 변경된 일정을 학년부 공유 캘린더에도 반영해야 합니다.

    이 실습을 통해 검색 → 수정 → 삭제 → 공유 캘린더 등록의 전체 흐름을 완성합니다.

    Step 1: 스프레드시트에 일정 관리 시트 만들기 📊¶

    먼저 일정 데이터를 관리할 스프레드시트를 준비합니다.

    Google 스프레드시트를 새로 만들고, 시트 이름을 일정관리 로 설정하세요.

    A1부터 다음 데이터를 입력합니다:

    • A1: 제목 | B1: 시작일 | C1: 종료일 | D1: 설명 | E1: 작업 | F1: 상태
    • A2: 중간고사 1일차 | B2: 2025-04-21 | C2: 2025-04-21 | D2: 국어·수학 | E2: 수정 | F2: (비워둠)
    • A3: 중간고사 2일차 | B3: 2025-04-22 | C3: 2025-04-22 | D3: 영어·과학 | E3: 수정 | F3: (비워둠)
    • A4: 중간고사 3일차 | B4: 2025-04-23 | C4: 2025-04-23 | D4: 사회·기술 | E4: 수정 | F4: (비워둠)
    • A5: 모의고사 1차 | B5: 2025-05-10 | C5: 2025-05-10 | D5: 전교생 대상 | E5: 삭제 | F5: (비워둠)
    • A6: 모의고사 2차 | B6: 2025-05-17 | C6: 2025-05-17 | D6: 전교생 대상 | E6: 삭제 | F6: (비워둠)

    E열("작업")의 의미:

    • 수정: 기존 캘린더 일정을 찾아서 날짜를 변경
    • 삭제: 기존 캘린더 일정을 찾아서 삭제
    • 등록: 새로 캘린더에 추가 (13차시에서 배운 내용)

    실무 TIP: F열("상태")은 코드가 자동으로 "수정완료", "삭제완료" 등을 기록합니다. 처리 결과를 시트에서 바로 확인할 수 있어 추적 관리가 쉬워집니다.

    Step 2: 일정 검색 함수 만들기 🔍¶

    스프레드시트의 확장 프로그램 → Apps Script 를 클릭하여 스크립트 편집기를 엽니다. 기존 코드를 모두 지우고 아래 코드를 입력합니다.

    /**
 * 캘린더에서 제목으로 일정을 검색하는 함수
 * @param {string} keyword - 검색할 키워드
 * @param {Date} searchStart - 검색 시작일
 * @param {Date} searchEnd - 검색 종료일
 * @param {Calendar} calendar - 검색할 캘린더 객체
 * @return {CalendarEvent[]} - 검색된 일정 배열
 */
function searchEvents(keyword, searchStart, searchEnd, calendar) {
  var events = calendar.getEvents(searchStart, searchEnd);
  var matched = [];

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle().indexOf(keyword) !== -1) {
      matched.push(events[i]);
    }
  }

  return matched;
}

    이 함수는 이후 모든 작업(수정·삭제)의 기초 부품입니다. 키워드를 받아서 해당 기간 내의 일정을 찾아 배열로 돌려줍니다.

    실무 TIP: 검색 함수를 별도로 분리해두면 수정·삭제·확인 등 다양한 용도로 재사용할 수 있습니다. "한 함수는 한 가지 일만 한다"는 원칙을 지키세요.

    Step 3: 일정 일괄 수정 함수 만들기 ✏️¶

    검색 함수 아래에 이어서 입력합니다.

    /**
 * 키워드로 일정을 찾아 날짜를 이동시키는 함수
 * @param {string} keyword - 검색할 키워드 (제목에 포함된 텍스트)
 * @param {number} daysToShift - 이동할 일수 (양수: 미래, 음수: 과거)
 * @param {Calendar} calendar - 대상 캘린더
 */
function shiftEventsByKeyword(keyword, daysToShift, calendar) {
  var searchStart = new Date('2025-01-01');
  var searchEnd = new Date('2025-12-31');

  var events = searchEvents(keyword, searchStart, searchEnd, calendar);

  if (events.length === 0) {
    Logger.log('⚠️ "' + keyword + '" 관련 일정을 찾지 못했습니다.');
    return 0;
  }

  var shiftMs = daysToShift * 24 * 60 * 60 * 1000; // 일수를 밀리초로 변환

  for (var i = 0; i < events.length; i++) {
    var event = events[i];

    // 종일 일정인지 확인
    if (event.isAllDayEvent()) {
      var oldDate = event.getAllDayStartDate();
      var newDate = new Date(oldDate.getTime() + shiftMs);

      // 여러 날짜에 걸친 종일 일정 처리
      var oldEndDate = event.getAllDayEndDate();
      var newEndDate = new Date(oldEndDate.getTime() + shiftMs);

      event.setAllDayDates(newDate, newEndDate);
    } else {
      // 시간이 지정된 일정
      var oldStart = event.getStartTime();
      var oldEnd = event.getEndTime();
      var newStart = new Date(oldStart.getTime() + shiftMs);
      var newEnd = new Date(oldEnd.getTime() + shiftMs);

      event.setTime(newStart, newEnd);
    }

    Logger.log('✅ 수정: ' + event.getTitle() + ' → ' + event.getStartTime());
  }

  Logger.log('총 ' + events.length + '건 수정 완료 (' + daysToShift + '일 이동)');
  return events.length;
}

    코드 핵심 포인트:

    • 종일 일정 vs 시간 지정 일정: isAllDayEvent()로 구분하여 각각 다른 메서드 사용
    • 일수 → 밀리초 변환: 일수 × 24 × 60 × 60 × 1000 이 공식을 기억하세요
    • 음수 입력 가능: daysToShift에 -7을 넣으면 1주일 앞당기기

    Step 4: 일정 일괄 삭제 함수 만들기 🗑️¶

    /**
 * 키워드로 일정을 찾아 삭제하는 함수 (드라이런 지원)
 * @param {string} keyword - 검색할 키워드
 * @param {Calendar} calendar - 대상 캘린더
 * @param {boolean} dryRun - true면 삭제하지 않고 대상만 로그 출력
 * @return {number} 삭제(예정) 건수
 */
function deleteEventsByKeyword(keyword, calendar, dryRun) {
  var searchStart = new Date('2025-01-01');
  var searchEnd = new Date('2025-12-31');

  var events = searchEvents(keyword, searchStart, searchEnd, calendar);

  if (events.length === 0) {
    Logger.log('⚠️ "' + keyword + '" 관련 일정을 찾지 못했습니다.');
    return 0;
  }

  for (var i = 0; i < events.length; i++) {
    var event = events[i];
    var title = event.getTitle();
    var date = event.getStartTime();

    if (dryRun) {
      Logger.log('🔍 [삭제 예정] ' + title + ' | ' + date);
    } else {
      event.deleteEvent();
      Logger.log('🗑️ [삭제 완료] ' + title + ' | ' + date);
    }
  }

  var action = dryRun ? '삭제 예정' : '삭제 완료';
  Logger.log('총 ' + events.length + '건 ' + action);
  return events.length;
}

    주의사항: 삭제는 되돌릴 수 없습니다. 반드시 dryRun을 true로 먼저 실행하여 삭제 대상을 확인한 후, false로 변경하여 실제 삭제를 진행하세요.

    Step 5: 스프레드시트 연동 메인 함수 만들기 🔗¶

    이제 핵심입니다. 스프레드시트의 데이터를 읽어서 자동으로 수정·삭제를 실행하는 메인 함수를 만듭니다.

    /**
 * 스프레드시트의 일정관리 시트를 읽어 캘린더를 일괄 업데이트하는 메인 함수
 */
function updateCalendarFromSheet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('일정관리');
  var data = sheet.getDataRange().getValues();

  // 기본 캘린더 사용 (공유 캘린더는 Step 6에서 추가)
  var calendar = CalendarApp.getDefaultCalendar();

  var summary = { modified: 0, deleted: 0, errors: 0 };

  // 1행은 헤더이므로 2행부터 시작 (인덱스 1)
  for (var i = 1; i < data.length; i++) {
    var row = i + 1; // 시트의 실제 행 번호
    var title = data[i][0];    // A열: 제목
    var newDate = data[i][1];  // B열: 새 날짜
    var action = data[i][4];   // E열: 작업 (수정/삭제)

    if (!title || !action) continue; // 빈 행 건너뛰기

    try {
      if (action === '수정') {
        var result = modifySingleEvent(title, newDate, calendar);
        sheet.getRange(row, 6).setValue(result ? '✅ 수정완료' : '⚠️ 미발견');
        if (result) summary.modified++;

      } else if (action === '삭제') {
        var result = deleteSingleEvent(title, calendar);
        sheet.getRange(row, 6).setValue(result ? '🗑️ 삭제완료' : '⚠️ 미발견');
        if (result) summary.deleted++;
      }

    } catch (e) {
      sheet.getRange(row, 6).setValue('❌ 오류: ' + e.message);
      summary.errors++;
      Logger.log('오류 (행 ' + row + '): ' + e.message);
    }
  }

  // 실행 결과 요약
  Logger.log('===== 실행 결과 =====');
  Logger.log('수정: ' + summary.modified + '건');
  Logger.log('삭제: ' + summary.deleted + '건');
  Logger.log('오류: ' + summary.errors + '건');

  SpreadsheetApp.getUi().alert(
    '캘린더 업데이트 완료!\n\n' +
    '수정: ' + summary.modified + '건\n' +
    '삭제: ' + summary.deleted + '건\n' +
    '오류: ' + summary.errors + '건'
  );
}

/**
 * 제목이 정확히 일치하는 일정 1건을 찾아 날짜를 변경
 */
function modifySingleEvent(title, newDate, calendar) {
  var searchStart = new Date('2025-01-01');
  var searchEnd = new Date('2025-12-31');
  var events = calendar.getEvents(searchStart, searchEnd);

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle() === title) {
      var targetDate = new Date(newDate);

      if (events[i].isAllDayEvent()) {
        events[i].setAllDayDate(targetDate);
      } else {
        // 기존 시간 유지하면서 날짜만 변경
        var oldStart = events[i].getStartTime();
        var oldEnd = events[i].getEndTime();
        var duration = oldEnd.getTime() - oldStart.getTime();

        targetDate.setHours(oldStart.getHours(), oldStart.getMinutes());
        var newEnd = new Date(targetDate.getTime() + duration);

        events[i].setTime(targetDate, newEnd);
      }

      Logger.log('✅ 수정: ' + title + ' → ' + targetDate);
      return true;
    }
  }

  return false; // 일정을 찾지 못함
}

/**
 * 제목이 정확히 일치하는 일정 1건을 찾아 삭제
 */
function deleteSingleEvent(title, calendar) {
  var searchStart = new Date('2025-01-01');
  var searchEnd = new Date('2025-12-31');
  var events = calendar.getEvents(searchStart, searchEnd);

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle() === title) {
      events[i].deleteEvent();
      Logger.log('🗑️ 삭제: ' + title);
      return true;
    }
  }

  return false; // 일정을 찾지 못함
}

    Step 6: 공유 캘린더 지원 추가하기 👥¶

    이제 마지막 단계입니다. 스프레드시트에 G열("캘린더ID") 를 추가하여, 행마다 다른 캘린더에 작업할 수 있게 확장합니다.

    스프레드시트에 추가:

    • G1: 캘린더ID
    • G2~G4: (비워두면 기본 캘린더 사용)
    • 공유 캘린더에 등록할 행에는 실제 캘린더 ID 입력

    메인 함수의 캘린더 선택 부분을 아래와 같이 수정합니다.

    /**
 * 공유 캘린더를 지원하는 개선된 메인 함수
 */
function updateCalendarFromSheetV2() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('일정관리');
  var data = sheet.getDataRange().getValues();

  var defaultCalendar = CalendarApp.getDefaultCalendar();
  var calendarCache = {}; // 캘린더 객체를 캐시하여 반복 조회 방지

  var summary = { modified: 0, deleted: 0, registered: 0, errors: 0 };

  for (var i = 1; i < data.length; i++) {
    var row = i + 1;
    var title = data[i][0];       // A열: 제목
    var startDate = data[i][1];   // B열: 시작일
    var endDate = data[i][2];     // C열: 종료일
    var description = data[i][3]; // D열: 설명
    var action = data[i][4];      // E열: 작업
    var calId = data[i][6];       // G열: 캘린더ID (선택)

    if (!title || !action) continue;

    // 캘린더 선택: G열이 비어있으면 기본 캘린더, 있으면 해당 공유 캘린더
    var calendar;
    if (!calId || calId === '') {
      calendar = defaultCalendar;
    } else {
      // 캐시에 있으면 재사용, 없으면 새로 가져오기
      if (!calendarCache[calId]) {
        calendarCache[calId] = CalendarApp.getCalendarById(calId);
      }
      calendar = calendarCache[calId];

      if (!calendar) {
        sheet.getRange(row, 6).setValue('❌ 캘린더 ID 오류');
        summary.errors++;
        continue;
      }
    }

    try {
      if (action === '수정') {
        var result = modifySingleEvent(title, startDate, calendar);
        sheet.getRange(row, 6).setValue(result ? '✅ 수정완료' : '⚠️ 미발견');
        if (result) summary.modified++;

      } else if (action === '삭제') {
        var result = deleteSingleEvent(title, calendar);
        sheet.getRange(row, 6).setValue(result ? '🗑️ 삭제완료' : '⚠️ 미발견');
        if (result) summary.deleted++;

      } else if (action === '등록') {
        // 13차시에서 배운 등록 기능도 통합
        var eventDate = new Date(startDate);
        calendar.createAllDayEvent(title, eventDate, { description: description });
        sheet.getRange(row, 6).setValue('✅ 등록완료');
        summary.registered++;
      }

    } catch (e) {
      sheet.getRange(row, 6).setValue('❌ ' + e.message);
      summary.errors++;
    }
  }

  SpreadsheetApp.getUi().alert(
    '📅 캘린더 업데이트 완료!\n\n' +
    '등록: ' + summary.registered + '건\n' +
    '수정: ' + summary.modified + '건\n' +
    '삭제: ' + summary.deleted + '건\n' +
    '오류: ' + summary.errors + '건'
  );
}

    실무 TIP: calendarCache 객체를 사용하면 같은 공유 캘린더 ID가 여러 행에 반복될 때 매번 새로 조회하지 않아 실행 속도가 빨라집니다. 일정이 50건 이상이면 체감 차이가 꽤 큽니다.

/**
 * 캘린더에서 제목으로 일정을 검색하는 함수
 */
function searchEvents(keyword, searchStart, searchEnd, calendar) {
  var events = calendar.getEvents(searchStart, searchEnd);
  var matched = [];

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle().indexOf(keyword) !== -1) {
      matched.push(events[i]);
    }
  }

  return matched;
}

/**
 * 제목이 정확히 일치하는 일정 1건을 찾아 날짜를 변경
 */
function modifySingleEvent(title, newDate, calendar) {
  var searchStart = new Date('2025-01-01');
  var searchEnd = new Date('2025-12-31');
  var events = calendar.getEvents(searchStart, searchEnd);

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle() === title) {
      var targetDate = new Date(newDate);

      if (events[i].isAllDayEvent()) {
        events[i].setAllDayDate(targetDate);
      } else {
        var oldStart = events[i].getStartTime();
        var oldEnd = events[i].getEndTime();
        var duration = oldEnd.getTime() - oldStart.getTime();

        targetDate.setHours(oldStart.getHours(), oldStart.getMinutes());
        var newEnd = new Date(targetDate.getTime() + duration);

        events[i].setTime(targetDate, newEnd);
      }

      Logger.log('✅ 수정: ' + title + ' → ' + targetDate);
      return true;
    }
  }
  return false;
}

/**
 * 제목이 정확히 일치하는 일정 1건을 찾아 삭제
 */
function deleteSingleEvent(title, calendar) {
  var searchStart = new Date('2025-01-01');
  var searchEnd = new Date('2025-12-31');
  var events = calendar.getEvents(searchStart, searchEnd);

  for (var i = 0; i < events.length; i++) {
    if (events[i].getTitle() === title) {
      events[i].deleteEvent();
      Logger.log('🗑️ 삭제: ' + title);
      return true;
    }
  }
  return false;
}

/**
 * 스프레드시트 기반 캘린더 일괄 업데이트 (공유 캘린더 지원)
 */
function updateCalendarFromSheetV2() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('일정관리');

  if (!sheet) {
    SpreadsheetApp.getUi().alert('⚠️ "일정관리" 시트를 찾을 수 없습니다.');
    return;
  }

  var data = sheet.getDataRange().getValues();
  var defaultCalendar = CalendarApp.getDefaultCalendar();
  var calendarCache = {};

  var summary = { modified: 0, deleted: 0, registered: 0, errors: 0 };

  for (var i = 1; i < data.length; i++) {
    var row = i + 1;
    var title = data[i][0];
    var startDate = data[i][1];
    var endDate = data[i][2];
    var description = data[i][3];
    var action = String(data[i][4]).trim();
    var calId = data[i][6] ? String(data[i][6]).trim() : '';

    if (!title || !action) continue;

    // 캘린더 선택
    var calendar;
    if (!calId) {
      calendar = defaultCalendar;
    } else {
      if (!calendarCache[calId]) {
        calendarCache[calId] = CalendarApp.getCalendarById(calId);
      }
      calendar = calendarCache[calId];
      if (!calendar) {
        sheet.getRange(row, 6).setValue('❌ 캘린더 ID 오류');
        summary.errors++;
        continue;
      }
    }

    try {
      if (action === '수정') {
        var result = modifySingleEvent(title, startDate, calendar);
        sheet.getRange(row, 6).setValue(result ? '✅ 수정완료' : '⚠️ 미발견');
        if (result) summary.modified++;

      } else if (action === '삭제') {
        var result = deleteSingleEvent(title, calendar);
        sheet.getRange(row, 6).setValue(result ? '🗑️ 삭제완료' : '⚠️ 미발견');
        if (result) summary.deleted++;

      } else if (action === '등록') {
        var eventDate = new Date(startDate);
        if (description) {
          calendar.createAllDayEvent(title, eventDate, { description: description });
        } else {
          calendar.createAllDayEvent(title, eventDate);
        }
        sheet.getRange(row, 6).setValue('✅ 등록완료');
        summary.registered++;
      }

    } catch (e) {
      sheet.getRange(row, 6).setValue('❌ ' + e.message);
      summary.errors++;
      Logger.log('오류 (행 ' + row + '): ' + e.message);
    }
  }

  SpreadsheetApp.getUi().alert(
    '📅 캘린더 업데이트 완료!\n\n' +
    '등록: ' + summary.registered + '건\n' +
    '수정: ' + summary.modified + '건\n' +
    '삭제: ' + summary.deleted + '건\n' +
    '오류: ' + summary.errors + '건'
  );
}

/**
 * 드라이런: 실제 변경 없이 어떤 작업이 실행될지 미리 확인
 */
function dryRunCheck() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('일정관리');
  var data = sheet.getDataRange().getValues();
  var calendar = CalendarApp.getDefaultCalendar();

  var report = '===== 드라이런 결과 =====\n\n';

  for (var i = 1; i < data.length; i++) {
    var title = data[i][0];
    var action = String(data[i][4]).trim();

    if (!title || !action) continue;

    // 해당 일정이 캘린더에 존재하는지 확인
    var events = searchEvents(title, new Date('2025-01-01'), new Date('2025-12-31'), calendar);
    var found = events.length > 0 ? '발견 (' + events.length + '건)' : '미발견';

    report += '[행 ' + (i + 1) + '] ' + action + ': "' + title + '" → ' + found + '\n';
  }

  Logger.log(report);
  SpreadsheetApp.getUi().alert(report);
}

/**
 * UI: 키워드로 일정 검색
 */
function searchByKeywordUI() {
  var ui = SpreadsheetApp.getUi();
  var response = ui.prompt('🔍 일정 검색', '검색할 키워드를 입력하세요:', ui.ButtonSet.OK_CANCEL);

  if (response.getSelectedButton() !== ui.Button.OK) return;

  var keyword = response.getResponseText().trim();
  if (!keyword) return;

  var calendar = CalendarApp.getDefaultCalendar();
  var events = searchEvents(keyword, new Date('2025-01-01'), new Date('2025-12-31'), calendar);

  if (events.length === 0) {
    ui.alert('⚠️ "' + keyword + '" 관련 일정을 찾지 못했습니다.');
    return;
  }

  var report = '🔍 "' + keyword + '" 검색 결과: ' + events.length + '건\n\n';
  for (var i = 0; i < events.length; i++) {
    report += (i + 1) + '. ' + events[i].getTitle() + ' | ' + events[i].getStartTime() + '\n';
  }

  ui.alert(report);
}

/**
 * UI: 키워드로 일괄 삭제
 */
function bulkDeleteUI() {
  var ui = SpreadsheetApp.getUi();
  var response = ui.prompt('🗑️ 일괄 삭제', '삭제할 일정의 키워드를 입력하세요:', ui.ButtonSet.OK_CANCEL);

  if (response.getSelectedButton() !== ui.Button.OK) return;

  var keyword = response.getResponseText().trim();
  if (!keyword) return;

  var calendar = CalendarApp.getDefaultCalendar();
  var events = searchEvents(keyword, new Date('2025-01-01'), new Date('2025-12-31'), calendar);

  if (events.length === 0) {
    ui.alert('⚠️ "' + keyword + '" 관련 일정이 없습니다.');
    return;
  }

  // 삭제 전 확인
  var confirm = ui.alert(
    '⚠️ 삭제 확인',
    '"' + keyword + '" 관련 일정 ' + events.length + '건을 삭제합니다.\n\n이 작업은 되돌릴 수 없습니다. 계속하시겠습니까?',
    ui.ButtonSet.YES_NO
  );

  if (confirm !== ui.Button.YES) return;

  for (var i = 0; i < events.length; i++) {
    events[i].deleteEvent();
  }

  ui.alert('🗑️ ' + events.length + '건 삭제 완료');
}

    코드 실행 순서:

    1. 스크립트를 저장(💾)합니다
    2. 스프레드시트를 새로고침합니다
    3. 상단 메뉴에 📅 캘린더 관리 가 나타납니다
    4. 먼저 "드라이런 (미리보기)" 를 클릭하여 결과를 확인합니다
    5. 이상이 없으면 "일괄 업데이트 실행" 을 클릭합니다

    실무 TIP: 첫 실행 시 Google에서 권한 승인을 요청합니다. "고급 → (안전하지 않은 앱으로 이동)"을 클릭한 뒤, 캘린더 접근 권한을 허용하세요. 이전 차시에서 승인했다면 캘린더 관련 추가 권한만 요청될 수 있습니다.

    ⚠️ 자주 하는 실수¶

    실수 1: 종일 일정에 setTime() 사용 💥¶

    // ❌ 잘못된 코드 – 종일 일정에 setTime 사용하면 오류 발생
event.setTime(new Date('2025-05-01'), new Date('2025-05-02'));

if (event.isAllDayEvent()) {
  event.setAllDayDate(new Date('2025-05-01'));
} else {
  event.setTime(new Date('2025-05-01 09:00'), new Date('2025-05-01 10:00'));

    종일 일정과 시간 지정 일정은 메서드가 다릅니다. isAllDayEvent()로 반드시 확인하세요. 이 구분을 빠뜨리면 Exception: Cannot use setTime on an all-day event 오류가 발생합니다.

    • 이메일 주소(someone@gmail.com)를 넣는 경우 (이건 다른 사람의 기본 캘린더를 의미함)
    • ID 앞뒤에 공백이 포함된 경우

    올바른 캘린더 ID 형식:

    • 공유 캘린더: abc123xyz@group.calendar.google.com

var calendar = CalendarApp.getCalendarById(calId);
if (!calendar) {

    실수 3: 드라이런 없이 바로 삭제 실행 🚨¶

    가장 위험한 실수입니다. 키워드 "회의"로 삭제하려 했는데, "회의실 예약 확인", "분기 회의록 정리" 등 의도하지 않은 일정까지 삭제되는 경우가 있습니다.

    // ❌ 위험 – 바로 삭제
deleteEventsByKeyword('회의', calendar, false);

// ✅ 안전 – 드라이런 먼저, 로그 확인 후 삭제
deleteEventsByKeyword('회의', calendar, true);  // 먼저 대상 확인
// 로그 확인: "분기 전략 회의", "팀 회의" 2건 삭제 예정 → OK!
deleteEventsByKeyword('회의', calendar, false); // 확인 후 삭제

    CASE STUDY: 한 담당자가 "체육"이라는 키워드로 삭제를 실행했는데, "체육대회" 뿐 아니라 "체육관 대관", "체육복 수거" 일정까지 삭제된 사례가 있었습니다. 드라이런이 5초의 수고를 더하지만, 30분의 복구 작업을 예방합니다.

    실수 4: 날짜 형식 불일치 📅¶

    스프레드시트에서 날짜를 읽어올 때, 셀 서식에 따라 문자열로 읽히거나 Date 객체로 읽힐 수 있습니다.

// ✅ 어떤 형식이든 안전하게 Date로 변환
