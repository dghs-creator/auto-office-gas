    신청서 자동 집계 ② – 요약표·현황판 자동 생성¶

    🎯 이 장에서 배우는 것¶

    • 집계 결과를 요약표 형태로 자동 생성하는 코드를 작성할 수 있다
    • 반별·부서별·항목별 통계를 피벗(교차표) 형태로 정리할 수 있다
    • 결과 시트에 서식(헤더 색상, 테두리, 조건부 강조)을 자동 적용할 수 있다
    • 생성된 요약표를 별도 시트에 현황판으로 구성할 수 있다

    💡 왜 이걸 배우나요?¶

    앞 챕터(6장)에서 신청서 원본 데이터를 정리하고 중복·오류를 처리하는 방법을 배웠습니다. 그런데 깨끗한 데이터만으로는 의사결정이 되지 않습니다. 상사에게 보고하거나, 팀원에게 공유할 때 필요한 것은 "한눈에 보이는 요약"입니다.

    🏢 현실 시나리오: 사내 교육 신청을 마감했습니다. 원본 데이터는 200행이 넘는데, 경영진이 원하는 건 "부서별로 몇 명이 어떤 과정에 신청했는지" 한 장짜리 현황표입니다. 매번 수작업으로 피벗을 돌리고 색칠하고 있다면, 오늘 그 작업을 코드 한 번으로 끝내겠습니다.

    코드로 요약표를 만들면 얻는 것 3가지:

    • ⏰ 시간 절약 — 데이터가 바뀌어도 스크립트 한 번 실행으로 최신 현황 완성
    • 🎯 실수 제거 — COUNTIF 범위 잘못 잡는 사고가 사라짐
    • 📊 일관된 서식 — 매번 같은 디자인의 보고용 시트가 자동 생성

    📚 핵심 개념¶

    개념 1: 피벗 집계 — "데이터를 축 기준으로 접어 세는 것"¶

    비유: 세탁물을 종류별(상의/하의/양말)로, 다시 색상별(흰색/검정)로 분류해서 각 칸에 몇 개인지 적는 것과 같습니다. 가로축 = 종류, 세로축 = 색상, 칸 안의 숫자 = 개수. 이것이 피벗입니다.

    정의: 원본 데이터에서 두 개의 범주(행 기준, 열 기준)를 잡고, 교차하는 셀에 개수·합계·비율 등을 계산하여 2차원 표로 만드는 작업입니다.

    예시: 사내 교육 신청 데이터에서 부서를 행, 신청 과정을 열로 놓으면, "마케팅팀에서 엑셀 과정에 신청한 사람이 5명"처럼 정리됩니다.

    원본 200행 → 부서(10) × 과정(4) = 40칸짜리 요약표

    개념 2: 별도 시트 자동 생성 — "보고서 전용 공간을 코드가 만든다"¶

    비유: 회의실 예약 시스템처럼, 코드가 알아서 "회의실(시트)이 없으면 새로 만들고, 이미 있으면 내용을 비우고 다시 세팅"하는 것입니다.

    정의: Apps Script에서 insertSheet() 또는 getSheetByName()을 활용하여 결과 전용 시트를 프로그래밍 방식으로 생성·초기화하는 패턴입니다.

    핵심 패턴:

    function getOrCreateSheet(ss, name) {
  let sheet = ss.getSheetByName(name);
  if (sheet) {
    sheet.clear(); // 기존 내용 초기화
  } else {
    sheet = ss.insertSheet(name);
  }
  return sheet;
}

    실무 TIP: 시트 이름에 날짜를 넣고 싶다면 "현황판_" + Utilities.formatDate(new Date(), "Asia/Seoul", "yyyyMMdd") 패턴을 쓰세요.

    개념 3: 2차원 배열 조립 — "표를 메모리에서 먼저 완성하고 한 번에 붙인다"¶

    비유: 레고 블록을 바닥에 하나씩 붙이는 대신, 작업대에서 전체 모양을 완성한 뒤 한 번에 베이스 플레이트에 올리는 것입니다. 셀을 하나씩 쓰면 느리지만, 2차원 배열을 만들어서 setValues()로 한 번에 쓰면 수십 배 빠릅니다.

    정의: JavaScript 2차원 배열([[행1열1, 행1열2], [행2열1, 행2열2]])에 요약 결과를 채운 뒤, sheet.getRange(row, col, numRows, numCols).setValues(array)로 일괄 출력하는 기법입니다.

    // 느린 방법 (❌ 셀 하나씩)
for (let i = 0; i < 100; i++) {
  sheet.getRange(i+1, 1).setValue(data[i]);
}

// 빠른 방법 (✅ 한 번에)
sheet.getRange(1, 1, data.length, data[0].length).setValues(data);

    개념 4: 자동 서식 적용 — "보고서 품질을 코드로 보장한다"¶

    비유: 프린터가 인쇄와 동시에 제본·코팅까지 해주는 것처럼, 데이터 출력과 동시에 헤더 색상, 테두리, 숫자 포맷, 조건부 강조까지 코드가 처리합니다.

    주요 메서드 정리:

    • setBackground(color) — 셀 배경색 지정 (예: "#4472C4")
    • setFontColor(color) — 글자색 (예: "#FFFFFF")
    • setBorder(top, left, bottom, right, vertical, horizontal) — 테두리
    • setNumberFormat(format) — 숫자/날짜 형식 (예: "#,##0")
    • setFontWeight("bold") — 볼드 처리

    🔨 따라하기¶

    실습 시나리오: 사내 교육 신청 데이터(이름, 부서, 신청 과정, 신청일)가 "신청원본"이라는 시트에 있습니다. 이 데이터를 부서별 × 과정별 인원 현황표로 자동 생성하겠습니다.

    Step 1: 샘플 데이터 준비¶

    Google 스프레드시트에서 "신청원본" 시트를 만들고 아래와 같은 구조로 데이터를 입력하세요. (최소 10행 이상 권장)

    • A열: 이름
    • B열: 부서 (마케팅, 영업, 개발, 인사, 재무 등)
    • C열: 신청과정 (엑셀실무, 데이터분석, 프레젠테이션, 리더십)
    • D열: 신청일 (2025-01-15 형태)
    1행(헤더): 이름 | 부서 | 신청과정 | 신청일
2행: 김철수 | 마케팅 | 엑셀실무 | 2025-01-15
3행: 이영희 | 영업 | 데이터분석 | 2025-01-16
... (10~20행 정도 입력)

    실무 TIP: 실제 업무에서는 Google 설문이나 기존 시스템에서 내보낸 CSV를 붙여넣기 하면 됩니다. 앞 챕터에서 정리한 데이터를 그대로 활용하세요.

    Step 2: Apps Script 편집기 열기 & 피벗 집계 함수 작성¶

    확장 프로그램 → Apps Script를 열고, 아래 코드를 입력합니다.

    /**
 * 신청원본 데이터를 부서별 × 과정별로 피벗 집계하는 함수
 */
function buildPivotData(records) {
  const deptSet = new Set();
  const courseSet = new Set();
  const countMap = {};

  records.forEach(row => {
    const dept = String(row[1]).trim();   // B열: 부서
    const course = String(row[2]).trim(); // C열: 신청과정
    if (!dept || !course) return;

    deptSet.add(dept);
    courseSet.add(course);

    const key = dept + "||" + course;
    countMap[key] = (countMap[key] || 0) + 1;
  });

  const depts = [...deptSet].sort();
  const courses = [...courseSet].sort();

  // 2차원 배열 조립
  const header = ["부서", ...courses, "합계"];
  const body = depts.map(dept => {
    const row = [dept];
    let rowTotal = 0;
    courses.forEach(course => {
      const cnt = countMap[dept + "||" + course] || 0;
      row.push(cnt);
      rowTotal += cnt;
    });
    row.push(rowTotal);
    return row;
  });

  // 하단 합계행
  const totalRow = ["합계"];
  let grandTotal = 0;
  courses.forEach((course, i) => {
    const colSum = body.reduce((sum, r) => sum + r[i + 1], 0);
    totalRow.push(colSum);
    grandTotal += colSum;
  });
  totalRow.push(grandTotal);

  return [header, ...body, totalRow];
}

    이 함수가 하는 일:

    1. 원본 데이터를 한 행씩 돌면서 부서·과정 목록을 수집
    2. "마케팅||엑셀실무" 같은 키로 인원수를 카운트
    3. 헤더행 + 데이터행 + 합계행으로 구성된 2차원 배열을 반환
    flowchart LR A["원본 데이터\n200행"] --> B["buildPivotData()"] B --> C["부서 목록 추출"] B --> D["과정 목록 추출"] B --> E["교차 카운트"] C --> F["2차원 배열 조립\n(헤더+본문+합계)"] D --> F E --> F F --> G["요약표 완성"]

    Step 3: 요약 시트 생성 & 데이터 출력 함수 작성¶

    피벗 데이터를 받아서 새 시트에 출력하는 메인 함수를 작성합니다.

    /**
 * 메인 실행 함수 — 요약 현황판 자동 생성
 */
function createSummaryDashboard() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  // 1) 원본 데이터 읽기
  const srcSheet = ss.getSheetByName("신청원본");
  if (!srcSheet) {
    SpreadsheetApp.getUi().alert("'신청원본' 시트를 찾을 수 없습니다.");
    return;
  }
  const allData = srcSheet.getDataRange().getValues();
  const records = allData.slice(1); // 헤더 제외

  // 2) 피벗 집계
  const pivotData = buildPivotData(records);

  // 3) 결과 시트 생성 (있으면 초기화)
  const summarySheet = getOrCreateSheet(ss, "📊 현황판");

  // 4) 제목 출력
  const title = "사내 교육 신청 현황 (" 
    + Utilities.formatDate(new Date(), "Asia/Seoul", "yyyy.MM.dd") 
    + " 기준)";
  summarySheet.getRange(1, 1).setValue(title);

  // 5) 피벗 데이터 한 번에 출력 (3행부터)
  const startRow = 3;
  const numRows = pivotData.length;
  const numCols = pivotData[0].length;
  summarySheet.getRange(startRow, 1, numRows, numCols).setValues(pivotData);

  // 6) 서식 적용
  applyDashboardStyle(summarySheet, startRow, numRows, numCols);

  // 7) 열 너비 자동 조정
  for (let c = 1; c <= numCols; c++) {
    summarySheet.autoResizeColumn(c);
  }

  SpreadsheetApp.getUi().alert("✅ 현황판이 생성되었습니다!");
}

    /**
 * 현황판 서식 자동 적용
 */
function applyDashboardStyle(sheet, startRow, numRows, numCols) {
  // ── 제목 서식 ──
  const titleRange = sheet.getRange(1, 1, 1, numCols);
  titleRange.merge();
  titleRange.setFontSize(14)
            .setFontWeight("bold")
            .setFontColor("#1F2937")
            .setHorizontalAlignment("center");

  // ── 헤더행 서식 (피벗의 첫 행) ──
  const headerRange = sheet.getRange(startRow, 1, 1, numCols);
  headerRange.setBackground("#4472C4")
             .setFontColor("#FFFFFF")
             .setFontWeight("bold")
             .setHorizontalAlignment("center");

  // ── 데이터 영역 테두리 ──
  const dataRange = sheet.getRange(startRow, 1, numRows, numCols);
  dataRange.setBorder(true, true, true, true, true, true,
                      "#B0B0B0", SpreadsheetApp.BorderStyle.SOLID);

  // ── 합계행 강조 (마지막 행) ──
  const totalRange = sheet.getRange(startRow + numRows - 1, 1, 1, numCols);
  totalRange.setBackground("#D6E4F0")
            .setFontWeight("bold");

  // ── 합계열 강조 (마지막 열) ──
  const totalColRange = sheet.getRange(startRow + 1, numCols, numRows - 1, 1);
  totalColRange.setFontWeight("bold")
               .setBackground("#F0F4F8");

  // ── 숫자 서식 ──
  const numberRange = sheet.getRange(startRow + 1, 2, numRows - 1, numCols - 1);
  numberRange.setNumberFormat("#,##0")
             .setHorizontalAlignment("center");

  // ── 조건부 강조: 0명인 셀 회색 표시 ──
  const rule = SpreadsheetApp.newConditionalFormatRule()
    .whenNumberEqualTo(0)
    .setBackground("#F3F4F6")
    .setFontColor("#9CA3AF")
    .setRanges([numberRange])
    .build();
  const rules = sheet.getConditionalFormatRules();
  rules.push(rule);
  sheet.setConditionalFormatRules(rules);
}

    Step 6: 비율(%) 현황 추가하기¶

    인원수만으로는 부족할 때, 과정별 선택 비율을 함께 보여주는 확장입니다.

    /**
 * 과정별 선택 비율 행을 추가하는 함수
 * createSummaryDashboard()의 5단계 이후에 호출
 */
function addPercentageRow(sheet, startRow, pivotData) {
  const totalRowData = pivotData[pivotData.length - 1]; // 합계행
  const grandTotal = totalRowData[totalRowData.length - 1];

  if (grandTotal === 0) return;

  const pctRow = ["비율(%)"];
  for (let i = 1; i < totalRowData.length - 1; i++) {
    const pct = ((totalRowData[i] / grandTotal) * 100).toFixed(1) + "%";
    pctRow.push(pct);
  }
  pctRow.push("100%");

  const writeRow = startRow + pivotData.length; // 합계행 바로 아래
  sheet.getRange(writeRow, 1, 1, pctRow.length).setValues([pctRow]);

  // 비율행 서식
  const pctRange = sheet.getRange(writeRow, 1, 1, pctRow.length);
  pctRange.setBackground("#FFF3CD")
          .setFontWeight("bold")
          .setHorizontalAlignment("center")
          .setBorder(true, true, true, true, true, true,
                     "#B0B0B0", SpreadsheetApp.BorderStyle.SOLID);
}

    📝 전체 코드¶

    아래는 위 단계를 모두 통합한 완성 코드입니다. 복사해서 바로 실행할 수 있습니다.

    // ===== 유틸리티 =====
function getOrCreateSheet(ss, name) {
  let sheet = ss.getSheetByName(name);
  if (sheet) {
    sheet.clear();
    // 기존 조건부 서식 규칙도 초기화
    sheet.setConditionalFormatRules([]);
  } else {
    sheet = ss.insertSheet(name);
  }
  return sheet;
}

// ===== 피벗 집계 =====
function buildPivotData(records) {
  const deptSet = new Set();
  const courseSet = new Set();
  const countMap = {};

  records.forEach(row => {
    const dept = String(row[1]).trim();
    const course = String(row[2]).trim();
    if (!dept || !course) return;
    deptSet.add(dept);
    courseSet.add(course);
    const key = dept + "||" + course;
    countMap[key] = (countMap[key] || 0) + 1;
  });

  const depts = [...deptSet].sort();
  const courses = [...courseSet].sort();

  const header = ["부서", ...courses, "합계"];
  const body = depts.map(dept => {
    const row = [dept];
    let rowTotal = 0;
    courses.forEach(course => {
      const cnt = countMap[dept + "||" + course] || 0;
      row.push(cnt);
      rowTotal += cnt;
    });
    row.push(rowTotal);
    return row;
  });

  const totalRow = ["합계"];
  let grandTotal = 0;
  courses.forEach((course, i) => {
    const colSum = body.reduce((sum, r) => sum + r[i + 1], 0);
    totalRow.push(colSum);
    grandTotal += colSum;
  });
  totalRow.push(grandTotal);

  return [header, ...body, totalRow];
}

function createSummaryDashboard() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const srcSheet = ss.getSheetByName("신청원본");
  if (!srcSheet) {
    SpreadsheetApp.getUi().alert("'신청원본' 시트를 찾을 수 없습니다.");
    return;
  }

  const records = srcSheet.getDataRange().getValues().slice(1);
  const pivotData = buildPivotData(records);
  const summarySheet = getOrCreateSheet(ss, "📊 현황판");

  // 제목
  const title = "사내 교육 신청 현황 ("
    + Utilities.formatDate(new Date(), "Asia/Seoul", "yyyy.MM.dd")
    + " 기준)";
  summarySheet.getRange(1, 1).setValue(title);

  // 데이터 출력
  const startRow = 3;
  const numRows = pivotData.length;
  const numCols = pivotData[0].length;
  summarySheet.getRange(startRow, 1, numRows, numCols).setValues(pivotData);

  // 비율행 추가
  addPercentageRow(summarySheet, startRow, pivotData);

  // 서식 적용
  applyDashboardStyle(summarySheet, startRow, numRows, numCols);

  // 열 너비 자동 조정
  for (let c = 1; c <= numCols; c++) {
    summarySheet.autoResizeColumn(c);
  }

  SpreadsheetApp.getUi().alert("✅ 현황판이 생성되었습니다!");
}

    ⚠️ 자주 하는 실수¶

    실수 1: 시트 이름 오타로 null 에러¶

    getSheetByName("신청원본")에서 실제 시트 이름이 "신청 원본"(공백 포함)이면 null이 반환되고, 이후 코드에서 Cannot read properties of null 에러가 발생합니다.

    ✅ 해결: 시트 탭을 더블클릭해서 정확한 이름을 확인하세요. 공백, 대소문자 모두 일치해야 합니다.

    실수 2: setValues()에 빈 배열이나 불규칙 배열 전달¶

    모든 행의 열 개수가 동일해야 합니다. 어떤 행은 5열, 어떤 행은 4열이면 에러가 납니다.

    ✅ 해결: buildPivotData()처럼 헤더·본문·합계 모두 같은 열 수로 조립하세요. 빈 값은 0 또는 ""로 채워야 합니다.

    실수 3: clear() 후 조건부 서식이 남아있는 현상¶

    sheet.clear()는 셀 값과 서식을 지우지만, 조건부 서식 규칙은 별도로 관리됩니다. 실행할 때마다 규칙이 중복 추가됩니다.

    ✅ 해결: 전체 코드의 getOrCreateSheet 함수처럼 sheet.setConditionalFormatRules([]) 를 명시적으로 호출하세요.

    실수 4: 데이터에 공백·줄바꿈이 섞여 집계가 쪼개짐¶

    "마케팅"과 "마케팅 "(뒤 공백)이 다른 부서로 집계됩니다.

    ✅ 해결: String(row[1]).trim()으로 양쪽 공백을 반드시 제거하세요. 이미 코드에 포함되어 있지만, 원본 정리 단계에서도 챙기는 것이 안전합니다.

    ✅ 스스로 점검하기¶

    아래 항목을 모두 체크할 수 있으면 이 챕터를 완료한 것입니다.

    • buildPivotData() 함수가 2차원 배열을 반환하는 원리를 설명할 수 있다
    • getOrCreateSheet() 패턴으로 시트를 안전하게 생성/초기화할 수 있다
    • setValues()로 데이터를 일괄 출력하는 것이 셀 단위 출력보다 빠른 이유를 안다
    • 헤더 색상, 테두리, 조건부 서식을 코드로 적용할 수 있다
    • 실행 후 "📊 현황판" 시트에 요약표가 서식과 함께 정상 출력된다
