    나만의 자동화 설계 – 업무 분석부터 스크립트 완성까지¶

    Part 6: 통합 활용과 확장 – 나만의 자동화 시스템 만들기 | 25차시 (최종)

    🎯 이 장에서 배우는 것¶

    • 자신의 반복 업무를 구조적으로 분석하여 자동화 대상을 선정할 수 있다
    • 업무 흐름을 입력 → 처리 → 출력 구조로 설계할 수 있다
    • 이 책에서 배운 코드 블록을 레고처럼 조합하여 나만의 스크립트를 완성할 수 있다
    • 완성된 자동화 스크립트를 점검하고 유지보수 계획을 세울 수 있다

    💡 왜 이걸 배우나요?¶

    지난 24차시 동안 우리는 엑셀 자동화, 웹 데이터 수집, 이메일 발송, 보고서 생성 등 수많은 개별 기술 블록을 익혔습니다. 하지만 현실 업무는 "엑셀만", "이메일만" 따로 돌아가지 않습니다.

    🏗️ 비유: 레고 블록을 하나하나 만드는 법은 배웠습니다. 이제 그 블록들을 조합해서 당신만의 건물을 지을 차례입니다.

    이 마지막 챕터는 "물고기를 잡아주는 장"이 아니라, "낚시하는 법을 완성하는 장"입니다. 여러분이 이 교재를 덮은 후에도 새로운 업무를 스스로 분석하고, 설계하고, 자동화할 수 있는 자립적 역량을 갖추는 것이 목표입니다.

    📚 핵심 개념¶

    개념 1: 업무 자동화 캔버스 🎨¶

    비유: 건축가가 건물을 짓기 전에 설계도를 그리듯, 코드를 쓰기 전에 업무의 전체 그림을 한 장에 정리하는 워크시트입니다.

    정의: 업무 자동화 캔버스란, 하나의 반복 업무를 6가지 요소로 분해하여 한눈에 파악할 수 있게 만든 설계 도구입니다.

    6가지 요소:

    • 업무 이름: 자동화할 작업의 명칭
    • 반복 주기: 매일 / 매주 / 매월 / 특정 이벤트 발생 시
    • 입력(Input): 어디서 어떤 데이터를 가져오는가
    • 처리(Process): 데이터에 어떤 로직을 적용하는가
    • 출력(Output): 결과를 어떤 형태로, 어디에 내보내는가
    • 예외 상황: 데이터가 없거나 오류가 나면 어떻게 하는가
    flowchart LR A["🔍 업무 분석"] --> B["📥 입력 정의"] B --> C["⚙️ 처리 로직"] C --> D["📤 출력 정의"] D --> E["⚠️ 예외 처리"] E --> F["✅ 스크립트 완성"]

    예시 – 주간 매출 보고서 자동화:

    • 업무 이름: 주간 매출 요약 보고서 생성
    • 반복 주기: 매주 월요일 오전 9시
    • 입력: ERP 시스템에서 다운로드한 매출 엑셀 파일
    • 처리: 부서별 합산, 전주 대비 증감률 계산, 차트 생성
    • 출력: PDF 보고서 + 팀장에게 이메일 발송
    • 예외: 파일이 없으면 슬랙 알림 발송

    💡 핵심 포인트: 코드를 한 줄도 쓰기 전에 캔버스부터 채우세요. 설계 없는 코딩은 네비게이션 없는 운전입니다.

    개념 2: 입력 → 처리 → 출력 (IPO) 패턴 🔄¶

    비유: 요리를 생각해보세요. 재료(입력)를 준비하고, 레시피(처리)에 따라 조리하고, 완성된 요리(출력)를 접시에 담습니다. 모든 자동화는 이 세 단계를 따릅니다.

    정의: IPO 패턴은 모든 데이터 처리 작업을 세 가지 단계로 분리하는 구조적 설계 방법입니다.

    flowchart LR subgraph INPUT ["📥 입력"] I1["엑셀 파일 읽기"] I2["웹에서 데이터 수집"] I3["DB 쿼리 결과"] I4["사용자 입력"] end subgraph PROCESS ["⚙️ 처리"] P1["필터링 / 정렬"] P2["계산 / 집계"] P3["병합 / 변환"] P4["조건 분기"] end subgraph OUTPUT ["📤 출력"] O1["엑셀 저장"] O2["이메일 발송"] O3["PDF 보고서"] O4["메신저 알림"] end INPUT --> PROCESS --> OUTPUT

    실무에서 이 패턴이 강력한 이유:

    • 디버깅이 쉽다: 어느 단계에서 문제가 생겼는지 바로 파악 가능
    • 재사용이 쉽다: 입력만 바꾸면 같은 처리 로직을 다른 업무에 적용 가능
    • 확장이 쉽다: 출력을 하나 더 추가하고 싶으면 출력 단계만 수정

    💡 핵심 포인트: 복잡한 업무도 IPO로 쪼개면 단순해집니다. "이 단계는 입력인가, 처리인가, 출력인가?"를 반복해서 물어보세요.

    개념 3: 코드 블록 조합법 🧱¶

    비유: 레고 세트에는 설명서가 있지만, 숙련된 빌더는 블록의 연결 규칙만 알면 설명서 없이도 원하는 것을 만듭니다. 코드 블록도 마찬가지입니다.

    정의: 이 책에서 배운 개별 기능(파일 읽기, 데이터 처리, 이메일 발송 등)을 함수 단위로 정리하고, 필요에 따라 연결하는 방법입니다.

    코드 블록 레퍼런스 카드 (이 책에서 배운 주요 블록):

    📥 입력 블록 - pd.read_excel() — 엑셀 파일 읽기 - pd.read_csv() — CSV 파일 읽기 - requests.get() — 웹 데이터 가져오기 - glob.glob() — 여러 파일 한꺼번에 찾기

    ⚙️ 처리 블록 - df.groupby().agg() — 그룹별 집계 - df.merge() — 데이터 병합 - df.pivot_table() — 피벗 테이블 - df[조건] — 조건부 필터링 - df.apply(함수) — 사용자 정의 변환

    📤 출력 블록 - df.to_excel() — 엑셀 저장 - smtplib — 이메일 발송 - matplotlib — 차트 생성 - openpyxl 서식 — 엑셀 서식 적용

    연결 규칙: 블록 사이에는 항상 pandas DataFrame이 흐릅니다. 입력 블록의 출력이 DataFrame이고, 처리 블록이 DataFrame을 받아 DataFrame을 반환하며, 출력 블록이 최종 DataFrame을 소비합니다.

    flowchart LR A["read_excel()"] -->|DataFrame| B["groupby().agg()"] B -->|DataFrame| C["merge()"] C -->|DataFrame| D["to_excel()"] C -->|DataFrame| E["차트 생성"] C -->|DataFrame| F["이메일 발송"]

    💡 핵심 포인트: DataFrame은 코드 블록 사이를 흐르는 만능 컨베이어 벨트입니다. 어떤 블록을 쓰든 DataFrame만 잘 넘기면 연결됩니다.

    개념 4: 자동화 프로젝트 완성 체크리스트 ✅¶

    비유: 비행기 조종사가 이륙 전 반드시 체크리스트를 확인하듯, 자동화 스크립트도 배포 전 체크리스트가 필요합니다.

    정의: 스크립트를 실무에 투입하기 전에 반드시 검증해야 할 항목들의 목록입니다.

    완성 체크리스트 4단계:

    1단계 – 동작 검증 🔍 - 샘플 데이터로 정상 실행되는가? - 예상 결과와 실제 결과가 일치하는가?

    2단계 – 예외 처리 ⚠️ - 파일이 없을 때 에러 메시지가 명확한가? - 빈 데이터가 들어와도 멈추지 않는가? - 네트워크 오류 시 재시도 로직이 있는가?

    3단계 – 유지보수성 🔧 - 경로, 수신자 등 설정값이 상단에 분리되어 있는가? - 주요 단계마다 로그(print 또는 logging)가 있는가? - 다른 사람이 읽어도 이해할 수 있는 주석이 있는가?

    4단계 – 운영 준비 🚀 - 실행 스케줄이 정해졌는가? (수동 / cron / 작업 스케줄러) - 실행 결과를 누가 확인하는가? - 문제 발생 시 알림 방법이 있는가?

    💡 핵심 포인트: "돌아가는 코드"와 "실무에 쓸 수 있는 코드"는 다릅니다. 체크리스트를 통과해야 진짜 자동화입니다.

    🔨 따라하기: 나만의 자동화 프로젝트 완성¶

    이번 실습에서는 "주간 부서별 경비 보고서 자동 생성 및 이메일 발송" 프로젝트를 처음부터 끝까지 함께 설계하고 완성합니다.

    📌 이 사례를 따라하면서 자신의 업무로 치환하는 연습을 병행하세요.

    Step 1: 업무 분석 – 캔버스 채우기 🔍¶

    가장 먼저, 자동화할 업무를 캔버스로 정리합니다.

    CASE STUDY: 김 과장의 주간 경비 보고

    김 과장은 매주 월요일마다 다음 작업을 반복합니다: 1. 경비 시스템에서 엑셀 파일 다운로드 (5분) 2. 부서별로 합산하고 전주 대비 증감 계산 (30분) 3. 차트가 포함된 요약 엑셀 작성 (20분) 4. 팀장 3명에게 이메일로 발송 (10분)

    총 65분 × 52주 = 연간 56시간을 이 작업에 쓰고 있습니다.

    캔버스 작성 결과:

    • 업무 이름: 주간 부서별 경비 보고서 자동화
    • 반복 주기: 매주 월요일 오전 8시 30분
    • 입력: weekly_expense_YYYYMMDD.xlsx (경비 시스템 다운로드 파일)
    • 처리: 부서별 합산 → 전주 대비 증감률 → 상위 5개 항목 추출 → 차트 생성
    • 출력: 서식이 적용된 엑셀 파일 + 이메일 발송
    • 예외: 파일 미존재 시 본인에게 알림 이메일 발송

    실무 TIP 🎯: 자신의 업무를 분석할 때는 일주일 동안 반복 작업을 할 때마다 메모하세요. "또 이걸 하고 있네"라는 생각이 드는 순간이 자동화 대상입니다.

    Step 4: 처리 블록 작성 – 집계와 비교 ⚙️¶

    핵심 비즈니스 로직을 구현합니다.

    def process_weekly_summary(df_current, df_previous=None):
    """부서별 경비를 집계하고, 전주 대비 증감률을 계산합니다."""

    # --- 1) 부서별 집계 ---
    summary = df_current.groupby("부서").agg(
        총경비=("금액", "sum"),
        건수=("금액", "count"),
        평균단가=("금액", "mean"),
        최대건=("금액", "max")
    ).reset_index()

    summary["평균단가"] = summary["평균단가"].round(0)
    print(f"✅ 부서별 집계 완료: {len(summary)}개 부서")

    # --- 2) 전주 대비 증감률 ---
    if df_previous is not None:
        prev_summary = df_previous.groupby("부서").agg(
            전주경비=("금액", "sum")
        ).reset_index()

        summary = summary.merge(prev_summary, on="부서", how="left")
        summary["전주경비"] = summary["전주경비"].fillna(0)
        summary["증감률(%)"] = (
            (summary["총경비"] - summary["전주경비"]) 
            / summary["전주경비"].replace(0, 1) * 100
        ).round(1)
        print("✅ 전주 대비 증감률 계산 완료")
    else:
        summary["전주경비"] = 0
        summary["증감률(%)"] = 0
        print("⚠️ 전주 데이터 없음 - 증감률 0으로 처리")

    # --- 3) 정렬 ---
    summary = summary.sort_values("총경비", ascending=False)

    return summary

# 실행
summary_df = process_weekly_summary(df_this_week, df_last_week)

    핵심 설계 포인트:

    • df_previous가 None이어도 동작합니다 → 예외 상황을 코드로 흡수
    • .replace(0, 1)로 0으로 나누기 오류를 방지합니다
    • 각 단계마다 print()로 진행 상황을 알립니다

def create_chart(summary_df, output_path):
    """부서별 경비 비교 차트를 생성합니다."""
    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # 차트 1: 부서별 경비 막대그래프
    colors = ['#2E86AB' if val >= 0 else '#E84855' 
              for val in summary_df["증감률(%)"]]
    axes[0].barh(summary_df["부서"], summary_df["총경비"], color=colors)
    axes[0].set_title("부서별 주간 경비", fontsize=14, fontweight='bold')
    axes[0].set_xlabel("금액 (원)")

    # 차트 2: 증감률 
    bar_colors = ['#E84855' if v > 10 else '#2E86AB' 
                  for v in summary_df["증감률(%)"]]
    axes[1].bar(summary_df["부서"], summary_df["증감률(%)"], color=bar_colors)
    axes[1].set_title("전주 대비 증감률", fontsize=14, fontweight='bold')
    axes[1].set_ylabel("증감률 (%)")
    axes[1].axhline(y=0, color='gray', linestyle='--', linewidth=0.8)
    plt.setp(axes[1].xaxis.get_majorticklabels(), rotation=45)

    plt.tight_layout()
    chart_path = output_path.replace('.xlsx', '_chart.png')
    plt.savefig(chart_path, dpi=150, bbox_inches='tight')
    plt.close()
    print(f"✅ 차트 저장 완료: {chart_path}")
    return chart_path


def save_styled_excel(summary_df, output_path):
    """서식이 적용된 엑셀 보고서를 생성합니다."""
    summary_df.to_excel(output_path, index=False, sheet_name="주간경비요약")

    # 서식 적용
    wb = load_workbook(output_path)
    ws = wb.active

    # 헤더 스타일
    header_fill = PatternFill(start_color="2E86AB", fill_color="2E86AB", 
                              patternType="solid")
    header_font = Font(color="FFFFFF", bold=True, size=11)
    thin_border = Border(
        left=Side(style='thin'), right=Side(style='thin'),
        top=Side(style='thin'), bottom=Side(style='thin')
    )

    for cell in ws[1]:
        cell.fill = header_fill
        cell.font = header_font
        cell.alignment = Alignment(horizontal='center')

    # 데이터 영역 서식
    for row in ws.iter_rows(min_row=2, max_row=ws.max_row, 
                            max_col=ws.max_column):
        for cell in row:
            cell.border = thin_border
            cell.alignment = Alignment(horizontal='center')
            # 증감률이 10% 이상이면 빨간 배경
            if cell.column_letter == 'F' and cell.value is not None:
                try:
                    if float(cell.value) > 10:
                        cell.fill = PatternFill(start_color="FFE0E0", 
                                               fill_color="FFE0E0",
                                               patternType="solid")
                except (ValueError, TypeError):
                    pass

    # 열 너비 자동 조정
    for col in ws.columns:
        max_length = max(len(str(cell.value or "")) for cell in col)
        ws.column_dimensions[col[0].column_letter].width = max_length + 4

    wb.save(output_path)
    print(f"✅ 엑셀 보고서 저장 완료: {output_path}")
    return output_path

    Step 6: 이메일 발송과 메인 실행 📧¶

    모든 블록을 연결하는 메인 함수를 완성합니다.

    import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.base import MIMEBase
from email import encoders
import datetime
import logging

# 로깅 설정
logging.basicConfig(
    filename=f"{LOG_DIR}automation_{datetime.date.today()}.log",
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

def send_report_email(recipients, subject, body, attachment_paths):
    """보고서를 첨부하여 이메일을 발송합니다."""
    msg = MIMEMultipart()
    msg['From'] = SENDER_EMAIL
    msg['To'] = ", ".join(recipients)
    msg['Subject'] = subject
    msg.attach(MIMEText(body, 'html'))

    for filepath in attachment_paths:
        with open(filepath, 'rb') as f:
            part = MIMEBase('application', 'octet-stream')
            part.set_payload(f.read())
            encoders.encode_base64(part)
            part.add_header('Content-Disposition', 
                          f'attachment; filename={os.path.basename(filepath)}')
            msg.attach(part)

    try:
        server = smtplib.SMTP(SMTP_SERVER, SMTP_PORT)
        server.starttls()
        server.login(SENDER_EMAIL, SENDER_PASSWORD)
        server.send_message(msg)
        server.quit()
        print(f"✅ 이메일 발송 완료: {len(recipients)}명")
        logging.info(f"이메일 발송 성공: {recipients}")
    except Exception as e:
        print(f"❌ 이메일 발송 실패: {e}")
        logging.error(f"이메일 발송 실패: {e}")

def main():
    """주간 경비 보고서 자동화 메인 프로세스"""
    print("=" * 50)
    print("🚀 주간 경비 보고서 자동화 시작")
    print(f"📅 실행일시: {datetime.datetime.now()}")
    print("=" * 50)
    logging.info("프로세스 시작")

    # Step 1: 입력
    df_this = load_data(THIS_WEEK_FILE)
    df_last = load_data(LAST_WEEK_FILE)

    if df_this is None:
        send_report_email(
            [ALERT_RECIPIENT],
            "⚠️ [자동화 알림] 주간 경비 파일 누락",
            f"<p>{THIS_WEEK_FILE} 파일을 찾을 수 없습니다.</p>",
            []
        )
        logging.error("이번 주 파일 누락으로 종료")
        return

    # Step 2: 처리
    summary = process_weekly_summary(df_this, df_last)

    # Step 3: 출력
    date_str = this_monday.strftime('%Y%m%d')
    output_file = os.path.join(OUTPUT_DIR, f"경비보고서_{date_str}.xlsx")

    excel_path = save_styled_excel(summary, output_file)
    chart_path = create_chart(summary, output_file)

    # Step 4: 이메일 발송
    total_expense = summary["총경비"].sum()
    email_body = f"""
    <h2>📊 주간 부서별 경비 보고서</h2>
    <p>기준일: {this_monday} ~ {this_monday + datetime.timedelta(days=6)}</p>

    <p>상세 내용은 첨부 파일을 확인해주세요.</p>
    <br>
    <p style="color:gray;">이 메일은 자동화 시스템에서 발송되었습니다.</p>
    """

    send_report_email(
        RECIPIENTS,
        f"[주간보고] 부서별 경비 요약 ({date_str})",
        email_body,
        [excel_path, chart_path]
    )

    print("=" * 50)
    print("✅ 모든 프로세스가 완료되었습니다!")
    logging.info("프로세스 정상 완료")

    "내 컴퓨터에서는 잘 되는데?"는 자동화의 적입니다. 스케줄러로 실행될 때는 아무도 모니터를 보고 있지 않습니다.

    # 🙅 예외 처리 없음
df = pd.read_excel(filename)  # 파일이 없으면? 프로그램 크래시!

# 🙆 예외 처리 포함
try:
    df = pd.read_excel(filename)
except FileNotFoundError:
    logging.error(f"파일 없음: {filename}")
    send_alert_email(f"파일을 찾을 수 없습니다: {filename}")
    sys.exit(1)
except Exception as e:
    logging.error(f"예상치 못한 오류: {e}")
    sys.exit(1)

    실수 4 (보너스): 로그를 남기지 않는다 🚫

    2주 전에 보고서가 발송되지 않았다면? 로그가 없으면 원인을 추적할 수 없습니다.

    import logging

logging.basicConfig(
    filename=f"logs/run_{datetime.date.today()}.log",
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

# 주요 단계마다 로그 기록
logging.info("파일 로드 완료")
logging.warning("전주 데이터 없음 - 증감률 0으로 처리")
logging.error("이메일 발송 실패: Connection refused")
