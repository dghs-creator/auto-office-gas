    수행평가·성적 집계 ③ – 성적표 개별 생성과 보안 관리¶

    Part 5 | [2권] 문서 생성·성적 처리 자동화 – 개별 문서와 성적을 한 번에

    🎯 이 장에서 배우는 것¶

    • 성적 데이터를 읽어 학생별 개별 성적표 문서를 자동 생성할 수 있다
    • 생성된 성적표에 학생 본인만 접근하도록 공유 권한을 코드로 설정할 수 있다
    • 성적표를 PDF로 변환하여 이메일 첨부 발송할 수 있다
    • 원본 성적 시트에 보안(시트 보호·범위 잠금)을 적용할 수 있다
    • 합산→등급→석차→성적표 생성→배포를 하나의 워크플로우로 통합 실행할 수 있다

    💡 왜 이걸 배우나요?¶

    성적 데이터를 집계하고 등급·석차까지 매기는 것은 절반에 불과합니다. 학생(또는 학부모, 수강생)에게 "나만 볼 수 있는 개인 성적표"를 전달하는 것이 최종 목표입니다.

    현실에서 벌어지는 일을 떠올려 보세요.

    🏫 30명 학급 × 6개 과목 = 성적표 30장. 엑셀에서 이름 하나하나 바꿔 넣고, PDF로 저장하고, 메일에 하나씩 첨부… 한 학급에 2시간, 5개 학급이면 이틀이 날아갑니다.

    이 장을 마치면 버튼 한 번으로 성적표 생성 → 권한 설정 → 이메일 발송까지 끝납니다. 그리고 성적 데이터가 외부에 유출되지 않도록 시트 보호와 파일 권한까지 코드로 관리합니다.

    실무 TIP: 이 워크플로우는 교육 현장뿐 아니라 인사 평가 결과 통보, 고객별 견적서 발송, 개인별 리포트 배포 등 "동일 양식 × N명 개별 데이터"가 필요한 모든 비즈니스에 그대로 적용됩니다.

    📚 핵심 개념¶

    개념 1: 템플릿 기반 문서 복제 – "붕어빵 틀 전략"¶

    비유부터 시작합시다. 붕어빵 장사를 한다고 상상하세요. 틀(템플릿)은 하나지만, 반죽(데이터)을 바꿔 넣으면 팥붕어빵도, 슈크림붕어빵도 나옵니다. 성적표도 마찬가지입니다.

    정확한 정의: 미리 만들어 둔 구글 문서(Docs) 템플릿을 DriveApp.getFileById().makeCopy()로 복제한 뒤, 본문의 플레이스홀더(예: {{학생이름}})를 실제 데이터로 치환하는 패턴입니다.

    예시로 확인:

    템플릿 본문:
────────────────────────
{{학생이름}} 님의 2025학년도 1학기 성적표

국어: {{국어}}점 ({{국어등급}})
수학: {{수학}}점 ({{수학등급}})
영어: {{영어}}점 ({{영어등급}})
총점: {{총점}}점 | 석차: {{석차}}등
────────────────────────

▼ 치환 후 (김민수):
────────────────────────
김민수 님의 2025학년도 1학기 성적표

국어: 92점 (A)
수학: 88점 (B+)
영어: 95점 (A)
총점: 275점 | 석차: 3등
────────────────────────

    핵심 포인트: 템플릿을 한 번만 잘 만들면, 코드는 "복제 → 치환"만 반복합니다. 디자인 변경이 필요하면 템플릿만 수정하세요.

    개념 2: 파일 공유 권한의 3단계 – "금고·열쇠·잠금 코드"¶

    비유: 성적표 파일은 금고입니다. 금고를 받을 사람에게 열쇠(공유 권한)를 줘야 합니다. 그리고 나머지 사람에게는 잠금 코드를 바꿔서 절대 열 수 없게 해야 합니다.

    정확한 정의: 구글 드라이브의 공유 권한은 크게 세 단계로 관리됩니다.

    graph LR A["파일 생성"] --> B["기본 접근 설정<br/>setSharing()"] B --> C["개별 권한 부여<br/>addViewer() / addEditor()"] C --> D["링크 공유 차단<br/>PRIVATE 설정"] style A fill:#4285F4,color:#fff style B fill:#EA4335,color:#fff style C fill:#34A853,color:#fff style D fill:#FBBC05,color:#000
    • Level 1 – 파일 수준 접근(setSharing): 링크가 있는 누구나 볼 수 있게 할지, 초대받은 사람만 볼 수 있게 할지 결정
    • Level 2 – 개인 권한(addViewer/addEditor): 특정 이메일 주소에 "보기 전용" 또는 "편집" 권한 부여
    • Level 3 – 링크 공유 차단(PRIVATE): 링크만으로는 접근 불가, 반드시 개별 초대 필요

    예시 코드 한 줄:

    file.setSharing(DriveApp.Access.PRIVATE, DriveApp.Permission.NONE);
file.addViewer("student@school.ac.kr");

    → 이 두 줄이면 "이 학생만 열람 가능, 그 외 누구도 접근 불가"가 됩니다.

    핵심 포인트: 성적표는 반드시 PRIVATE + addViewer(개인이메일) 조합을 쓰세요. ANYONE_WITH_LINK는 성적 데이터에 절대 사용하지 마세요.

    개념 3: 시트 보호와 범위 잠금 – "유리 진열장"¶

    비유: 박물관의 유리 진열장을 떠올리세요. 안의 유물(성적 데이터)은 볼 수는 있지만 만질 수 없습니다. 관리자(교사)만 진열장 열쇠를 갖고 있죠.

    정확한 정의: Google Sheets의 Protection 클래스를 사용하면 특정 시트나 셀 범위를 잠가서 허용된 사용자 외에는 수정할 수 없게 만듭니다.

    graph TB subgraph 보호_유형 A["시트 전체 보호<br/>sheet.protect()"] B["특정 범위 보호<br/>range.protect()"] end subgraph 권한_설정 C["편집자 지정<br/>addEditor()"] D["나 자신만 허용<br/>removeEditors()"] end A --> C A --> D B --> C B --> D style A fill:#4285F4,color:#fff style B fill:#34A853,color:#fff style C fill:#FBBC05,color:#000 style D fill:#EA4335,color:#fff

    실무에서 자주 쓰는 두 가지 시나리오:

    • 시나리오 A – 입력 시트 잠금: 성적 원본 데이터가 있는 시트를 통째로 보호 → 실수로 데이터 수정 방지
    • 시나리오 B – 수식 영역만 잠금: 등급·석차 수식이 있는 열만 보호 → 점수 입력은 허용하되 수식은 건드리지 못하게

    핵심 포인트: protection.setWarningOnly(true)를 쓰면 경고만 표시하고 편집은 가능합니다. 성적 데이터에는 반드시 false(완전 차단)로 설정하세요.

    개념 4: 워크플로우 통합 – "컨베이어 벨트"¶

    비유: 자동차 공장의 컨베이어 벨트를 생각해 보세요. 부품 조립 → 도색 → 검수 → 포장이 한 라인에서 연속으로 일어납니다. 성적 처리도 마찬가지입니다.

    graph LR A["① 합산·평균"] --> B["② 등급 산출"] B --> C["③ 석차 계산"] C --> D["④ 성적표 생성"] D --> E["⑤ 권한 설정"] E --> F["⑥ 이메일 발송"] F --> G["⑦ 원본 시트 잠금"] style A fill:#4285F4,color:#fff style B fill:#4285F4,color:#fff style C fill:#4285F4,color:#fff style D fill:#34A853,color:#fff style E fill:#EA4335,color:#fff style F fill:#FBBC05,color:#000 style G fill:#EA4335,color:#fff

    정확한 정의: 앞 챕터(19, 20장)에서 만든 함수들과 이번 장의 함수들을 하나의 main() 함수에서 순서대로 호출하여, 한 번 실행으로 전 과정을 처리하는 통합 스크립트입니다.

    왜 통합이 중요한가:

    • 일관성: 단계별 수동 실행 시 실수(예: 등급 계산 전 석차 산출) 방지
    • 감사 추적: 언제 실행했는지, 몇 명에게 발송했는지 로그 기록
    • 재현 가능: 동일 스크립트로 다음 학기에도 그대로 사용

    핵심 포인트: 통합 스크립트에는 반드시 에러 처리(try-catch)와 실행 로그를 포함하세요. 30명 중 28번째에서 에러가 나면 어디서 멈췄는지 알 수 있어야 합니다.

    1) 성적 데이터 시트 준비

    구글 스프레드시트를 열고 시트 이름을 성적원본으로 설정한 뒤, 아래와 같은 구조로 데이터를 입력하세요 (앞 챕터에서 이미 만든 시트가 있다면 그대로 사용).

    • A1행 (헤더): 학생이름 | 이메일 | 국어 | 수학 | 영어 | 총점 | 평균 | 등급 | 석차

    Step 1: 성적표 개별 생성 – 템플릿 복제와 데이터 치환¶

    🎯 이 단계의 목표: 학생 수만큼 템플릿을 복제하고, 각각의 플레이스홀더를 실제 데이터로 바꿉니다.

    Apps Script 에디터를 열고(확장 프로그램 > Apps Script), 아래 코드를 입력합니다.

    /**
 * Step 1: 학생별 성적표 문서 생성
 * - 템플릿 복제 → 플레이스홀더 치환
 * - 생성된 파일을 지정 폴더에 저장
 */
function createReportCards() {
  // ── 설정값 (여기만 수정하세요) ──
  const SPREADSHEET_ID = '여기에_스프레드시트_ID';
  const TEMPLATE_ID    = '여기에_템플릿_문서_ID';
  const FOLDER_ID      = '여기에_폴더_ID';

  // ── 데이터 읽기 ──
  const ss    = SpreadsheetApp.openById(SPREADSHEET_ID);
  const sheet = ss.getSheetByName('성적원본');
  const data  = sheet.getDataRange().getValues();
  const headers = data[0]; // 첫 행은 헤더

  // ── 폴더·템플릿 준비 ──
  const folder   = DriveApp.getFolderById(FOLDER_ID);
  const template = DriveApp.getFileById(TEMPLATE_ID);
  const today    = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd');
  const totalStudents = data.length - 1; // 헤더 제외

  // ── 학생별 반복 처리 ──
  const results = []; // 결과 추적용

  for (let i = 1; i < data.length; i++) {
    const row = data[i];
    const studentName = row[0];
    const email       = row[1];

    try {
      // 1) 템플릿 복제
      const fileName = studentName + '_2025_1학기_성적표';
      const copy = template.makeCopy(fileName, folder);

      // 2) 문서 열고 플레이스홀더 치환
      const doc  = DocumentApp.openById(copy.getId());
      const body = doc.getBody();

      body.replaceText('\\{\\{학생이름\\}\\}', studentName);
      body.replaceText('\\{\\{국어\\}\\}',     String(row[2]));
      body.replaceText('\\{\\{수학\\}\\}',     String(row[3]));
      body.replaceText('\\{\\{영어\\}\\}',     String(row[4]));
      body.replaceText('\\{\\{총점\\}\\}',     String(row[5]));
      body.replaceText('\\{\\{평균\\}\\}',     String(row[6]));
      body.replaceText('\\{\\{등급\\}\\}',     String(row[7]));
      body.replaceText('\\{\\{석차\\}\\}',     String(row[8]));
      body.replaceText('\\{\\{전체인원\\}\\}', String(totalStudents));
      body.replaceText('\\{\\{발급일\\}\\}',   today);

      // 과목별 등급은 종합 등급과 동일하게 처리 (개별 등급 열이 있다면 수정)
      body.replaceText('\\{\\{국어등급\\}\\}', String(row[7]));
      body.replaceText('\\{\\{수학등급\\}\\}', String(row[7]));
      body.replaceText('\\{\\{영어등급\\}\\}', String(row[7]));

      doc.saveAndClose();

      // 3) 결과 기록
      results.push({
        name: studentName,
        email: email,
        fileId: copy.getId(),
        status: '성공'
      });

      Logger.log('✅ ' + studentName + ' 성적표 생성 완료');

    } catch (e) {
      results.push({
        name: studentName,
        email: email,
        fileId: null,
        status: '실패: ' + e.message
      });
      Logger.log('❌ ' + studentName + ' 생성 실패: ' + e.message);
    }
  }

  // 결과를 스크립트 속성에 임시 저장 (다음 단계에서 사용)
  PropertiesService.getScriptProperties()
    .setProperty('reportResults', JSON.stringify(results));

  Logger.log('📊 전체 ' + totalStudents + '명 중 ' + 
    results.filter(r => r.status === '성공').length + '명 성공');

  return results;
}

    코드 실행 방법: 1. 함수 선택 드롭다운에서 createReportCards 선택 2. ▶ 실행 버튼 클릭 3. 첫 실행 시 구글 드라이브·문서 접근 권한 승인

    주의사항: replaceText의 첫 번째 인자는 정규표현식입니다. {{의 중괄호는 정규식에서 특수문자이므로 \\{\\{로 이스케이프해야 합니다. 이 부분을 빼먹으면 치환이 작동하지 않습니다.

    실행 후 확인: - 지정한 드라이브 폴더에 학생 수만큼 문서가 생성되었는지 확인 - 문서 하나를 열어 플레이스홀더가 실제 데이터로 바뀌었는지 확인

    실무 TIP: 과목별 개별 등급이 필요하다면 성적 원본 시트에 국어등급, 수학등급, 영어등급 열을 별도로 만들고, 해당 열 인덱스를 replaceText에 매핑하세요. 위 코드에서 row[7]을 일괄 사용한 것은 단순화를 위한 것입니다.

    Step 2: 보안 권한 설정 – 학생 본인만 열람 가능하게¶

    🎯 이 단계의 목표: 생성된 성적표에 PRIVATE 권한을 설정하고, 학생 본인 이메일에만 뷰어 권한을 부여합니다.

    /**
 * Step 2: 성적표 파일에 개별 공유 권한 설정
 * - PRIVATE(링크 공유 차단)
 * - 학생 본인에게만 뷰어 권한
 */
function setReportPermissions() {
  // Step 1에서 저장한 결과 불러오기
  const resultsJson = PropertiesService.getScriptProperties()
    .getProperty('reportResults');

  if (!resultsJson) {
    Logger.log('⚠️ 먼저 createReportCards()를 실행하세요.');
    return;
  }

  const results = JSON.parse(resultsJson);
  let successCount = 0;

  for (const item of results) {
    if (item.status !== '성공' || !item.fileId) continue;

    try {
      const file = DriveApp.getFileById(item.fileId);

      // 1) 링크 공유 완전 차단
      file.setSharing(
        DriveApp.Access.PRIVATE,       // 초대받은 사람만 접근
        DriveApp.Permission.NONE       // 링크로는 아무 권한 없음
      );

      // 2) 학생 본인에게 뷰어 권한 부여
      file.addViewer(item.email);

      // 3) 다운로드·복사·인쇄 제한 (Advanced Drive Service 필요)
      // → Step 4에서 추가 설명

      successCount++;
      Logger.log('🔒 ' + item.name + ' 권한 설정 완료 → ' + item.email);

    } catch (e) {
      Logger.log('❌ ' + item.name + ' 권한 설정 실패: ' + e.message);
    }
  }

  Logger.log('🔒 권한 설정 완료: ' + successCount + '/' + results.length + '명');
}

    권한이 제대로 설정되었는지 확인하는 방법: 1. 드라이브 폴더에서 성적표 파일 하나를 우클릭 2. "공유" 클릭 3. "제한됨 - 추가된 사용자만 이 링크로 열 수 있습니다" 확인 4. 공유 목록에 해당 학생 이메일이 "뷰어"로 표시되는지 확인

    주의사항: addViewer()에 잘못된 이메일 주소를 넣으면 에러가 발생합니다. 실행 전 이메일 형식 검증을 추가하면 더 안전합니다.

    Step 3: PDF 변환과 이메일 발송¶

    🎯 이 단계의 목표: 성적표를 PDF로 변환하고, 학생 이메일로 첨부 파일 발송합니다.

    /**
 * Step 3: 성적표 PDF 변환 + 이메일 발송
 * - 구글 문서 → PDF 변환
 * - 학생 이메일로 PDF 첨부 발송
 */
function sendReportCardEmails() {
  const resultsJson = PropertiesService.getScriptProperties()
    .getProperty('reportResults');

  if (!resultsJson) {
    Logger.log('⚠️ 먼저 createReportCards()를 실행하세요.');
    return;
  }

  const results = JSON.parse(resultsJson);
  let sentCount = 0;

  for (const item of results) {
    if (item.status !== '성공' || !item.fileId) continue;

    try {
      // 1) 구글 문서를 PDF로 변환
      const doc = DriveApp.getFileById(item.fileId);
      const pdfBlob = doc.getAs('application/pdf');
      pdfBlob.setName(item.name + '_성적표.pdf');

      // 2) 이메일 발송
      const subject = '[성적표] 2025학년도 1학기 성적표 안내';
      const htmlBody = 
        '<h3>' + item.name + ' 님의 성적표를 보내드립니다.</h3>' +
        '<p>첨부된 PDF를 확인해 주세요.</p>' +
        '<p>온라인에서도 확인 가능합니다: ' +
        '<a href="https://docs.google.com/document/d/' + item.fileId + 
        '/edit">성적표 보기</a></p>' +
        '<hr><p style="color:gray; font-size:12px;">' +
        '본 메일은 자동 발송되었습니다. ' +
        '문의사항은 담당 교사에게 연락해 주세요.</p>';

      MailApp.sendEmail({
        to: item.email,
        subject: subject,
        htmlBody: htmlBody,
        attachments: [pdfBlob]
      });

      sentCount++;
      Logger.log('📧 ' + item.name + ' → ' + item.email + ' 발송 완료');

      // 구글 메일 발송 제한 방지 (일일 1,500통)
      Utilities.sleep(1000); // 1초 대기

    } catch (e) {
      Logger.log('❌ ' + item.name + ' 이메일 발송 실패: ' + e.message);
    }
  }

  Logger.log('📧 이메일 발송 완료: ' + sentCount + '/' + results.length + '명');
}

    실무 TIP: MailApp.getRemainingDailyQuota()를 먼저 호출하면 오늘 남은 이메일 발송 가능 횟수를 확인할 수 있습니다. 무료 계정은 일일 100통, Workspace 계정은 1,500통입니다. 대규모 발송 시 반드시 확인하세요.

    Step 4: 원본 성적 시트 보호 설정¶

    🎯 이 단계의 목표: 성적표 발송 후 원본 데이터가 실수로 변경되지 않도록 시트와 범위를 잠급니다.

    /**
 * Step 4: 원본 성적 시트 보호
 * - 시트 전체 보호 (관리자만 편집)
 * - 수식 범위 추가 보호
 */
function protectGradeSheet() {
  const SPREADSHEET_ID = '여기에_스프레드시트_ID';
  const ADMIN_EMAIL    = '담당자@school.ac.kr'; // 편집 권한을 유지할 이메일

  const ss    = SpreadsheetApp.openById(SPREADSHEET_ID);
  const sheet = ss.getSheetByName('성적원본');

  // ── 방법 1: 시트 전체 보호 ──
  const sheetProtection = sheet.protect()
    .setDescription('성적 원본 데이터 보호 - ' + new Date().toLocaleDateString());

  // 현재 편집자 목록에서 관리자만 남기기
  const editors = sheetProtection.getEditors();
  for (const editor of editors) {
    if (editor.getEmail() !== ADMIN_EMAIL) {
      sheetProtection.removeEditor(editor);
    }
  }

  // ⚠️ 경고만 표시가 아닌, 완전 차단
  sheetProtection.setWarningOnly(false);

  Logger.log('🛡️ 시트 전체 보호 설정 완료');

  // ── 방법 2: 특정 범위만 보호 (수식 영역) ──
  // F열(총점)~I열(석차)에 수식이 있다고 가정
  const lastRow = sheet.getLastRow();
  const formulaRange = sheet.getRange(2, 6, lastRow - 1, 4); // F2:I(lastRow)

  const rangeProtection = formulaRange.protect()
    .setDescription('수식 영역 보호 (총점~석차)');

  const rangeEditors = rangeProtection.getEditors();
  for (const editor of rangeEditors) {
    if (editor.getEmail() !== ADMIN_EMAIL) {
      rangeProtection.removeEditor(editor);
    }
  }
  rangeProtection.setWarningOnly(false);

  Logger.log('🛡️ 수식 범위 보호 설정 완료 (F~I열)');
}

    보호 해제가 필요할 때:

    /**
 * 보호 해제 함수 (다음 학기 데이터 입력 시 사용)
 */
function removeProtections() {
  const ss    = SpreadsheetApp.openById('여기에_스프레드시트_ID');
  const sheet = ss.getSheetByName('성적원본');

  const protections = sheet.getProtections(SpreadsheetApp.ProtectionType.SHEET);
  for (const p of protections) {
    p.remove();
  }

  const rangeProtections = sheet.getProtections(SpreadsheetApp.ProtectionType.RANGE);
  for (const p of rangeProtections) {
    p.remove();
  }

  Logger.log('🔓 모든 보호가 해제되었습니다.');
}

    주의사항: setWarningOnly(true)와 setWarningOnly(false)의 차이는 중요합니다. true는 "편집하시겠습니까?" 경고만 보여주고 실제 편집이 가능합니다. 성적 데이터에는 반드시 false를 사용하세요.

        '<p>처리 인원: ' + successCount + '/' + results.length + '명</p>' +
        '<p>소요 시간: ' + elapsed + '초</p>' +
        '<p>실행 시각: ' + startTime.toLocaleString() + '</p>'
    });

  } catch (e) {
    Logger.log('\n💥 워크플로우 중단: ' + e.message);
    Logger.log('스택 트레이스: ' + e.stack);

    // 에러 발생 시 관리자에게 알림
    MailApp.sendEmail({
      to: Session.getActiveUser().getEmail(),
      subject: '[오류] 성적표 워크플로우 중단',
      htmlBody: '<h3 style="color:red;">워크플로우 오류 발생</h3>' +
        '<p>오류 메시지: ' + e.message + '</p>' +
        '<p>발생 시각: ' + new Date().toLocaleString() + '</p>'
    });
  }
}

    실무 TIP: 이전 챕터의 함수(calculateTotalsAndAverages, assignGrades, calculateRanking)가 같은 프로젝트에 없다면, 해당 함수들을 이 프로젝트에도 복사해 넣거나, 라이브러리로 연결하세요. 통합 스크립트의 핵심은 모든 함수가 같은 실행 환경에 존재하는 것입니다.

    Step 6: 실행 확인과 트러블슈팅¶

    🎯 이 단계의 목표: 실행 결과를 검증하고, 발생할 수 있는 문제를 해결합니다.

    체크리스트로 최종 확인:

    • 문서 생성 확인: 드라이브 폴더에 학생 수만큼 파일이 있는가?
    • 데이터 치환 확인: 임의 3명의 성적표를 열어 {{플레이스홀더}}가 남아있지 않은가?
    • 권한 확인: 파일 "공유" 설정에서 "제한됨"으로 표시되는가?
    • 이메일 확인: "보낸편지함"에 발송 기록이 있는가?
    • 시트 보호 확인: 성적원본 시트에서 셀을 편집하려 하면 차단되는가?

    자주 발생하는 에러와 해결법:

    CASE STUDY: "Document has been trashed" 에러

    템플릿 문서를 실수로 휴지통에 넣으면 makeCopy()가 실패합니다. 해결: 드라이브 휴지통에서 복원하거나, 템플릿 ID를 올바른 것으로 교체하세요.

    CASE STUDY: "You have exceeded the maximum sending quota" 에러

    일일 이메일 발송 한도 초과입니다. 해결: MailApp.getRemainingDailyQuota()로 남은 횟수를 확인하고, 한도를 넘길 경우 다음 날 나머지를 발송하도록 코드를 수정하세요.

    CASE STUDY: replaceText가 작동하지 않음

    템플릿에서 {{학생이름}}을 타이핑할 때, 한글 자동완성이 중괄호 사이에 보이지 않는 문자를 삽입하는 경우가 있습니다. 해결: 템플릿의 플레이스홀더를 메모장에서 타이핑한 후 붙여넣기 하세요.

    📝 전체 코드¶

    아래는 이번 장의 핵심 함수를 하나의 파일에 정리한 전체 코드입니다. 복사하여 Apps Script 에디터에 붙여넣고, 상단의 설정값(ID)만 수정하면 바로 실행할 수 있습니다.

    // ═══════════════════════════════════════════════════
// 📋 성적표 개별 생성 & 보안 관리 – 전체 통합 스크립트
// ═══════════════════════════════════════════════════

// ── 전역 설정 (이 부분만 수정하세요) ──
const CONFIG = {
  SPREADSHEET_ID: '여기에_스프레드시트_ID',
  TEMPLATE_ID:    '여기에_템플릿_문서_ID',
  FOLDER_ID:      '여기에_폴더_ID',
  SHEET_NAME:     '성적원본',
  ADMIN_EMAIL:    '담당자@school.ac.kr'
};


/**
 * 1. 학생별 성적표 생성
 */
function createReportCards() {
  const ss    = SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID);
  const sheet = ss.getSheetByName(CONFIG.SHEET_NAME);
  const data  = sheet.getDataRange().getValues();
  const folder   = DriveApp.getFolderById(CONFIG.FOLDER_ID);
  const template = DriveApp.getFileById(CONFIG.TEMPLATE_ID);
  const today    = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd');
  const totalStudents = data.length - 1;

  const results = [];

  for (let i = 1; i < data.length; i++) {
    const row = data[i];
    const studentName = row[0];
    const email       = row[1];

    try {
      const fileName = studentName + '_2025_1학기_성적표';
      const copy = template.makeCopy(fileName, folder);
      const doc  = DocumentApp.openById(copy.getId());
      const body = doc.getBody();

      body.replaceText('\\{\\{학생이름\\}\\}', studentName);
      body.replaceText('\\{\\{국어\\}\\}',     String(row[2]));
      body.replaceText('\\{\\{수학\\}\\}',     String(row[3]));
      body.replaceText('\\{\\{영어\\}\\}',     String(row[4]));
      body.replaceText('\\{\\{총점\\}\\}',     String(row[5]));
      body.replaceText('\\{\\{평균\\}\\}',     String(row[6]));
      body.replaceText('\\{\\{등급\\}\\}',     String(row[7]));
      body.replaceText('\\{\\{석차\\}\\}',     String(row[8]));
      body.replaceText('\\{\\{전체인원\\}\\}', String(totalStudents));
      body.replaceText('\\{\\{발급일\\}\\}',   today);
      body.replaceText('\\{\\{국어등급\\}\\}', String(row[7]));
      body.replaceText('\\{\\{수학등급\\}\\}', String(row[7]));
      body.replaceText('\\{\\{영어등급\\}\\}', String(row[7]));

      doc.saveAndClose();

      results.push({
        name: studentName, email: email,
        fileId: copy.getId(), status: '성공'
      });
      Logger.log('✅ ' + studentName + ' 성적표 생성 완료');

    } catch (e) {
      results.push({
        name: studentName, email: email,
        fileId: null, status: '실패: ' + e.message
      });
      Logger.log('❌ ' + studentName + ' 실패: ' + e.message);
    }
  }

  PropertiesService.getScriptProperties()
    .setProperty('reportResults', JSON.stringify(results));
  Logger.log('📊 ' + results.filter(r => r.status === '성공').length + 
    '/' + totalStudents + '명 성공');
  return results;
}


/**
 * 2. 개별 권한 설정 (PRIVATE + 학생 뷰어)
 */
function setReportPermissions() {
  const resultsJson = PropertiesService.getScriptProperties()
    .getProperty('reportResults');
  if (!resultsJson) { Logger.log('⚠️ 먼저 createReportCards 실행'); return; }

  const results = JSON.parse(resultsJson);
  let count = 0;

  for (const item of results) {
    if (item.status !== '성공') continue;
    try {
      const file = DriveApp.getFileById(item.fileId);
      file.setSharing(DriveApp.Access.PRIVATE, DriveApp.Permission.NONE);
      file.addViewer(item.email);
      count++;
      Logger.log('🔒 ' + item.name + ' 권한 설정 완료');
    } catch (e) {
      Logger.log('❌ ' + item.name + ' 권한 실패: ' + e.message);
    }
  }
  Logger.log('🔒 완료: ' + count + '명');
}


/**
 * 3. PDF 변환 + 이메일 발송
 */
function sendReportCardEmails() {
  const resultsJson = PropertiesService.getScriptProperties()
    .getProperty('reportResults');
  if (!resultsJson) { Logger.log('⚠️ 먼저 createReportCards 실행'); return; }

  const results = JSON.parse(resultsJson);
  let sent = 0;

  // 발송 전 남은 쿼터 확인
  const quota = MailApp.getRemainingDailyQuota();
  Logger.log('📧 남은 일일 발송 쿼터: ' + quota);

  if (quota < results.length) {
    Logger.log('⚠️ 쿼터 부족! 필요: ' + results.length + ', 남음: ' + quota);
    // 쿼터가 부족해도 가능한 만큼은 발송
  }

  for (const item of results) {
    if (item.status !== '성공') continue;
    if (sent >= quota) {
      Logger.log('⚠️ 쿼터 소진. 나머지는 내일 발송 필요.');
      break;
    }

    try {
      const doc = DriveApp.getFileById(item.fileId);
      const pdfBlob = doc.getAs('application/pdf');
      pdfBlob.setName(item.name + '_성적표.pdf');

      MailApp.sendEmail({
        to: item.email,
        subject: '[성적표] 2025학년도 1학기 성적표 안내',
        htmlBody: '<h3>' + item.name + ' 님의 성적표</h3>' +
          '<p>첨부 PDF를 확인해 주세요.</p>' +
          '<p><a href="https://docs.google.com/document/d/' + 
          item.fileId + '/edit">온라인 보기</a></p>',
        attachments: [pdfBlob]
      });

      sent++;
      Logger.log('📧 ' + item.name + ' 발송 완료');
      Utilities.sleep(1000);
    } catch (e) {
      Logger.log('❌ ' + item.name + ' 발송 실패: ' + e.message);
    }
  }
  Logger.log('📧 발송 완료: ' + sent + '명');
}


/**
 * 4. 원본 시트 보호
 */
function protectGradeSheet() {
  const ss    = SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID);
  const sheet = ss.getSheetByName(CONFIG.SHEET_NAME);

  // 시트 전체 보호
  const protection = sheet.protect()
    .setDescription('성적 원본 보호 - ' + new Date().toLocaleDateString());

  const editors = protection.getEditors();
  for (const editor of editors) {
    if (editor.getEmail() !== CONFIG.ADMIN_EMAIL) {
      protection.removeEditor(editor);
    }
  }
  protection.setWarningOnly(false);

  // 수식 범위 추가 보호 (F~I열)
  const lastRow = sheet.getLastRow();
  if (lastRow > 1) {
    const rangeProtection = sheet.getRange(2, 6, lastRow - 1, 4).protect()
      .setDescription('수식 영역 보호');
    const rEditors = rangeProtection.getEditors();
    for (const e of rEditors) {
      if (e.getEmail() !== CONFIG.ADMIN_EMAIL) {
        rangeProtection.removeEditor(e);
      }
    }
    rangeProtection.setWarningOnly(false);
  }

  Logger.log('🛡️ 시트 보호 완료');
}


/**
 * 5. 보호 해제 (다음 학기 준비용)
 */
function removeProtections() {
  const ss    = SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID);
  const sheet = ss.getSheetByName(CONFIG.SHEET_NAME);

  const allProtections = [
    ...sheet.getProtections(SpreadsheetApp.ProtectionType.SHEET),
    ...sheet.getProtections(SpreadsheetApp.ProtectionType.RANGE)
  ];

  for (const p of allProtections) {
    p.remove();
  }
  Logger.log('🔓 모든 보호 해제 (' + allProtections.length + '개)');
}

    ⚠️ 자주 하는 실수¶

    실수 1: 플레이스홀더 정규식 이스케이프 누락 🔥¶

    증상: replaceText를 실행했는데 {{학생이름}}이 그대로 남아있음

    원인: replaceText의 첫 번째 인자는 정규표현식입니다. {는 정규식에서 "앞 문자를 N번 반복"을 의미하는 특수문자이므로, 그대로 넣으면 문자 {를 찾지 못합니다.

    해결: - ❌ body.replaceText('{{학생이름}}', name) — 작동 안 함 - ✅ body.replaceText('\\{\\{학생이름\\}\\}', name) — 올바른 코드

    기억법: "중괄호에는 항상 백슬래시 두 개!" — \\{ 이 패턴을 몸에 익히세요.

    실수 2: ANYONE_WITH_LINK로 성적표 공유 😱¶

    증상: 성적표 링크를 아는 사람이면 누구나 열람 가능

    원인: 기본 공유 설정이 ANYONE_WITH_LINK인 상태에서 addViewer()만 호출하면, 기존의 링크 공유 설정은 그대로 남습니다.

    해결: 반드시 setSharing()을 먼저 호출하여 PRIVATE으로 변경한 후 addViewer()를 호출하세요.

    // 순서가 중요합니다!
file.setSharing(DriveApp.Access.PRIVATE, DriveApp.Permission.NONE); // 먼저!
file.addViewer(email); // 그 다음!

    실수 3: setWarningOnly(true)로 시트 보호 설정 🤦¶

    증상: 시트를 보호했다고 생각했는데, 다른 사람이 여전히 편집 가능

    원인: setWarningOnly(true)는 "정말 편집하시겠습니까?"라는 경고만 보여줄 뿐, "확인"을 누르면 편집이 됩니다. 사실상 보호가 아닙니다.

    해결: - ❌ protection.setWarningOnly(true) — 경고만, 차단 안 됨 - ✅ protection.setWarningOnly(false) — 완전 차단

    성적 데이터에는 예외 없이 false입니다.

    실수 4: 메일 발송 쿼터 미확인 후 대량 발송 📭¶

    증상: 처음 N명은 정상 발송되다가, 갑자기 에러 발생하며 나머지는 미발송

    원인: Google Apps Script의 이메일 발송 한도(무료: 100통/일, Workspace: 1,500통/일)를 초과

    해결: 발송 전 반드시 쿼터 확인 → 부족하면 배치 분할

    const quota = MailApp.getRemainingDailyQuota();
if (quota < studentCount) {
  Logger.log('⚠️ 쿼터 부족! 오늘 ' + quota + '명만 발송합니다.');
}
