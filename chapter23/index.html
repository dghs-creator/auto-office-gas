    실전 프로젝트 ① – 학기 초 원클릭 세팅 시스템¶

    Part 6: 통합 활용과 확장 – 나만의 자동화 시스템 만들기 | 23차시

    🎯 이 장에서 배우는 것¶

    • 캘린더 등록 + 클래스룸 생성 + 학생 초대를 하나의 스크립트로 연결할 수 있다
    • 메뉴 버튼 하나로 학기 초 세팅 전체를 실행하는 커스텀 UI를 만들 수 있다
    • 실행 전 확인 대화상자와 진행 상황 표시를 구현할 수 있다
    • 에러가 발생해도 전체 프로세스가 멈추지 않는 에러 처리 구조를 설계할 수 있다

    💡 왜 이걸 배우나요?¶

    학기 초가 되면 모든 교육 담당자와 관리자에게 동일한 루틴이 찾아옵니다.

    "캘린더에 일정 등록하고, 클래스룸(또는 팀 채널) 만들고, 참가자 초대하고…"

    하나하나는 어렵지 않습니다. 하지만 학급이 5개, 10개, 20개가 되면 이야기가 달라집니다. 수작업으로 반복하다 보면 오타, 누락, 중복 생성 같은 실수가 반드시 발생합니다.

    🏭 공장 비유: 자동차 공장에서 엔진 조립, 도장, 검수를 각각 다른 건물에서 하면 비효율적입니다. 하나의 컨베이어 벨트 위에 올려놓으면 원자재가 들어가서 완성차가 나옵니다. 우리가 만들 '원클릭 세팅 시스템'이 바로 이 컨베이어 벨트입니다.

    이번 장을 마치면, 스프레드시트에 데이터를 정리한 뒤 메뉴 버튼 하나만 클릭하면 아래 작업이 순서대로 자동 실행됩니다.

    flowchart LR A["📋 스프레드시트\n데이터 입력"] --> B["📅 캘린더\n일정 등록"] B --> C["🏫 클래스룸\n과목 생성"] C --> D["👥 학생\n일괄 초대"] D --> E["✅ 결과\n리포트 출력"]

    비즈니스 현장에서도 신규 프로젝트 세팅, 분기별 팀 재편성, 워크숍/캠프 일괄 준비 등 동일한 패턴에 그대로 적용할 수 있습니다.

    📚 핵심 개념¶

    개념 1: 통합 오케스트레이션 함수 🎼¶

    비유부터 시작합시다. 오케스트라에는 바이올린, 첼로, 플루트 등 각각의 파트가 있지만, 지휘자가 전체 흐름을 조율합니다. 우리 스크립트에서도 캘린더 함수, 클래스룸 함수, 초대 함수가 각각 '파트'이고, 이들을 순서대로 호출하며 데이터를 전달하는 메인 함수가 '지휘자' 역할을 합니다.

    정확한 정의: 오케스트레이션 함수(Orchestration Function)란 여러 개의 하위 기능(서브 함수)을 정해진 순서대로 호출하면서, 앞 단계의 결과를 다음 단계에 넘겨주는 최상위 제어 함수입니다.

    예시로 확인:

    function orchestrateSetup(config) {
  // 1단계: 캘린더 일정 등록
  const calendarResults = createCalendarEvents(config.events);

  // 2단계: 클래스룸 생성 (1단계 결과 활용)
  const classroomResults = createClassrooms(config.courses);

  // 3단계: 학생 초대 (2단계에서 생성된 courseId 활용)
  const inviteResults = inviteStudents(classroomResults, config.students);

  // 4단계: 결과 리포트
  return generateReport(calendarResults, classroomResults, inviteResults);
}

    핵심 포인트: 오케스트레이션 함수는 직접 "일"을 하지 않습니다. 누가, 어떤 순서로, 무엇을 전달받아 실행할지만 결정합니다. 덕분에 개별 기능을 수정해도 전체 흐름이 깨지지 않습니다.

    개념 2: 커스텀 메뉴 UI 🖱️¶

    비유: 스마트폰 홈 화면의 앱 아이콘을 떠올려보세요. 복잡한 코드를 몰라도 아이콘 하나만 누르면 앱이 실행됩니다. 커스텀 메뉴도 마찬가지로, 스프레드시트 상단 메뉴바에 나만의 메뉴를 추가해서, 코드 편집기를 열지 않고도 스크립트를 실행할 수 있게 합니다.

    정확한 정의: onOpen() 트리거를 사용해 스프레드시트가 열릴 때 자동으로 메뉴를 추가하는 기능입니다. SpreadsheetApp.getUi() 객체를 통해 메뉴 항목과 연결할 함수를 지정합니다.

    예시로 확인:

    function onOpen() {
  const ui = SpreadsheetApp.getUi();
  ui.createMenu('🚀 학기 초 세팅')
    .addItem('전체 세팅 실행', 'runFullSetup')
    .addSeparator()
    .addItem('캘린더만 등록', 'runCalendarOnly')
    .addItem('클래스룸만 생성', 'runClassroomOnly')
    .addItem('학생 초대만 실행', 'runInviteOnly')
    .addToUi();
}

    스프레드시트를 열면 메뉴바에 🚀 학기 초 세팅이 나타나고, 클릭하면 하위 항목이 펼쳐집니다.

    실무 TIP 💼: 메뉴 항목을 전체 실행과 부분 실행으로 나누세요. 테스트할 때는 부분 실행으로 개별 기능을 검증하고, 본 작업에서는 전체 실행을 사용합니다.

    개념 3: 확인 대화상자와 진행 상황 표시 💬¶

    비유: ATM에서 100만 원을 이체할 때 "정말 이체하시겠습니까?"라는 확인 화면이 뜹니다. 실수로 버튼을 눌렀을 때 큰 사고를 방지하는 안전장치입니다. 우리 시스템에도 동일한 안전장치가 필요합니다.

    정확한 정의: Browser.msgBox() 또는 ui.alert()를 사용하여 실행 전 사용자에게 확인/취소를 묻는 대화상자를 표시합니다. 진행 상황은 SpreadsheetApp.getActiveSpreadsheet().toast() 메서드로 화면 우하단에 간결하게 표시합니다.

    예시로 확인:

    function runFullSetup() {
  const ui = SpreadsheetApp.getUi();

  // 확인 대화상자
  const response = ui.alert(
    '⚠️ 전체 세팅 실행',
    '캘린더 등록, 클래스룸 생성, 학생 초대를 모두 실행합니다.\n계속하시겠습니까?',
    ui.ButtonSet.YES_NO
  );

  if (response !== ui.Button.YES) {
    ui.alert('취소되었습니다.');
    return;
  }

  // 진행 상황 표시 (토스트 메시지)
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  ss.toast('1/3 캘린더 일정 등록 중...', '🚀 세팅 진행', 10);
  // ... 캘린더 작업 실행

  ss.toast('2/3 클래스룸 생성 중...', '🚀 세팅 진행', 10);
  // ... 클래스룸 작업 실행

  ss.toast('3/3 학생 초대 중...', '🚀 세팅 진행', 10);
  // ... 초대 작업 실행

  ss.toast('✅ 모든 세팅이 완료되었습니다!', '완료', 5);
}

    핵심 포인트: 확인 대화상자는 실수 방지, 토스트 메시지는 "지금 뭘 하고 있는지" 알려주는 역할입니다. 사용자가 불안해하지 않도록 반드시 진행 상황을 보여주세요.

    개념 4: 에러 격리 패턴 🛡️¶

    비유: 비행기에는 엔진이 2개 이상 있습니다. 하나가 고장 나도 나머지 엔진으로 비행을 계속할 수 있습니다. 우리 스크립트도 마찬가지로, 캘린더 등록에서 에러가 나도 클래스룸 생성과 학생 초대는 계속 진행되어야 합니다.

    정확한 정의: 각 단계를 try-catch 블록으로 감싸서, 한 단계의 실패가 전체 프로세스를 중단시키지 않도록 하는 설계 패턴입니다. 에러 정보는 별도 배열에 수집하여 마지막에 한꺼번에 리포트합니다.

    예시로 확인:

    function safeExecute(taskName, taskFunction) {
  try {
    const result = taskFunction();
    return { success: true, task: taskName, data: result };
  } catch (error) {
    Logger.log(`❌ ${taskName} 실패: ${error.message}`);
    return { success: false, task: taskName, error: error.message };
  }
}

    // ====================================
// 📅 캘린더 일정 등록
// ====================================
function createCalendarEvents() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(CONFIG.EVENT_SHEET);
  const data = sheet.getDataRange().getValues();
  const calendar = CalendarApp.getCalendarById(CONFIG.CALENDAR_ID);

  const results = [];

  // 첫 행(헤더) 건너뛰고 데이터 행 순회
  for (let i = 1; i < data.length; i++) {
    const [title, dateStr, startTime, endTime, description] = data[i];

    // 빈 행 건너뛰기
    if (!title || !dateStr) continue;

    const result = safeExecute(`일정: ${title}`, function() {
      // 날짜와 시간 조합
      const dateObj = new Date(dateStr);
      const startParts = String(startTime).split(':');
      const endParts = String(endTime).split(':');

      const startDate = new Date(dateObj);
      startDate.setHours(parseInt(startParts[0]), parseInt(startParts[1]), 0);

      const endDate = new Date(dateObj);
      endDate.setHours(parseInt(endParts[0]), parseInt(endParts[1]), 0);

      // 캘린더에 이벤트 생성
      const event = calendar.createEvent(title, startDate, endDate, {
        description: description || ''
      });

      return event.getId();
    });

    // 상태 열(F열) 업데이트
    const statusCell = sheet.getRange(i + 1, 6);  // F열
    if (result.success) {
      statusCell.setValue('✅ 완료');
    } else {
      statusCell.setValue('❌ ' + result.error);
    }

    results.push(result);
  }

  return results;
}

    🏫 클래스룸 생성 함수

    중요: Classroom API는 Apps Script의 고급 서비스로 활성화해야 합니다. Apps Script 편집기 좌측 메뉴에서 서비스 → Google Classroom API 를 추가하세요.

    // ====================================
// 🏫 클래스룸(과목) 생성
// ====================================
function createClassrooms() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(CONFIG.COURSE_SHEET);
  const data = sheet.getDataRange().getValues();

  const results = [];
  const courseMap = {};  // 과목명 → courseId 매핑 (초대 시 사용)

  for (let i = 1; i < data.length; i++) {
    const [courseName, section, description] = data[i];

    if (!courseName) continue;

    const result = safeExecute(`과목: ${courseName}`, function() {
      // Classroom API로 과목 생성
      const courseResource = {
        name: courseName,
        section: section || '',
        descriptionHeading: description || '',
        ownerId: 'me',
        courseState: 'ACTIVE'
      };

      const course = Classroom.Courses.create(courseResource);
      courseMap[courseName] = course.id;

      return course.id;
    });

    // 상태 열(D열) 업데이트
    const statusCell = sheet.getRange(i + 1, 4);  // D열
    if (result.success) {
      statusCell.setValue('✅ ID: ' + result.data);
    } else {
      statusCell.setValue('❌ ' + result.error);
    }

    results.push(result);
  }

  // courseMap을 스크립트 속성에 저장 (다음 단계에서 사용)
  PropertiesService.getScriptProperties()
    .setProperty('COURSE_MAP', JSON.stringify(courseMap));

  return results;
}

    👥 학생 초대 함수

    // ====================================
// 👥 학생 초대
// ====================================
function inviteStudents() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(CONFIG.STUDENT_SHEET);
  const data = sheet.getDataRange().getValues();

  // 이전 단계에서 저장한 courseMap 불러오기
  const courseMapStr = PropertiesService.getScriptProperties()
    .getProperty('COURSE_MAP');

  if (!courseMapStr) {
    throw new Error('과목 정보가 없습니다. 클래스룸을 먼저 생성하세요.');
  }

  const courseMap = JSON.parse(courseMapStr);
  const results = [];

  for (let i = 1; i < data.length; i++) {
    const [courseName, email] = data[i];

    if (!courseName || !email) continue;

    const result = safeExecute(`초대: ${email} → ${courseName}`, function() {
      const courseId = courseMap[courseName];

      if (!courseId) {
        throw new Error(`"${courseName}" 과목을 찾을 수 없습니다.`);
      }

      // Classroom API로 학생 초대
      const invitation = {
        courseId: courseId,
        userId: email,
        role: 'STUDENT'
      };

      Classroom.Invitations.create(invitation);
      return '초대 완료';
    });

    // 상태 열(C열) 업데이트
    const statusCell = sheet.getRange(i + 1, 3);  // C열
    if (result.success) {
      statusCell.setValue('✅ 완료');
    } else {
      statusCell.setValue('❌ ' + result.error);
    }

    results.push(result);
  }

  return results;
}

    // ====================================
// 🎼 오케스트레이션: 전체 세팅 실행
// ====================================
function runFullSetup() {
  const ui = SpreadsheetApp.getUi();
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  // ── 1. 확인 대화상자 ──
  const response = ui.alert(
    '⚠️ 전체 세팅 실행 확인',
    '다음 작업을 순서대로 실행합니다:\n\n' +
    '1️⃣ 캘린더 일정 등록\n' +
    '2️⃣ 클래스룸(과목) 생성\n' +
    '3️⃣ 수강생 초대\n\n' +
    '계속하시겠습니까?',
    ui.ButtonSet.YES_NO
  );

  if (response !== ui.Button.YES) {
    ss.toast('❌ 사용자가 취소했습니다.', '취소', 3);
    return;
  }

  // ── 2. 실행 시작 ──
  const allResults = [];
  const startTime = new Date();

  // Phase 1: 캘린더
  ss.toast('📅 1/3 단계: 캘린더 일정 등록 중...', '🚀 세팅 진행', 30);
  const calResults = safeExecute('캘린더 등록', createCalendarEvents);
  allResults.push(calResults);

  // Phase 2: 클래스룸
  ss.toast('🏫 2/3 단계: 클래스룸 생성 중...', '🚀 세팅 진행', 30);
  const classResults = safeExecute('클래스룸 생성', createClassrooms);
  allResults.push(classResults);

  // Phase 3: 학생 초대 (클래스룸 생성이 성공한 경우에만)
  if (classResults.success) {
    ss.toast('👥 3/3 단계: 수강생 초대 중...', '🚀 세팅 진행', 30);
    const inviteResults = safeExecute('학생 초대', inviteStudents);
    allResults.push(inviteResults);
  } else {
    ss.toast('⚠️ 클래스룸 생성 실패로 학생 초대를 건너뜁니다.', '경고', 5);
    allResults.push({ success: false, task: '학생 초대', error: '클래스룸 생성 실패로 건너뜀' });
  }

  // ── 3. 최종 리포트 ──
  const endTime = new Date();
  const duration = Math.round((endTime - startTime) / 1000);

  showFinalReport(allResults, duration);
}

function confirmAndRun(taskName, taskFunction) {
  const ui = SpreadsheetApp.getUi();
  const response = ui.alert(
    taskName + ' 실행',
    taskName + '을(를) 실행하시겠습니까?',
    ui.ButtonSet.YES_NO
  );

  if (response !== ui.Button.YES) return;

  const ss = SpreadsheetApp.getActiveSpreadsheet();
  ss.toast(taskName + ' 실행 중...', '진행', 30);

  const result = safeExecute(taskName, taskFunction);

  if (result.success) {
    ss.toast('✅ ' + taskName + ' 완료!', '성공', 5);
  } else {
    ui.alert('❌ ' + taskName + ' 실패\n\n' + result.error);
  }

    // ====================================
// 🛡️ 안전 실행 래퍼
// ====================================
function safeExecute(taskName, taskFunction) {
  try {
    const data = taskFunction();
    return { success: true, task: taskName, data: data };
  } catch (error) {
    Logger.log('❌ ' + taskName + ' 실패: ' + error.message);
    return { success: false, task: taskName, error: error.message };
  }
}

// ====================================
// 📊 최종 리포트 대화상자
// ====================================
function showFinalReport(results, durationSeconds) {
  const ui = SpreadsheetApp.getUi();

  let report = '=== 학기 초 세팅 결과 ===\n\n';
  report += '⏱️ 총 소요 시간: ' + durationSeconds + '초\n\n';

  let successCount = 0;
  let failCount = 0;

  results.forEach(function(r) {
    if (r.success) {
      report += '✅ ' + r.task + ' — 성공\n';
      successCount++;
    } else {
      report += '❌ ' + r.task + ' — 실패: ' + r.error + '\n';
      failCount++;
    }
  });

  report += '\n---\n';
  report += '성공: ' + successCount + '건 / 실패: ' + failCount + '건\n';

  if (failCount === 0) {
    report += '\n🎉 모든 세팅이 완료되었습니다!';
  } else {
    report += '\n⚠️ 실패 항목을 확인하고 개별 재실행하세요.';
  }

  ui.alert('📊 세팅 결과 리포트', report, ui.ButtonSet.OK);
}

function resetAllStatus() {
  const ui = SpreadsheetApp.getUi();
  const response = ui.alert(
    '🔄 상태 초기화',
    '모든 시트의 상태 열을 비웁니다. 계속하시겠습니까?',

  if (response !== ui.Button.YES) return;

  // 과목정보 D열 초기화
  const courseSheet = ss.getSheetByName(CONFIG.COURSE_SHEET);
  if (courseSheet && courseSheet.getLastRow() > 1) {
    courseSheet.getRange(2, 4, courseSheet.getLastRow() - 1, 1).clearContent();
  }

  // 수강생 C열 초기화
  const studentSheet = ss.getSheetByName(CONFIG.STUDENT_SHEET);
  if (studentSheet && studentSheet.getLastRow() > 1) {
    studentSheet.getRange(2, 3, studentSheet.getLastRow() - 1, 1).clearContent();
  }

  // 일정 F열 초기화
  const eventSheet = ss.getSheetByName(CONFIG.EVENT_SHEET);
  if (eventSheet && eventSheet.getLastRow() > 1) {
    eventSheet.getRange(2, 6, eventSheet.getLastRow() - 1, 1).clearContent();
  }

  // 저장된 과목 매핑 정보도 삭제
  PropertiesService.getScriptProperties().deleteProperty('COURSE_MAP');

  ss.toast('✅ 모든 상태가 초기화되었습니다.', '초기화 완료', 3);
}

    3. 클래스룸만 테스트: 메뉴 → 🏫 클래스룸만 생성 → 과목정보 시트의 상태 열에서 Course ID 확인
    4. 학생 초대만 테스트: 메뉴 → 👥 학생 초대만 → 수강생 시트의 상태 열 확인
    5. 전체 통합 테스트: 상태 초기화 후 → 전체 세팅 실행 → 리포트 확인

    주의사항 ⚠️: Classroom API는 Google Workspace(유료) 계정 또는 Google Workspace for Education 계정에서만 사용 가능합니다. 무료 Gmail 계정에서는 Classroom API가 작동하지 않습니다. 이 경우 캘린더 부분만 먼저 테스트하세요.

    에러 시뮬레이션 테스트

    일부러 에러를 만들어 에러 격리가 작동하는지 확인합니다.

    • 일정 시트에 날짜를 비워둔 행 추가 → 해당 행만 실패하고 나머지는 성공하는지 확인
    • 수강생 시트에 잘못된 이메일 입력 → 해당 초대만 실패하는지 확인

    // ============================================================
// 🚀 학기 초 원클릭 세팅 시스템 - 전체 코드

// ── 설정 ──
const CONFIG = {
  CALENDAR_ID: 'primary',
  COURSE_SHEET: '과목정보',
  STUDENT_SHEET: '수강생',
  EVENT_SHEET: '일정'
};

// ── 커스텀 메뉴 ──
function onOpen() {
  const ui = SpreadsheetApp.getUi();
  ui.createMenu('🚀 학기 초 세팅')
    .addItem('✅ 전체 세팅 실행', 'runFullSetup')
    .addSeparator()
    .addItem('📅 캘린더만 등록', 'runCalendarOnly')
    .addItem('🏫 클래스룸만 생성', 'runClassroomOnly')
    .addItem('👥 학생 초대만', 'runInviteOnly')
    .addSeparator()
    .addItem('🔄 상태 초기화', 'resetAllStatus')
    .addToUi();
}

// ── 안전 실행 래퍼 ──
function safeExecute(taskName, taskFunction) {
  try {
    const data = taskFunction();
    return { success: true, task: taskName, data: data };
  } catch (error) {
    Logger.log('❌ ' + taskName + ' 실패: ' + error.message);
    return { success: false, task: taskName, error: error.message };
  }
}

// ── 전체 세팅 실행 ──
function runFullSetup() {
  const ui = SpreadsheetApp.getUi();
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  const response = ui.alert(
    '⚠️ 전체 세팅 실행 확인',
    '다음 작업을 순서대로 실행합니다:\n\n' +
    '1️⃣ 캘린더 일정 등록\n' +
    '2️⃣ 클래스룸(과목) 생성\n' +
    '3️⃣ 수강생 초대\n\n' +
    '계속하시겠습니까?',
    ui.ButtonSet.YES_NO
  );

  if (response !== ui.Button.YES) {
    ss.toast('❌ 취소되었습니다.', '취소', 3);
    return;
  }

  const allResults = [];
  const startTime = new Date();

  ss.toast('📅 1/3 캘린더 일정 등록 중...', '🚀 진행', 30);
  allResults.push(safeExecute('캘린더 등록', createCalendarEvents));

  ss.toast('🏫 2/3 클래스룸 생성 중...', '🚀 진행', 30);
  const classResult = safeExecute('클래스룸 생성', createClassrooms);
  allResults.push(classResult);

  if (classResult.success) {
    ss.toast('👥 3/3 수강생 초대 중...', '🚀 진행', 30);
    allResults.push(safeExecute('학생 초대', inviteStudents));
  } else {
    allResults.push({ 
      success: false, 
      task: '학생 초대', 
      error: '클래스룸 생성 실패로 건너뜀' 
    });
  }

  const duration = Math.round((new Date() - startTime) / 1000);
  showFinalReport(allResults, duration);
}

// ── 캘린더 일정 등록 ──
function createCalendarEvents() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(CONFIG.EVENT_SHEET);
  const data = sheet.getDataRange().getValues();
  const calendar = CalendarApp.getCalendarById(CONFIG.CALENDAR_ID);
  const results = [];

  for (let i = 1; i < data.length; i++) {
    const [title, dateStr, startTime, endTime, description] = data[i];
    if (!title || !dateStr) continue;

    const result = safeExecute('일정: ' + title, function() {
      const dateObj = new Date(dateStr);
      const startParts = String(startTime).split(':');
      const endParts = String(endTime).split(':');

      const startDate = new Date(dateObj);
      startDate.setHours(parseInt(startParts[0]), parseInt(startParts[1]), 0);

      const endDate = new Date(dateObj);
      endDate.setHours(parseInt(endParts[0]), parseInt(endParts[1]), 0);

      const event = calendar.createEvent(title, startDate, endDate, {
        description: description || ''
      });
      return event.getId();
    });

    sheet.getRange(i + 1, 6).setValue(
      result.success ? '✅ 완료' : '❌ ' + result.error
    );
    results.push(result);
  }
  return results;
}

// ── 클래스룸 생성 ──
function createClassrooms() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(CONFIG.COURSE_SHEET);
  const data = sheet.getDataRange().getValues();
  const results = [];
  const courseMap = {};

  for (let i = 1; i < data.length; i++) {
    const [courseName, section, description] = data[i];
    if (!courseName) continue;

    const result = safeExecute('과목: ' + courseName, function() {
      const course = Classroom.Courses.create({
        name: courseName,
        section: section || '',
        descriptionHeading: description || '',
        ownerId: 'me',
        courseState: 'ACTIVE'
      });
      courseMap[courseName] = course.id;
      return course.id;
    });

    sheet.getRange(i + 1, 4).setValue(
      result.success ? '✅ ID: ' + result.data : '❌ ' + result.error
    );
    results.push(result);
  }

  PropertiesService.getScriptProperties()
    .setProperty('COURSE_MAP', JSON.stringify(courseMap));
  return results;
}

// ── 학생 초대 ──
function inviteStudents() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(CONFIG.STUDENT_SHEET);
  const data = sheet.getDataRange().getValues();

  const courseMapStr = PropertiesService.getScriptProperties()
    .getProperty('COURSE_MAP');
  if (!courseMapStr) {
    throw new Error('과목 정보가 없습니다. 클래스룸을 먼저 생성하세요.');
  }
  const courseMap = JSON.parse(courseMapStr);
  const results = [];

  for (let i = 1; i < data.length; i++) {
    const [courseName, email] = data[i];
    if (!courseName || !email) continue;

    const result = safeExecute('초대: ' + email, function() {
      const courseId = courseMap[courseName];
      if (!courseId) throw new Error('"' + courseName + '" 과목을 찾을 수 없음');

      Classroom.Invitations.create({
        courseId: courseId,
        userId: email,
        role: 'STUDENT'
      });
      return '완료';
    });

    sheet.getRange(i + 1, 3).setValue(
      result.success ? '✅ 완료' : '❌ ' + result.error
    );
    results.push(result);
  }
  return results;
}

// ── 최종 리포트 ──
function showFinalReport(results, durationSeconds) {
  const ui = SpreadsheetApp.getUi();
  let report = '=== 학기 초 세팅 결과 ===\n\n';
  report += '⏱️ 소요 시간: ' + durationSeconds + '초\n\n';

  let success = 0, fail = 0;
  results.forEach(function(r) {
    if (r.success) {
      report += '✅ ' + r.task + '\n';
      success++;
    } else {
      report += '❌ ' + r.task + ': ' + r.error + '\n';
      fail++;
    }
  });

  report += '\n성공 ' + success + '건 / 실패 ' + fail + '건';
  report += fail === 0 ? '\n\n🎉 완료!' : '\n\n⚠️ 실패 항목을 확인하세요.';

  ui.alert('📊 결과', report, ui.ButtonSet.OK);
}

// ── 부분 실행 ──
function runCalendarOnly() { confirmAndRun('📅 캘린더 등록', createCalendarEvents); }
function runClassroomOnly() { confirmAndRun('🏫 클래스룸 생성', createClassrooms); }
function runInviteOnly() { confirmAndRun('👥 학생 초대', inviteStudents); }

function confirmAndRun(taskName, taskFunction) {
  const ui = SpreadsheetApp.getUi();
  if (ui.alert(taskName, '실행하시겠습니까?', ui.ButtonSet.YES_NO) !== ui.Button.YES) return;

  SpreadsheetApp.getActiveSpreadsheet().toast(taskName + ' 실행 중...', '진행', 30);
  const result = safeExecute(taskName, taskFunction);

  result.success
    ? SpreadsheetApp.getActiveSpreadsheet().toast('✅ ' + taskName + ' 완료!', '성공', 5)
    : ui.alert('❌ 실패: ' + result.error);
}

// ── 상태 초기화 ──
function resetAllStatus() {
  const ui = SpreadsheetApp.getUi();
  if (ui.alert('🔄 초기화', '모든 상태를 비웁니다.', ui.ButtonSet.YES_NO) !== ui.Button.YES) return;

  const ss = SpreadsheetApp.getActiveSpreadsheet();

  const sheets = [
    { name: CONFIG.COURSE_SHEET, col: 4 },
    { name: CONFIG.STUDENT_SHEET, col: 3 },
    { name: CONFIG.EVENT_SHEET, col: 6 }
  ];

  sheets.forEach(function(s) {
    const sheet = ss.getSheetByName(s.name);
    if (sheet && sheet.getLastRow() > 1) {
      sheet.getRange(2, s.col, sheet.getLastRow() - 1, 1).clearContent();
    }
  });

  PropertiesService.getScriptProperties().deleteProperty('COURSE_MAP');
  ss.toast('✅ 초기화 완료', '완료', 3);
}

    ⚠️ 자주 하는 실수 (반드시 확인!)¶

    실수 1: Classroom API 서비스를 활성화하지 않음 🔴¶

    증상: ReferenceError: Classroom is not defined 에러 발생

    원인: Google Classroom API를 Apps Script 고급 서비스에 추가하지 않음

    해결: Apps Script 편집기 좌측 "+"(서비스 추가) 클릭 → Google Classroom API 선택 → 추가 클릭. 식별자가 Classroom인지 확인하세요.

    실수 2: 시간 문자열 파싱 오류 🔴¶

    증상: 캘린더 일정이 이상한 시간에 등록됨 (예: 새벽 0시)

    원인: 스프레드시트에서 "09:00"을 입력하면 자동으로 Date 객체로 변환되는 경우가 있음. String(startTime).split(':')에서 예상과 다른 값이 나옴

    해결: 시간 열의 서식을 일반 텍스트로 변경하세요. 1. 시간 열 전체 선택 2. 서식 → 숫자 → 일반 텍스트 설정 3. 시간을 다시 입력 ("09:00" 형식)

    실수 3: 무료 Gmail 계정에서 Classroom API 호출 🔴¶

    증상: GoogleJsonResponseException: API call to classroom.courses.create failed 에러

    원인: Classroom API는 Google Workspace 또는 Google Workspace for Education 계정 전용

    해결: - 방법 A: 조직의 Workspace 계정으로 전환 - 방법 B: 클래스룸 부분을 주석 처리하고 캘린더 + 시트 자동화만 활용

    실수 4: 시트 이름 오타 🟡¶

    증상: TypeError: Cannot read properties of null (reading 'getDataRange') 에러

    원인: CONFIG에 설정한 시트 이름과 실제 시트 탭 이름이 다름 (띄어쓰기, 대소문자 주의)

    해결: 시트 탭 이름을 더블클릭해서 정확히 확인하고, CONFIG 값과 글자 하나까지 일치시키세요.

    실수 5: 이전 실행 결과가 남아있는 상태에서 재실행 🟡¶

    증상: 클래스룸이 중복 생성되거나, 이미 초대된 학생에게 다시 초대장이 발송됨

    원인: 상태 열에 "완료"가 찍혀 있어도 스크립트가 이를 체크하지 않고 다시 실행

    해결: 재실행 전 반드시 🔄 상태 초기화를 먼저 실행하거나, 코드에 "이미 완료된 행은 건너뛰기" 로직을 추가하세요.

    // 개선된 버전: 이미 완료된 행 건너뛰기
if (String(data[i][statusColumn]).includes('✅')) {
  continue;  // 이미 처리된 행은 건너뜀
}

const currentStatus = String(sheet.getRange(i + 1, statusCol).getValue());

    도전 과제 3: 비즈니스 확장 — 프로젝트 킥오프 세팅 ⭐⭐⭐¶

    학기 초 세팅 패턴을 비즈니스 프로젝트에 맞게 변형하세요.

    • "과목" → "프로젝트 팀 채널" (Google Chat Space 생성)
    • "수강생" → "팀원 초대"
    • "일정" → "킥오프 미팅, 마일스톤 일정" 캘린더 등록

    동일한 오케스트레이션 구조에서 하위 함수만 교체하면 됩니다. 이것이 오케스트레이션 패턴의 진정한 힘입니다.

    CASE STUDY: 실제 활용 시나리오 3가지 📋¶

    시나리오 A — 신규 학기 전체 세팅 - 10개 과목, 300명 학생, 20개 OT 일정 - 수작업 예상 시간: 4~5시간 - 원클릭 세팅: 2~3분 (API 호출 대기 시간 포함)
